# Mac 설치 경험과 릴리즈 계획

## 목표와 참고 범위

목표는 **Mac 앱 설치 → 최초 모델 준비 → 로컬 기본 사용**이다. 사용자에게 Docker·Node·Ollama·Python의 수동 설치나 터미널 실행을 요구하지 않는다. 팀 서버 연결은 설정의 별도 선택이다. 현재 앱은 Node만 번들하고 Ollama·Whisper 환경은 별도로 준비하므로 이 목표를 아직 달성하지 않았다.

사용자가 지칭한 Alt는 문맥상 [Alt 필기앱](https://altalt.io/ko/)으로 추정한다. 링크를 사용자에게 확정받은 것은 아니다. 2026-11-18 공식 FAQ는 Apple Silicon의 로컬 전사, 로컬 AI와 선택 클라우드 기능, 기기 안 저장을 설명한다. 이는 설치 경험의 참고 자료이며 Alt 앱을 설치·분석하거나 내부 모델 설치기를 검증한 결과가 아니다.

[Lightning-SimulWhisper README](https://github.com/altalt-org/Lightning-SimulWhisper)는 Alt 앱 전체 소스가 아닌 전사 엔진이라고 밝힌다. [LICENCE.txt](https://github.com/altalt-org/Lightning-SimulWhisper/blob/main/LICENCE.txt)는 PolyForm Noncommercial 1.0.0이다. 이 저장소의 코드·바이너리를 아맞다의 상용 대리점 제품에 포함하지 않는다. 아래 설치 마법사는 아맞다의 제안이다.

| 서버 연결 | HTTPS 주소 실행 옵션 | 설정에서 연결 주소·자료 전송 범위 확인, 로컬 자료 자동 업로드 없음 |

## 최초 실행 화면

1. **이 Mac에서 시작**을 기본으로 제시한다. 기종·OS·메모리·남은 저장 공간을 검사한다. 미지원 기기에는 이유와 수동 업무 사용을 제공하며 유료 클라우드로 자동 전환하지 않는다.
2. **모델 준비** 화면에서 전사 모델과 주문 정리 모델을 나누어 이름·버전·라이선스·실제 다운로드 바이트·필요 저장 공간·다운로드 서버를 보여 준다. 모델 파일을 받는 연결이며 사용자의 녹음·원문은 전송하지 않는다고 구분한다.
3. **내려받기**는 명시적인 시작 이후 진행한다. 모델별 진행률·남은 용량·일시 정지·취소·재시도를 제공한다. 앱을 재실행해도 이어 받는다. 다운로드 실패·손상·디스크 부족 때 기존 정상 모델을 보존한다.
4. **로컬 준비 확인**은 내장 가짜 음성으로 전사와 주문 카드 생성이 실제로 끝나는지 확인한다. 파일 존재만으로 완료 표시하지 않는다. 이후 인터넷을 끊어 같은 흐름을 검증한다.
5. **업무 시작**에서 업종을 선택한다. 업종별 용어·필드·필수값·검토 규칙은 기존 버전 있는 프로필 경계를 사용한다. 첫 지원 업종은 자동차 부품이며, 임의 업종을 모두 지원한다고 표시하지 않는다.
6. **팀 서버 연결**은 설정으로 옮긴다. 접속할 서버와 전송될 자료·계정 경계를 설명하고 별도 로그인한다. 로컬 자료를 자동 동기화하거나 팀 GPU 설정을 변경하지 않는다.

## 모델과 전송·비용 표시

| 대상 | 현재 후보 및 근거 | 크기·비용·외부 전송 표시 |
|---|---|---|
| 주문 정리 | [Ollama qwen3:4b](https://ollama.com/library/qwen3:4b), Apache-2.0 | 공식 태그 페이지 약 2.5 GB. 모델 최초 다운로드만 외부 연결, 추론은 로컬. 유료 API 비용 없음. 메모리·전력·통신 사용은 별도 |
| 음성 전사 | [Systran/faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small/tree/main), 모델 카드 MIT | 공식 저장소 약 486 MB. 런타임·변환기 크기는 별도. 로컬 음성 처리, 유료 API 비용 없음 |
| 실행기 | 현재 Ollama·faster-whisper·Node 경계 유지 | 최종 배포할 각 바이너리·종속 라이브러리의 라이선스와 고지를 확정한다. 아직 자동 번들 배포 미완료 |
| 선택 서버 | 사용자가 직접 지정한 팀 서버 | 업로드할 때 녹음·원문·업무 데이터가 해당 서버로 전달된다. 서버 운영 비용과 AI 제공자 비용은 그 설정에 따름 |
| 선택 외부 AI | 별도 명시적 기능으로만 검토 | 기본 꺼짐. 제공자·전송 항목·예상 비용·철회 방법을 안내해야 하며 현재 개발/테스트에서는 호출 금지 |

위 용량은 2026-11-18 공식 페이지의 참고값이며 설치기의 고정 용량 약속이 아니다. 릴리즈 전에 모델 리비전·파일 목록·정확한 바이트·SHA-256·출처 URL·라이선스 URL을 manifest에 고정한다. 두 모델은 약 3 GB 규모이나 실행기·압축 해제·업데이트 여유 공간과 RAM 요구량은 실측 후 따로 표시한다. 태그가 변경되었다고 실행 중 자동 교체하지 않는다.

## 구현 경계와 크리티컬 패스

1. **배포 런타임 확정**: Apple Silicon용 앱 전용 Ollama 및 전사 실행기, 오디오 변환 의존성을 배포 가능한 형태로 고정한다. 시스템 PATH·사용자 Python에 의존하지 않고 앱이 만든 프로세스만 관리한다. 현재 adapter의 `127.0.0.1:11434` 고정 경로와 함께 앱 전용 helper 연결 경계를 변경하여 사용자가 띄운 Ollama 데몬과 충돌하지 않게 한다. 실행파일·플러그인은 서명된 앱 업데이트로 제공하고 최초 준비 단계에서는 검증된 모델 가중치만 받는다. Node 팀 서버 경로와 기존 GPU 워커는 그대로 둔다.
2. **모델 관리자**: 내려받기 manifest, 저장 공간 확인, 재개·취소, 체크섬 검증, 임시 파일의 원자적 교체, 이전 버전 복구를 구현한다. 외부 연결은 준비 단계의 승인된 모델 배포 주소로 제한한다.
3. **로컬 시작 흐름**: 로컬 소유자/업종 설정과 실행기 상태를 UI에 연결한다. 기존 웹 계정·작업공간 검증을 무력화하지 않고 로컬 소유자 생성에만 앱 전용 1회성 인증 경계를 설계한다. 재실행해도 같은 로컬 작업공간을 사용하고 세션과 일꾼 자격 증명을 자동 구성하여 outbox·SQLite 조회·worker.env 수동 편집을 제거한다.
4. **실제 추론 수용 시험**: 실제 가짜 음성으로 전사·카드·근거 질의·재시작 후 자료 보존을 확인한다. 시간·메모리·품질과 다운로드 이후 외부 연결 여부를 기록한다. fixture 시험과 다른 결과물로 관리한다.
5. **배포 서명·업데이트**: 중첩 실행기 서명·공증·설치본 무결성, 업데이트 실패 복구와 사용자 자료 보존을 검증한다. 이 검증 전에는 일반 사용자용 완성 설치판으로 발표하지 않는다.

## 릴리즈 체크리스트

- [ ] Node·Docker·Ollama·Python이 없는 깨끗한 Apple Silicon Mac에서 설치하고 첫 업무까지 터미널 없이 진행한다.
- [ ] 실제 배포 모델의 리비전·크기·체크섬·라이선스 고지와 모든 실행기 의존성을 확정한다.
- [ ] Lightning-SimulWhisper의 비상업 라이선스 코드를 포함하지 않았는지 확인한다.
- [ ] 모델 다운로드 취소·재개·오프라인·디스크 부족·손상·업데이트 실패 후 복구를 확인한다.
- [ ] 인터넷 차단 상태에서 가짜 음성 업로드→실제 전사→실제 주문 카드→근거 질문을 통과한다.
- [ ] 파일 한 개·여러 개 선택·취소, 저장/확정/출고, 앱 재시작과 종료 후 자식 프로세스 정리를 GUI로 확인한다.
- [ ] 로컬 사용 중 음성·원문 전송 없음과 유료 API 호출 없음을 실행 증거로 확인한다.
- [ ] 팀 서버 연결은 별도 선택이며 로컬 자료 자동 업로드·팀 GPU 설정 변경이 없음을 확인한다.
- [ ] 새 UI E2E·스크린샷·실모델 결과를 보고서에 넣고 Developer ID 서명·공증·설치/업데이트를 검증한다.

체크리스트의 미체크 항목은 현재 미완료다. [현재 빌드와 수동 준비 안내](mac-app.md)는 개발 검증용 경로로 유지한다.
