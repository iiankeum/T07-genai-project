- 날짜 · 시각: YYYY-MM-DD HH:MM (KST)
- 채널: 예) 인스타그램 @계정 / 오픈채팅 「방 이름」(인원 약 n명) / 네이버 카페 「카페 이름」 ○○게시판
- 링크: 게시물 주소(비공개 방이면 「비공개 — 캡처로 대신」)
- 올린 사람: 예) 금*현
- 누가 · 어떻게 썼나: 예) AI 초안(work/02-마케팅-강현/산출물/게시물-초안/01-…md)을 금*현이 고쳐서 올림
- 운영자 허락: 예) 방장에게 미리 물어 허락받음(YYYY-MM-DD) / 홍보 게시판이라 허락 불필요 / 해당 없음
- 추적 링크: 예) https://…/intro?src=insta-1117

## 올린 내용
본문을 그대로 붙인다(그림은 `docs/promotion/img/YYYY-MM-DD-채널-1.png` 처럼 저장하고 링크).

## 반응 수치
잰 시각을 꼭 적는다. 재지 못한 칸은 `-` 로 둔다. 숫자를 짐작해 채우지 않는다.

| 잰 시각 | 조회 · 도달 | 좋아요 · 공감 | 댓글 | 공유 · 저장 | 링크 클릭(src) | 데모 방문(src) | 체험 신청(src) |
|---|---|---|---|---|---|---|---|
| +1일 YYYY-MM-DD HH:MM | | | | | | | |
| +3일 | | | | | | | |
| +7일 | | | | | | | |

- 재는 법: 조회 · 좋아요 · 댓글은 그 채널 화면(인스타 인사이트 등)에서, 링크 클릭 · 데모 방문 · 체험 신청은 개발 방 서버 기록에서 `src` 값으로 센다.
