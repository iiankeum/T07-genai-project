# 아이디어: AI 전화 주문 받아쓰기

- 작성일: 2026-11-08
- 제안자 ID: dmms0830-lang
- 타겟 업종/직무: 자동차 부품 유통(부품 대리점·도매상) / 전화로 주문을 받는 영업·출고 담당자

자동차 부품 대리점에는 정비소(공업사)에서 하루 종일 주문 전화가 온다. "그 아반떼 앞범퍼 하나, 급해요"처럼 짧고 두서없는 말이 대부분이다. 담당자는 통화하면서 메모지에 받아 적고, 끊은 뒤 다시 전산에 옮긴다.

바쁠 때는 메모가 빠지고, "아까 그 정비소가 몇 개라고 했더라" 하며 다시 전화를 건다. 통화를 녹음해 두는 곳도 있지만 녹음 파일이 쌓이기만 할 뿐 다시 듣는 일은 거의 없다.

1. 통화 녹음 파일을 올리거나, 녹음이 쌓이는 폴더를 지정해 둔다
2. 음성 인식 AI가 통화를 글로 옮긴다
3. 생성형 AI가 대화에서 주문 내용을 뽑아 "주문 카드"로 정리한다 — 누가(거래처) · 무슨 차(차종·연식·차번호) · 무슨 부품 · 몇 개 · 급한지 · 다시 물어봐야 할 것
4. 담당자는 카드를 보고 고치거나 확정만 한다. 정확한 품번은 사람이 정하고, AI는 초안까지만 만든다
5. 하루가 끝나면 "오늘 주문 n건 · 아직 처리 안 된 것 · 다시 전화해야 할 곳"을 요약해 준다

- 활용 포인트 — 메모 빠짐이 줄고, 담당자가 바뀌거나 쉬는 날에도 누가 무엇을 주문했는지 남는다. "그때 분명히 두 개라고 했다" 같은 다툼도 녹음과 카드로 바로 확인할 수 있다
- 실제로 쓰일 곳 — 제안자가 자동차 부품 대리점용 업무 프로그램을 만드는 회사를 운영하고 있어, 실제 대리점에서 시범 사용과 피드백을 받을 수 있다. 홍보 대상(전국 부품 대리점·도매상, 전화로 주문받는 다른 도매업)도 분명하다
- 오픈소스 공개 — 실제 고객 통화는 쓰지 않는다. 팀원들이 정비소·대리점 역할을 나눠 가짜 주문 통화를 녹음하고, 그 녹음과 결과를 저장소에 함께 공개한다. 실제 현장에서는 녹음이 밖으로 나가지 않도록 PC 안에서 돌리는 음성 인식(Whisper 등)이나 국내 서비스를 고를 수 있게 한다
- 우려 포인트
  - 품번·차번호 같은 숫자와 "휀다·쇼바" 같은 현장 말을 음성 인식이 틀리기 쉽다 → 자주 틀리는 낱말 사전을 두고, 받아쓴 글을 생성형 AI가 한 번 더 고친다
  - 전화 음질이 낮고, 양쪽 목소리가 한 줄로 섞여 녹음되는 경우가 많다
  - 업무 통화를 당사자가 녹음하는 것은 일반적으로 허용되지만, 녹음을 외부 서비스로 보내면 개인정보 처리 위탁·국외 이전 문제가 생긴다 → 위의 PC 안 처리 선택지
- 검증 방법 — 실제 부품대리점에서 접수 부장들이 받는 전화 녹음파일을 받아서 테스트 한다 (한결이 구해올 수 있음)
