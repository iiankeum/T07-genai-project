# 아이디어: 글로벌 단말 인증·규제 Q&A 에이전트

- 작성일: 2026-11-06
- 제안자 ID: iiankeum
- 타겟 업종/직무: 스마트폰·전자기기 제조업 / 해외 인증·규제 담당자

스마트폰을 해외에 출시하려면 나라마다 다른 인증(이집트 NTRA, 사우디 CST, 인도 BIS 등)을 챙겨야 한다. 규정 문서가 국가별 기관 사이트에 흩어져 있고, 영어·아랍어·불어 등 언어도 제각각이라 담당자가 매번 직접 찾아 읽고 정리하는 데 시간이 많이 든다.

각국의 공개 규제 문서를 모아 RAG로 연결하고, "이 스펙의 단말을 ○○국에 출시하려면 어떤 인증이 필요한가?" 같은 질문에 근거 문서 링크와 함께 체크리스트로 답해주는 AI 에이전트를 만든다.

- 처음에는 국가 3~5개로 범위를 좁혀 시작
- 회사 내부 자료 없이 각국 기관의 공개 문서만 사용
- 비슷한 오픈소스가 거의 없어서 차별성이 있음
- 우려사항: 규제 문서 수집·정제에 손이 많이 가고, 원문이 영어가 아닌 경우가 있음
