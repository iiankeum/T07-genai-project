# ops/server — 데모 서버 배포 장치 사본(기록용)

여기 파일은 **서버에 설치된 것의 사본**이다. 서버는 이 폴더를 읽지 않는다.
저장소에 푸시한 코드가 배포 장치를 바꾸지 못하게, 진짜 파일은 서버의 root 소유 폴더에 따로 둔다.
고치려면 서버 관리자(한결 방)가 서버에 다시 설치하고 이 사본도 같이 고친다.

| 파일 | 서버에서 하는 일 |
|---|---|
| `deploy.py` | 1분마다 `origin/dev` 를 확인 → 새 커밋이면 풀기 · `npm ci --ignore-scripts` · 앱 재시작 · 30초 헬스체크 · 실패 시 앞 버전으로 되돌림 · `/_deploy/status.json` 공개 |
| `run-app.sh` | `src/app/server.mjs` 가 있으면 그것을, 없으면 「준비 중」 서버(`placeholder.mjs`)를 띄움 |
| `applog.sh` | 배포 실패 때 앱 로그 끝 60줄을 비밀값을 가려서 보여 줌(root, 인자 없음) |
| `systemd/` | 앱 서비스(전용 사용자 · 가두기 · 메모리 300MB 상한) · 배포 서비스 · 1분 타이머 |
| `sudoers-callnote-deploy` | 배포 사용자가 root 로 할 수 있는 일 두 가지(앱 재시작 · 로그 보기) |
| `t07.caddy` | 데모 사이트 HTTPS 블록(원래 Caddyfile 에는 import 한 줄만 추가) |
| `install.sh` | 위 파일을 서버에 까는 설치기(여러 번 돌려도 같은 결과 · 비밀값은 서버에서 무작위 생성) |

사용법 · 비밀값 관리 · 되돌리는 법은 [서버 안내](../../work/00-총괄-한결/서버-안내.md)에 있다.
