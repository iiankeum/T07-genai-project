## 지킬 것(요약)
- 지어낸 후기 · 사용자 수 · 성과 · 「○○ 대리점이 쓰고 있다」를 쓰지 않는다.
- 데모는 「가짜 통화 데모」라고 쓴다. 데모에 없는 기능은 말하지 않는다.
- 실제 녹음 · 받아쓴 글 · 거래처 · 대리점 · 팀원 회사 이름을 쓰지 않는다.
- 오픈채팅 · 카페 · 밴드는 운영자 허락 먼저. 홍보 문자 · 메일은 「새 소식 받기」 동의자에게만.
- 신청자 이름 · 연락처는 서버에만. 저장소 · 단톡 · 메일로 옮기지 않는다.
