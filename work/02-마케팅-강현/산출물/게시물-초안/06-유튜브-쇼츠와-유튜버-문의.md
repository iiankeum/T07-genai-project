# 게시물 6 — 유튜브 쇼츠 · 설명 영상 대본, 중소 정비 유튜버 문의 메일 (48주차)

> AI 초안 · 돌린 사람: 배*결 · Claude Code(Opus 5.5) · 강현(마케팅) 작업방 · 2026-11-12 · 검토 전 · 게시 · 발송하지 않음

- 왜 유튜브: 50대 · 60세 이상이 가장 오래 쓰는 앱 1위가 유튜브다(2024년 8월) — [조사-유튜브-SNS-언론-협회.md](../../자료/조사-유튜브-SNS-언론-협회.md) 발견 10.
- 원칙: 화면은 가짜 통화 데모만. 「가짜 통화 데모」 자막을 처음부터 끝까지 띄운다. 데모에 실제로 있는 기능만 찍는다(개발 방 구현-대조표 확인). **다른 영상에 홍보 댓글을 달지 않는다**(유튜브 스팸 정책).

## A. 쇼츠 60초 대본 「통화 끝나면 주문 카드 한 장」
| 초 | 화면 | 자막 · 말 |
|---|---|---|
| 0~3 | 휴대폰으로 데모 통화 목록(가짜) | 「주문 전화, 녹음은 쌓이는데 다시 찾기 어렵죠?」 |
| 3~12 | 가짜 통화 열기 → 받아쓴 글(F02), 주문 내용 색 표시 | 「통화가 글로 바뀝니다」 |
| 12~25 | 주문 카드(F04) — 거래처 · 차종 · 부품 · 수량 · 급한지 | 「거래처 · 차종 · 부품 · 수량 · 급한지 — 카드 초안은 AI 가」 |
| 25~35 | 카드의 수량을 누름 → 그 문장 표시 · 녹음 재생(F05 들어 보기) | 「"두 개"라고 한 대목, 바로 다시 듣기」 |
| 35~45 | 찾기칸에 「범퍼」(F08) | 「지난 통화도 낱말로 찾기」 |
| 45~52 | 카드 고치기 → 확정(F06) | 「품번 · 확정은 담당자가」 |
| 52~60 | 소개 페이지 | 「대학 수업 팀이 만드는 시험판 · 무료 체험 신청은 고정 댓글 링크」 |

- 설명란: 「대학 수업 「인간-인공지능협업제품서비스설계」 T07 팀이 만드는 시험판입니다. 화면의 통화 · 거래처 · 번호는 모두 가짜입니다. 무료 체험 신청: https://t07.3-39-67-126.sslip.io/intro/?src=yt-shorts-1」
- 데모에 마이크 받아쓰기(F03)가 되면 0~12초를 「마이크에 대고 "아반떼 앞범퍼 두 개, 급해요"」로 바꾼다.

## B. 설명 영상 3분 뼈대 「대리점 주문 전화, 이렇게 정리해 보려 합니다」
1. (0:00) 문제 — 회의록의 문제 4가지(메모 빠짐 · 녹음 못 찾음 · 수량 다툼 · 담당자 부재). 「저희가 정리한 문제」라고 말한다(설문 결과처럼 말하지 않는다).
2. (0:40) 데모 — 쇼츠와 같은 순서, 천천히.
3. (1:50) 하지 않는 것 — 품번은 AI 가 지어내지 않는다 · 확정은 사람 · 데모는 가짜 통화.
4. (2:20) 녹음은 어디로 — 실제 체험 전에 어디서 받아쓰는지 설명하고 동의받은 뒤 시작(정하는 중인 것은 정하는 중이라고).
5. (2:40) 부탁 — 「무료 체험 신청 · 15분 인터뷰 · 현장 말 알려 주기」.
