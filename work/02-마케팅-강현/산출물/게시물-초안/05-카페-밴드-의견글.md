# 게시물 5 — 네이버 업계 카페: 운영진 허락 요청 → 의견 요청 글 (밴드는 직접 안 함)

> AI 초안 · 돌린 사람: 배*결 · Claude Code(Opus 5.5) · 강현(마케팅) 작업방 · 2026-11-11 · 검토 전 · 게시 · 발송하지 않음
> 근거: [조사-오픈채팅-카페-밴드.md](../../자료/조사-오픈채팅-카페-밴드.md)

- 목적: 홍보가 아니라 **현장 의견을 묻는 글**로 다가간다. 답은 기획(기능 우선순위)에 쓴다. 체험 신청 링크는 **운영진이 허락한 경우에만** 넣는다(설문 끝에 체험 신청을 크게 붙이면 광고로 볼 여지가 커진다 — 조사 시사점 3).
- 주의: 의견 요청이라도 우리 제품을 소개하는 설문은 광고성 정보로 볼 수 있다(KISA 안내서 52쪽 — 조사 발견 30, 검증에서 고침). 그래서 **허락 없이는 의견 요청 글도 올리지 않는다.**
- 법: 카페 · 블로그 · SNS 등 남의 공간에 영리 광고를 올리려면 운영자 사전 동의가 필요하다(정보통신망법 제50조의7). 공지에 「광고글 삭제」만 있어도 거부 의사로 본다(발견 33 · 36).
- 순서: ① 운영진에 허락 요청(11/17) → ② 허락받은 게시판 · 횟수대로 글(11/21~) → ③ 답글 요약 · 기록.
- 밴드: 정비사 밴드는 **정비업 종사자만 가입**(명함 · 자격증 확인)이라 학생 팀은 직접 들어가지 않는다. 현장 인맥이 있으면 리더에게 소개를 부탁하는 정도(발견 10 · 27).

## ① 운영진에게 보내는 허락 요청(메일 · 운영자 문의 게시판, 링크 없음)
```
제목: [학생 과제] 회원분들께 3문항 의견을 여쭙는 글을 올려도 될지 여쭙습니다

안녕하세요, ○○ 카페 운영진님.
대학 수업 「인간-인공지능협업제품서비스설계」 팀 프로젝트를 하는 T07 팀 ○○○입니다.

저희는 정비소와 부품 대리점 사이의 주문 전화를 AI 가 받아쓰고 '주문 카드'로 정리하는 도구를 과제로 만들고 있습니다.
판매나 유료 홍보가 아니고, 현장 의견을 듣고 싶습니다.

회원분들께 아래 3문항을 여쭙는 글을 한 번 올려도 될지, 된다면 어느 게시판에 몇 번까지 괜찮은지 알려 주시면 그대로 지키겠습니다.
1. 주문 전화 메모는 어떻게 하세요?
2. 주문 전화에서 겪는 불편은?
3. 통화를 AI 가 받아쓴다면 가장 걱정되는 점은?

데모(팀이 만든 가짜 통화)나 무료 체험 신청 링크는 허락해 주실 때만 넣겠습니다.
안 된다고 하시면 올리지 않겠습니다. 고맙습니다.

○○○ 드림 · [학교 메일 — 정해지면]
```

## ② 허락받은 게시판에 올리는 글

### 제목 후보
1. [학생 팀 · 운영진 허락 받음] 부품 주문 전화 받을 때 메모 어떻게 하세요?
2. [학생 팀 · 운영진 허락 받음] "아까 몇 개라고 했더라" 다시 전화하신 적 있으세요?

### 본문
```
[학생 팀 프로젝트 · 운영진 허락 받고 올립니다]

안녕하세요. 대학 수업에서 '전화 주문 받아쓰기' 도구를 만들고 있는 T07 팀입니다.
판매 글이 아니라 현장 의견을 여쭙고 싶어 글을 올립니다. 문제가 되면 바로 지우겠습니다.

저희가 정리한 문제는 이렇습니다.
- 정비소 주문 전화를 받으며 메모하고, 끊고 나서 전산에 다시 옮긴다
- 바쁠 때 메모가 빠져 "몇 개라고 했더라" 하고 다시 전화한다
- 통화 녹음은 쌓이지만 다시 찾아 듣기는 어렵다

그래서 통화를 글로 받아쓰고, 거래처 · 차종 · 부품 · 수량 · 급한지를 '주문 카드' 초안으로 정리하고, 나중에 낱말로 찾는 도구를 만들고 있어요. 품번 확정은 사람이 합니다.

여쭤보고 싶은 것 세 가지만 답글로 부탁드립니다(1분이면 됩니다).
1. 주문 전화 메모는 어떻게 하세요? (종이 / 전산에 바로 / 녹음 / 기억)
2. 위 문제 중 실제로 겪는 게 있나요? 없다면 더 큰 불편은 뭔가요?
3. 통화를 AI 가 받아쓴다면 가장 걱정되는 점은? (정확도 / 녹음 유출 / 사용법 / 기타)

(운영진이 링크를 허락하신 경우만) 데모(팀이 만든 가짜 통화)와 무료 체험 신청:
https://t07.3-39-67-126.sslip.io/intro/?src=cafe-○○-1121

고맙습니다.
```

## 지킬 것
- 가입 · 글쓰기는 금*현 님이 본인 계정 · 본인 판단으로 한다(이 방은 하지 않았다).
- 등업 조건을 채우려고 의미 없는 글 · 댓글을 쓰지 않는다.
- 답글 내용은 요약해서 기록하고, 쓴 사람 닉네임은 저장소에 남기지 않는다. 카페 회원에게 따로 쪽지 · 카톡을 보내지 않는다(대형 카페가 가장 강하게 막는 행위 — 발견 22).
- 같은 글을 여러 카페에 같은 날 올리지 않는다. 한 곳씩 반응을 보고 고친다.
