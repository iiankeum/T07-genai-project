# 게시물 4 — 카카오톡 오픈채팅 (찾기 → 방장 허락 → 허락받은 방에만)

> AI 초안 · 돌린 사람: 배*결 · Claude Code(Opus 5.5) · 강현(마케팅) 작업방 · 2026-11-11 · 검토 전 · 발송하지 않음
> 근거: [조사-오픈채팅-카페-밴드.md](../../자료/조사-오픈채팅-카페-밴드.md)

- 목적: 정비 · 부품 업계 사람이 실제로 모인 방에서 문제에 공감하는지 듣는다. 신청은 우리 소개 페이지에서 받는다.
- 현실: 업계 오픈채팅방은 웹에서 거의 보이지 않는다(앱 안 검색만 된다). 블로그 검색 결과는 대부분 개별 업체의 1:1 상담방이었다(조사 발견 11). 그래서 **찾기 → 표 만들기 → 맞는 방만 방장에게 묻기** 순서로 한다.
- 순서: ① 방 찾기 · 표(11/17~18) → ② 방장에게 허락 요청 — **첫 메시지에 링크 없음**(11/18) → ③ 허락받은 방에만 질문형 글 1회(11/19~) → ④ 질문에 답하고 기록.
- 절대 안 하는 것: 회원에게 1:1 먼저 말 걸기(**0건**) · 여러 방에 같은 글 · 남을 방에 계속 초대 · 이용자인 척하는 글. 카카오 정책상 반복 전송은 영구 제한까지 가고(발견 13), 동의 없는 1:1 광고는 정보통신망법 제50조 과태료 대상이다(발견 32 · 34).

## ① 방 찾기(앱 안 검색) — 표만 남긴다
검색어 후보(조사 시사점 7): 「정비사」 「정비인」 「자동차정비」 「카센터」 「공업사」 「1급공업사」 「판금」 「도장」 「수입차정비」 「대형차정비」 「자동차부품」 「부품대리점」 「부품상」 「중고부품」 「정비공장 경리」 「진단기」 「카센터 창업」, 「지역명 + 정비」.

| 찾은 날 | 방 이름 | 인원 | 공지의 홍보 규칙 | 맞는가(대리점 · 정비소 사람이 주문 이야기를 하는 방인가) | 방장에게 물을까 |
|---|---|---|---|---|---|
| | | | | | |

- 공지에 「홍보 금지」 · 「광고글 삭제」가 있으면 그 방은 묻지도 않는다(거부 의사로 본다 — 발견 36).
- 표는 `docs/promotion/2026-11-17-오픈채팅.md` 에 남긴다(방장 · 회원 닉네임은 적지 않는다).

## ② 방장에게 보내는 허락 요청(1:1, 링크 없음)
```
안녕하세요, ○○방 방장님. 방 공지를 보고 먼저 여쭙습니다.

저희는 대학 수업 팀 프로젝트로, 부품 주문 전화를 AI 가 받아쓰고 주문 카드로 정리하는 도구를 만드는 학생 4명입니다.
판매하는 것이 아니고, 현장 의견을 듣고 싶어서 연락드렸습니다.

방 회원분들께 "주문 전화 메모를 어떻게 하시는지" 짧은 질문 글을 한 번만 올려도 될까요?
허락해 주시면 정하신 횟수 · 방식만 지키겠습니다. 안 된다고 하시면 올리지 않겠습니다.
```
- 방장이 「소개 링크도 괜찮다」고 하면 ③의 링크 줄을 넣고, 아니면 빼고 질문만 올린다.
- 방장 답(허락 · 거절 · 무응답)은 캡처해 이름을 가리고 기록한다. 거절도 기록이다.

## ③ 허락받은 방에 올리는 글(짧게)
```
[학생 팀 프로젝트 · 방장님 허락 받고 올립니다]

안녕하세요. 부품 주문 전화를 AI 가 받아쓰고 '주문 카드'로 정리하는 도구를 만드는 대학 수업 T07 팀입니다.

여쭤보고 싶은 게 있어요.
👉 주문 전화 받을 때 메모는 어떻게 하세요? (종이 · 전산 바로 입력 · 녹음 · 기억)
👉 "몇 개라고 했더라" 하고 다시 전화하신 적, 한 주에 몇 번쯤 되세요?

답 주시면 기능을 정하는 데 그대로 씁니다. 판매 아니고, 불편하시면 바로 내리겠습니다.
(방장님이 허락하신 경우만) 가짜 통화로 움직이는 데모와 무료 체험 신청: https://t07.3-39-67-126.sslip.io/intro/?src=oc-○○-1119
```

## 답글 · 질문이 오면(예시 답)
| 질문 | 답 초안 |
|---|---|
| 돈 받나요? | 「지금은 수업 프로젝트라 무료 체험만 받습니다. 정식 서비스 · 가격은 정한 게 없어요.」 |
| 녹음이 밖으로 나가나요? | 「데모는 가짜 통화만 씁니다. 실제 체험은 녹음을 어디서 받아쓰는지 먼저 설명드리고 동의를 받은 뒤 시작합니다.」 |
| 품번도 맞춰 주나요? | 「아니요, AI 는 카드 초안까지고 품번은 담당자가 정합니다.」 |
| 어느 회사예요? | 「대학 수업 팀입니다. 팀원 한 명이 대리점 업무 프로그램 회사를 운영하고 있어서 현장 시험을 도와요.」(회사 이름은 말하지 않는다) |
| 연락처 줄 테니 따로 얘기하자 | 「고맙습니다! 소개 페이지 신청서에 남겨 주시면 거기서 연락드릴게요.」(채팅방에서 개인 연락처를 받아 따로 모으지 않는다) |

## 우리 방을 만든다면
- 팀 오픈채팅방을 만들면 **스스로 들어오는 방**으로만 운영한다. 소개 페이지에 링크를 두고, 남을 초대하지 않는다(카카오 「지속적 초대」 금지 — 발견 13).

## 지킬 것
- 방 안 대화 캡처는 다른 사람 이름 · 프로필 사진을 가린다.
- 허락을 못 받은 방, 반응이 나빴던 방도 기록한다(「규칙을 지켜 시도했다」가 기록이 된다).
