## 4. 매주 반복할 것

- **게시할 때마다** `docs/promotion/YYYY-MM-DD-채널.md`에 링크 · 내용 · 반응(+1일 · +7일)을 남긴다.
- **매주 일요일** 숫자를 모아 README 숫자판을 갱신한다.

| 숫자판 지표 | 재는 곳 |
|---|---|
| 누적 조회수 (전 채널 합) | 인스타 · 유튜브 통계 |
| 팔로워 (인스타 + 유튜브) | 각 플랫폼 |
| 참여 (좋아요 + 댓글 + 저장 + 공유) | 각 플랫폼 |
| 데모 링크 클릭 | 데모 서버 `?src=` 집계 |
| 게시 횟수 · 게시한 곳 수 | 홍보 기록 |

## 6. 일정이 밀리면

- **데모가 늦어지면**: W48 쇼츠 · 기능 카드뉴스를 1주 미루고, 그 자리에 문제 공감 · 은어 콘텐츠를 하나 더 올린다.
- **완성품이 늦어지면**: 출시 포스트를 미루고, 데모 기준으로 W50 메이커 커뮤니티 공개를 먼저 한다.
- 어떤 경우에도 **주 2회 이상 게시**는 유지한다.

## 7. 게시물에 쓰지 않을 말
- 「정확도 ○○%」 · 「100% 정확」 — 실제 통화로 잰 숫자가 없다
- 「녹음이 밖으로 안 나가요」 — 지금 구조상 사실이 아니다
- 「○○ 대리점이 쓰고 있어요」 · 지어낸 후기 — 실제 사용자가 없다
- 데모 영상에는 늘 「가짜 통화 데모」 자막을 넣는다
