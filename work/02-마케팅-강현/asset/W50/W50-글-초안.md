### 1분 소개 영상 대본 (세로 · 약 60초)
| 시간 | 화면 | 자막 / 내레이션 |
|---|---|---|
| 0~5초 | 「두 개라고 했잖아요!」 | 부품 대리점 오후 3시, 흔한 전화 |
| 5~12초 | 메모지 · 시간순 녹음 파일 | 메모는 흐릿하고, 녹음은 찾기 어렵죠 |
| 12~25초 | 녹음 올리기 → 받아쓰기 화면 | 통화가 끝나면 글로 써지고 |
| 25~35초 | 주문 카드 칸이 채워짐 | 주문 카드 한 장으로 정리돼요 |
| 35~45초 | 「들어 보기」 → 0:02 재생 | 헷갈리면 누르세요, 그 녹음이 나와요 |
| 45~53초 | 찾기 · 묻기 | 지난 통화는 찾고 물어보면 끝 |
| 53~60초 | 로고 · 주소 | [제품명] · 데모는 프로필에서 |

- 데모 쇼츠 #1 · #2 녹화본을 재사용하고, 완성품 화면만 새로 녹화한다(12/6까지).

## 12/9(수) · 메이커 커뮤니티 공개 글 (디스콰이엇 · GeekNews, 선택)

```
제목: [제품명] — 부품 대리점 주문 전화를 「근거가 붙은 주문 카드」로 바꾸는 오픈소스

안녕하세요. 5주 동안 4명이 만든 [제품명]을 공개합니다.

■ 문제
자동차 부품 대리점은 하루 종일 정비소 주문 전화를 받습니다. 통화 내용은 메모지와 기억에만 남고, 녹음은 시간순 파일로 쌓여 다시 찾기 어렵습니다. 「두 개라고 했다 / 안 했다」 다툼도 여기서 생깁니다.

■ 만든 것
- 통화 녹음 → 받아쓰기(Whisper) → 주문 카드(LLM 구조화 출력)
- 카드의 칸마다 근거 문장과 재생 위치 — 누르면 그 대목부터 재생
- 틀릴 수 있는 값은 「들어 보기」로 표시, 확정은 사람이
- 통화 찾기 · 지난 통화에 묻기(근거 없으면 「찾지 못했어요」)

■ 배운 점
- 받아쓰기 자체보다 「업무 칸 + 근거」가 차별점이었습니다.
- 거래처 이름 같은 고유명사는 받아쓰기보다 뒷단(거래처 목록 · 낱말 사전)에서 고치는 편이 나았습니다.

■ 링크
- 데모(가짜 통화): [주소]
- 코드: https://github.com/iiankeum/T07-genai-project

피드백 환영합니다!
```
