## 폴더 모양

```
asset/
  profile/  # 프로필 사진 후보 · 소개 문구 · 계정 설정 기록
  W47/ … W51/  # 주차별 게시물. 게시물 하나 = 폴더 하나 (그림 · 영상 · 글.md · 디자인 원본 .html)
  _crops/   # 데모 화면 캡처를 잘라 둔 것 (W48 이후 그림에 쓴다)
  _tools/   # 공통 스타일 base.css · 그림 뽑는 render.js
```

- `글.md` 에 게시 글과 해시태그가 있다. `_preview.png` 로 여러 장을 한 번에 훑어볼 수 있다.
- 게시한 뒤에는 `docs/promotion/YYYY-MM-DD-채널.md` 에 링크와 반응을 남긴다.
- 데모 화면이 들어간 에셋에는 「가짜 통화 데모」 표시가 보이게 한다. 정확도 숫자 · 지어낸 후기 · 「녹음이 밖으로 안 나감」 같은 말은 쓰지 않는다.
- 대학 · 수업 · 학생 언급은 넣지 않는다(금*현 님 결정, 2026-11-13).
