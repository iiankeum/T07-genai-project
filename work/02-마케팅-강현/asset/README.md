## 폴더 모양

```
asset/
  W47/   # 시작 포스트 · 문제 공감 카드뉴스 · 은어 퀴즈
  W48/   # 데모 쇼츠 #1 · 개발기 #1 · 기능 카드뉴스 #1
  W49/   # 데모 쇼츠 #2 · 기능 카드뉴스 #2 · 개발기 #2 · 출시 예고
  W50/   # 출시 포스트 · 소개 영상 · 메이커 커뮤니티 글 · 사용법 카드뉴스
  W51/   # 하이라이트 쇼츠 · 마무리 포스트
```

- 게시물 하나마다 이미지 · 영상 · 게시 글(`글.md`)을 같은 폴더에 둔다.
- 게시한 뒤에는 `docs/promotion/YYYY-MM-DD-채널.md`에 링크와 반응을 남긴다.
- 데모 화면이 들어간 에셋에는 「가짜 통화 데모」 표시가 보이게 한다.
