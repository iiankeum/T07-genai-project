## 게시 글

```
휀다, 쇼바, 미미, 데후, 빠데 🔧
정비 · 부품 현장에서는 매일 쓰는 말이지만, 처음 들으면 외계어 같죠?

5문제, 몇 개 맞히셨는지 댓글에 숫자로 남겨 주세요!
(정답은 7번째 장에 있어요)

사실 이 퀴즈를 낸 이유가 있어요.
저희는 부품 주문 전화를 받아 적는 AI를 만들고 있는데,
AI가 현장 말을 모르면 「휀다」를 엉뚱한 말로 적어 버리거든요.

그래서 부탁드려요 🙏
여러분 현장에서 쓰는 부품 별명 · 줄임말을 댓글로 알려 주세요.
모인 말은 AI 낱말 사전에 넣어서, 다음 개발기에서 결과를 공유할게요.

#자동차부품 #정비소 #카센터 #공업사 #부품대리점 #정비용어 #자동차상식 #퀴즈 #생성형AI
```

## 확인한 뜻
| 말 | 뜻 |
|---|---|
| 휀다 | 펜더 — 바퀴 위를 덮는 차체 판 |
| 쇼바 | 쇼크업소버 — 충격 흡수 장치 |
| 미미 | 엔진 마운트 — 엔진을 받치는 고무 부품 |
| 데후 | 디퍼렌셜 — 좌우 바퀴 속도 차이를 나누는 기어 |
| 빠데 | 퍼티 — 찍히거나 파인 곳을 메우는 재료 |

- 기획서 낱말 사전 예시(휀다 · 쇼바 · 미미)와 맞췄다. 게시 전 배*결 님께 현장에서 실제로 이렇게 쓰는지 한 번 확인받으면 좋다.
- 댓글로 모인 말은 「현장 말 → 표준 말」 표로 정리해 개발 쪽 낱말 사전(F07)에 넘긴다.
