## 1. 제품 한 줄

**아차(ACHA)** — 자동차 부품 대리점에 걸려 오는 주문 전화를 AI가 받아 적어, **확인만 하면 되는 「주문 카드」**로 정리해 주는 서비스.

- 이름 뜻: 통화를 끊자마자 나오는 말 「**아차**, 몇 개라고 했더라?」 + 자동차의 「**차**」. 그 순간에 열어 보는 서비스라는 뜻.
- 계정 이름: **아차 랩** (`@acha.lab`, 임시)
- 브랜드 메시지: **「통화 끊고 '아차' 할 때, 아차가 기억하고 있어요.」**
- 이전 이름 「콜카드(callcard.lab)」 · 「콜노트」 · 「아맞다」는 더 이상 쓰지 않는다.

### 핵심 기능 (에셋에서 보여 줄 것)
1. **주문 카드**: 통화가 끝나면 거래처 · 차종 · 부품 · 수량 · 급함 정도를 카드 한 장으로 정리
2. **들어 보기(근거 재생)**: 헷갈리는 칸을 누르면 그 말을 한 녹음 구간(예: 0:02)부터 바로 재생
3. **재확인 표시**: AI가 확실하지 않은 칸은 표시하고, 사람이 확인하기 전에는 확정 못 함
4. **찾기 · 묻기**: 「지난주 쏘렌토 건」처럼 지난 통화를 검색하거나 질문
5. **오늘의 브리핑**: 하루 주문 흐름, 다시 전화할 곳 정리

원칙: **AI는 초안까지, 확정은 사람이.** 품번 · 재고 · 납기는 AI가 지어내지 않는다.

## 4. 반드시 지킬 것 (금지 · 표시 규칙)

1. **지어낸 후기 · 사용자 수 · 성과 금지.** 「사장님들이 극찬!」 같은 말 안 씀.
2. **실제 커뮤니티 화면 흉내 금지.** 디시 · 네이트판 · 더쿠 등 실제 사이트 로고 · 화면을 쓰지 않는다. 「커뮤 글 느낌」은 내되, 게시판 이름은 지어 쓰고 가상임을 밝힌다.
3. **가상 이야기에는 표시**: 「※ 있을 법한 일을 재구성한 가상 이야기입니다」. 「실화」라고 쓰지 않는다.
4. **데모 화면이 들어가면 「가짜 통화 데모」 표시**를 보이게 넣는다.
5. **정확도 숫자 쓰지 않기**(예: 「인식률 98%」). 「녹음이 밖으로 안 나감」 같은 보안 약속도 쓰지 않는다.
6. **대학 · 수업 · 학생 팀 언급 금지.** 「학생 팀입니다」 같은 말 안 씀.
7. 실제 거래처 · 대리점 이름, 실제 녹음, 진짜 전화번호 · 차번호 금지. 예시 거래처는 지어낸 이름(예: 「새한카센터」).
8. 캐릭터는 **창작 캐릭터만**. 기존 만화 · 브랜드 캐릭터를 닮게 만들지 않는다.
9. 공인(연예인 등) 사진 · 얼굴 사용 금지.

## 6. 콘텐츠 방향

### 알고리즘 메모
- 팔로워 1만 미만 계정은 **릴스가 도달이 가장 높다**(팔로워 아닌 사람에게 캐러셀의 약 3배). 캐러셀은 끝까지 안 넘긴 사람에게 다시 보여 주는 장점이 있다.
- **같은 장으로 캐러셀 + 릴스(장당 2~3초 슬라이드쇼) 둘 다** 만드는 게 효율적.
- 「보내기(DM 공유)」가 팔로워 밖 도달에 중요 → 「이거 우리 가게 얘기」 하고 보내고 싶은 공감 내용.
- 유행 음악은 인스타 모바일 앱에서만 붙일 수 있음 → 영상은 음악 없이 만들고 앱에서 붙인다.

### 썰 형식 (요즘 유행)
- 1장에 「부품집 사장이 전화 한 통 때문에 30만 원 날린 썰」 같은 큰 제목 → 커뮤 글 느낌 장을 한 장씩 넘김 → 댓글창 느낌(「녹음 있어요?」「녹음 찾다가 30분 날림ㅋㅋ」) → 마지막 장 「그래서 만드는 것」 + 팔로우 유도.
- 4장 규칙(가상 표시 · 실제 사이트 흉내 금지)을 지킨다.

### 카툰 연재 「아차! 부품집 전화 극장」 (1화 초안 있음)
- 등장인물: **부품집 사장님**(안경 · 남색 앞치마 「부품」) / **정비소 실장님**(주황 모자 · 회색 작업복)
- 1화 「전화 한 통의 나비효과」 7장:
  1. 표지 · 캐릭터 소개
  2. 08:30 전화 세 대가 동시에 「따르릉」 — 「네네! 잠시만요!!」
  3. 시끄러운 정비소 — 실장님 「아반떼 AD 앞범퍼, 그거 **두 개**! 오늘 오후 급해요!」
  4. 사장님 메모 「거래처: 새한? 세안? / 아반떼 앞범.. / 수량: 1? 2?」
  5. 「두 개…였나? 하나…였나?」 사이에 다음 전화
  6. 15:10 다시 울리는 전화 — 「아차…! 아침 그 앞범퍼…」
  7. 「2화에 계속…」 + 「사장님, 두 개 시켰는데 하나만 왔어요」 예고 + 댓글 · 팔로우 유도
- 2화 「녹음은 있는데…」: 하나만 왔다는 항의 → 서로 맞다고 우김 → 녹음 파일을 처음부터 하나씩 → 30분째 못 찾음 → 「3화에 계속」
- 3화 「아차가 기억하고 있어요」: 같은 상황, 이번엔 주문 카드 → 「들어 보기」 → 실장님 목소리 「두 개!」 → 해결 · 제품 소개(데모 화면엔 「가짜 통화 데모」 표시)
- 모든 화에 가상 이야기 표시. 1화에는 제품이 안 나온다(일부러).
- 더 강한 재료: 팀원(부품 업계 경험자)에게 실제 현장 이야기를 받아 이름 · 가게를 빼고 「실화 재구성」으로 쓰기.
