## 인스타 (릴스)

인스타 페이지에서는 GitHub 주소로 바로 받을 수 없다(CSP). GitHub 탭에서 받아 **주소 # 뒤에 실어** 인스타 탭으로 넘긴다. 주소 길이 한계 때문에 base64 를 1,500,000자씩 나눠 여러 번 넘기고, 인스타 쪽 IndexedDB 에 모은다.

1. GitHub 탭(`https://github.com/iiankeum/T07-genai-project`)에서 javascript 로 파일을 `fetch` → base64. 조각 수 `n = ceil(길이 / 1500000)`.
2. 조각 k 마다: GitHub 탭에서 다시 받아 k 번째 조각만 잘라 `location.href = 'https://www.instagram.com/acha.lab.kr/#' + k + ',' + n + ',' + 조각` 으로 이동 → 인스타 탭에서 `location.hash` 를 읽어 IndexedDB(`xfer` DB, `f` 저장소, 키 `c0`…)에 넣고 `history.replaceState` 로 주소의 # 를 지운다 → GitHub 로 돌아간다.
3. 인스타 탭에서 조각을 이어 붙여 `atob` → `Blob(video/mp4)` → SHA-256 이 저장소 파일과 같은지 확인 → `File`.
4. `svg[aria-label="새로운 게시물"]` 의 버튼을 누르고, `[role=dialog]` 안의 `input[type=file]` 에 DataTransfer 로 파일을 넣고 `change` 이벤트를 보낸다. 「동영상 게시물은 릴스로 공유됩니다」 안내가 뜨면 확인.
5. 자르기(`svg[aria-label="자르기 선택"]`)에서 「원본」(세로 9:16)을 고른다 → 「다음」 → 「다음」.
6. 캡션: `[role=dialog] [contenteditable=true]` 에 focus 후 `ClipboardEvent('paste')`(DataTransfer text/plain)로 넣고, `innerText` 해시를 확인한다.
7. AI 레이블: 「AI 레이블 추가」 옆 `input[type=checkbox]` 를 표의 값대로 켠다/끈다.
8. 「공유하기」 → 「릴스가 공유되었습니다」/「게시물이 공유되었습니다」가 뜰 때까지 기다린다.
9. 프로필에서 새 게시물 주소(`/reel/…` 또는 `/p/…`)를 확인한다. `indexedDB.deleteDatabase('xfer')`.

## 유튜브 (쇼츠)

유튜브 스튜디오 페이지는 GitHub 원본 주소를 바로 `fetch` 할 수 있다.

1. `https://studio.youtube.com/` 에서 javascript 로 영상을 `fetch` → SHA-256 확인 → `File`.
2. 「만들기」 → 「동영상 업로드」. 업로드 창의 `input[type=file]` 에 DataTransfer 로 넣고 `change`.
3. 제목: `글.md` 의 유튜브 제목. 설명: 인스타 캡션에서 해시태그 줄을 뺀 글 + `인스타그램: @acha.lab.kr` + 마지막 줄에 인스타 태그 중 앞의 2개와 `#아차랩` (예: `#정비소 #자영업자 #아차랩`). 데모 쇼츠 #1 은 `글.md` 의 유튜브 설명 그대로.
4. 시청자층: 「아니요, 아동용이 아닙니다」.
5. 「자세히 보기」 → 「변경되거나 합성된 콘텐츠」: 표의 AI 표시가 「켬」이면 **예**, 「끔」이면 아니요.
6. 「다음」 세 번 → 공개 상태 **공개** → 「게시」. 나온 영상 주소를 적어 둔다.
