# 실사 쇼츠 만드는 방법 — Claude 가 ChatGPT · Flow 를 직접 돌린다

> AI 작성 · 돌린 사람: 금*현 · Claude(Opus 5.5) · 2026-11-26 · 방식 결정: 금*현 2026-11-26

매일 새벽 예약 작업 「아차 랩 실사 쇼츠 5편 만들기」가 이 문서대로 한다. 2026-11-26 A6 「손등 메모」를 이 방법으로 처음 만들었다.

## 준비 (작업공간)

- 글꼴: `mkdir -p ~/.fonts && cp _kit/fonts/*.ttf ~/.fonts/ && fc-cache -f` (Jua · Black Han Sans · Nanum Pen Script, 모두 OFL).
- Playwright 는 보통 깔려 있다(`node -e "require('playwright')"`). 없으면 `npm i -g playwright && npx playwright install chromium`.
- ffmpeg · python3(numpy · scipy) 필요.

## 브라우저

- 금*현 님 PC 의 Claude 데스크톱 앱 **내장 브라우저**(`mcp__remote-devices__Claude_Browser__*`). ChatGPT · Flow(flow.google.com)는 금*현 님 계정으로 로그인돼 있다.
- **로그인 · 비밀번호 입력 · 약관/권리 확인 「동의」는 Claude 가 누르지 않는다.** 그런 창이 뜨면 거기서 멈추고 금*현 님에게 알린다.
- 브라우저 → 작업공간으로 파일 가져오기: 페이지 안에서 `fetch` → base64 → `javascript_tool` 결과로 **25만 자씩** 나눠 돌려받는다(결과가 크면 작업공간의 `/tmp/claude-tool-results/…txt` 에 저장된다). 각 조각은 `'C<번호>:' + 조각 + ':END'` 로 감싸고, 작업공간에서 이어 붙여 디코드한 뒤 **SHA-256 이 브라우저에서 잰 값과 같은지** 확인한다.
- 작업공간 → 브라우저(기준 인물 사진): ChatGPT 페이지는 GitHub 원본을 직접 못 받는다(CSP). github.com 탭에서 받아 base64 로 `location.href = 'https://chatgpt.com/#ref=' + b64` 로 넘기고, 도착한 페이지에서 `location.hash` 를 읽어 `File` 로 만든다.

## 한 편 만드는 순서

1. **아이디어**: [아이디어-대기열.md](../아이디어-대기열.md) 에서 `대기` 인 맨 위 하나. 장면 · 인물(사장님=`boss-기준.jpg` · 실장님=`mech-기준.jpg`, `asset/toon/ep01-real/ref/`) · 자막 · 캡션이 적혀 있다.
2. **ChatGPT 이미지**: 새 대화 → 기준 인물 사진을 `input[type=file][accept="image/*"]` 에 DataTransfer 로 넣고 → 「Create an image. …」 + 아래 **이미지 공통 꼬리** 로 보낸다. 1 ~ 2분 뒤 `img[alt^="생성된 이미지"]` 를 받는다(canvas 로 JPEG 0.93 으로 줄여서 가져오면 조각이 2개면 된다).
   - **확인**: 인물이 기준과 같나(주황 모자 · 회색 작업복 / 사장님 안경 · 옷), 글자 · 숫자 · 로고가 없나, 장면이 첫 1초에 읽히나. 아니면 같은 대화에서 고칠 점만 적어 한 번 더 시킨다(한 아이디어에 최대 2번).
3. **Flow 영상**: 이미지를 `https://flow.google.com/project/<프로젝트>#img=<b64>` 로 넘겨 `File` 로 만든 뒤 페이지에 drop 이벤트로 올린다. 설정: **동영상 · 프레임 · 9:16 · Veo 3.1 - Lite · x1**(10 크레딧). **모델은 반드시 Lite**(금*현 2026-11-26 — 하루 5편은 Lite 기준. Fast 는 20 크레딧이라 절반밖에 못 만든다). 「시작」에 그 이미지를 고르고 움직임 프롬프트 + **움직임 공통 꼬리** → 보내기. 1 ~ 2분.
   - 결과 영상을 열어 `video.currentSrc` 를 얻고, **다른 탭에서 그 주소로 이동**(googlevideo.com 으로 넘어감)한 뒤 그 페이지에서 `fetch(location.href)` 로 받아 조각으로 가져온다(flow 페이지에서 바로 fetch 하면 막힌다).
   - **확인**: 6장 프레임 시트로 사람 · 물건이 사라지거나 손가락이 녹는 등 깨짐이 없나 본다. 깨졌으면 그 구간을 자르거나, 크레딧이 남으면 다시 뽑는다.
4. **편집**: `bash _kit/build-one.sh <id> flow.mp4 "<첫 자막>" "<끝 자막>" "<큰 글씨>" <이 폴더>` → `-yt` · `-insta` · `-solve-insta` · `-solve-yt` 네 판. 원본 이미지 · 영상은 `img/` 에.
5. **글**: [글.md](../글.md) 에 「## <ID> · 제목 (`<id>-*`)」 절(캡션 코드 블록 + 유튜브 제목)을 더한다. 캡션 규칙은 `W48/04-릴스묶음/글.md` 「규칙」(해시태그 5개 · 5칸 역할 · 첫 줄에 현장 낱말).
6. **대기열**: [게시 대기열](../../../게시-대기열.md) 맨 아래에 `대기 | 대기` 로 넣는다. 인스타 파일 `-solve-insta`, 유튜브 `-yt`, AI 표시 「켬(사실적인 AI 영상)」.

## 이미지 공통 꼬리

```
Vertical 9:16 photo (1080x1920), photorealistic, documentary editorial photography, 35mm, natural light, shallow depth of field, muted slate blue and cream tones with a touch of coral. The person must be exactly the attached reference (same face, age, glasses, cap and clothes). Plain clothes: no text, no logos, no name tags. No readable text, letters, numbers, signs, screens or license plates anywhere. Leave the top 20% and bottom 25% of the frame calm for captions. Fictional person, not resembling any real person.
```

## 움직임 공통 꼬리

```
Simple, slow motion. Keep the person, clothes and background exactly as in the image. Handheld documentary camera, realistic. No text appears. No dialogue or speech; only quiet ambience. No voices, no talking, no words in any language.
```

움직임은 **한 동작 + 과장된 반응 하나**로 짧게 쓴다(여러 동작을 넣으면 깨진다 — 11/24 교훈). 마지막 1 ~ 2초에 B급 「아차」 표정이 오게 한다.

## 11/26 새벽 첫 예약 실행에서 배운 것

- Flow 크레딧은 **하루 2편(40 크레딧)쯤**에서 바닥났다(A6 + B2). 한도에 걸리면 보내기 단추가 주황 「!」 로 바뀐다 — 「업그레이드」 · 「설정」은 누르지 않는다.
- **전화 받는 장면은 Flow 가 「오디오를 생성할 수 없습니다」로 실패**했다(B1, 문구를 바꿔도 2번 다). 크레딧은 환불된다. 통화 장면이면 입이 움직이지 않는 동작(물건 · 손 · 몸짓)으로 쓰거나, 무음 설정은 금*현 님에게 묻는다.
- 이미지를 Flow 에 올릴 때는 프롬프트 칸이 아니라 **위쪽 결과 격자**(`elementFromPoint(400,600)`, `tile-row`)에 dragenter → 0.5초 뒤 drop 을 보내야 올라간다. `location.hash` 는 `history.replaceState` 로 지우기 전에 변수에 먼저 담는다.
- ChatGPT 에는 같은 화면이 두 벌(숨은 것 하나) 있다. 보이는 `.ProseMirror` 의 `form` 안 `input[type=file]` 을 쓰고, 「응답이 없습니다」 문구는 숨은 쪽일 수 있으니 스크린샷으로 확인한다.
- 이미지까지만 만든 아이디어는 `img/<id>.jpg` 로 남겨 둔다. 다음 실행은 ChatGPT 를 건너뛰고 그 이미지로 Flow 부터 한다.

## 11/27 새벽 실행에서 배운 것

- Flow 화면이 바뀌었다: 기본이 **「Flow 에이전트」(채팅 패널) 모드**다. 프롬프트 줄의 반짝이 단추(`aria-label="Flow 에이전트"`)를 꺼야 예전처럼 「시작 · 종료」 프레임 칸이 나온다. 모델 설정은 `aria-label="설정 트리거"` 단추(「동영상 · 720p · 8초 · 9:16 · x1」)에 있고, 처음 열었을 때 **Veo 3.1 - Fast 로 돌아가 있었다** — 매번 Lite 로 바꿔 확인한다(Fast · Quality · Omni 1.1 은 12/5 지원 종료 예정이라고 뜬다).
- 이미지는 위 격자에 drop 하면 올라가고, 「시작」을 누르면 「프레임 이미지 선택」 창에서 파일 이름으로 고를 수 있다(이미 올린 `b1-akka.jpg` · `b3-twophones.jpg` 도 남아 있다).
- 영상 주소가 `flow-content.google/video/…` 로 바뀌었다. 결과를 연 뒤 재생 단추를 누르고 `performance.getEntriesByType('resource')` 에서 그 주소를 찾아 **flow 페이지에서 바로 `fetch`** 하면 받아진다(googlevideo 탭 이동 필요 없음).
- 조각은 25만 자가 한계다. 마지막 조각이 짧으면 결과가 대화에 그대로 쏟아지므로 `'.'` 로 25만 자까지 채워 파일로 저장되게 한다(`join.py` 는 `C번호:…:END` 만 읽는다).
- **전화를 귀에 댄 이미지는 무조건 「오디오를 생성할 수 없습니다」**(B3 도 실패, 입 다문 동작으로 써도 같음). 실패 칸에 「무음 동영상을 반환하려면 설정을 업데이트하세요」가 뜨지만 설정 변경이라 누르지 않았다. 전화 장면은 폰을 손에 든 정도(B9)까지만 된다.
- ChatGPT 는 새로 연 탭의 **첫 보내기가 늘 「응답이 없습니다」로 실패**한다(주소가 `local-chatgpt:` 로 남음). 「새 채팅」을 눌러 사진 · 글을 다시 넣고 한 번 더 보내면 된다.
- Flow 크레딧은 오늘 **Lite 5편(50)** 에서 바닥났다(배너 「크레딧이 소진되었습니다」). 하루 5편이 딱 맞는다 — 실패(환불)를 빼고 5번 보낼 수 있다.

## 11/28 새벽 실행에서 배운 것

- ChatGPT 는 탭 2개(사장님 · 실장님)를 동시에 돌려도 된다. 같은 대화에서 「Now create a new, separate image with the same man …」 으로 이어 시키면 기준 사진을 다시 넣지 않아도 인물이 유지된다. 만든 이미지는 **다른 탭에서 그 대화 주소(`chatgpt.com/c/…`)를 열어도** 같은 SHA-256 으로 다시 받을 수 있다 — Flow 로 넘길 「운반 탭」을 따로 두면 ChatGPT 탭을 잃지 않는다. 해시에 이미지 두 장을 `|` 로 이어 붙여 한 번에 넘겨도 된다.
- Flow 「프레임 이미지 선택」 창에서 줄을 누르면 **미리보기만** 바뀐다. 아래 「프롬프트에 추가」를 눌러야 시작 프레임이 들어간다(첫 줄은 이미 골라져 있어 줄만 눌러도 됐던 것). Flow 는 탭 3개에서 동시에 보내도 된다.
- 전화가 없는 장면(B13 가게 앞 손 흔들기 · 입을 벌린 놀람)도 한 번 「오디오를 생성할 수 없습니다」로 실패했다(환불). 움직임 프롬프트 앞에 `Silent video.` 를 붙이고 「입을 벌림」 대신 `lips pressed together` 로 쓰니 됐다. 이후 4편 모두 이 방식으로 실패 없음.
- 영상 주소 찾기: 편집 화면 `performance` 에 `flow-content.google/video/…` 가 안 잡히는 영상이 있다(B12 · B15, 썸네일이 `storage.googleapis.com` 인 것). 그때는 **격자에서 그 칸에 마우스를 올리면** 생기는 `<video>` 의 `currentSrc`(`flow.google.com/asb/…=mm,22,15`)로 다른 탭을 이동 → `googlevideo.com` 으로 넘어가면 `fetch(location.href)`(720×1280 · 8초, itag 22). 또 `performance` 버퍼가 250개에서 차므로 먼저 `performance.setResourceTimingBufferSize(5000)`.
- 크레딧은 오늘도 Lite 5편(50)에서 소진 배너. 실패는 환불이라 5편을 다 채웠다.
