# 부품 대리점 업무 흐름 — 업무 프로그램 문서를 읽고 일반화한 것

> AI 초안 · 돌린 사람: 배*결 · Claude Code(Opus 5.5) 조사 에이전트(D2) + 남희(기획) 작업방이 한 번 더 거름 · 2026-11-11 · 검토 전

## 이 문서는 무엇인가

- 순정부품 대리점이 쓰는 업무 프로그램 하나의 설명서 · 설계 문서를 **읽기만** 하고, 「부품 대리점 업무에서 일반적으로 보이는 흐름」으로 바꿔 쓴 것이다.
- 그 프로그램을 만든 회사, 제품 이름, 고객 대리점, 사람, 화면 · 메뉴 이름, 내부 용어, 코드 · 표 이름, 경로, 주소는 적지 않았다. 그 제품만의 기능 설명도 뺐다.
- 원본이 비공개라 공개 URL 을 달 수 없다. 표시는 이렇게 한다.
  - **[현장 문서]** 비공개 업무 프로그램 문서에서 읽은 일반 흐름. 한 곳의 사정이라 업계 전체로 넓히는 것은 추정이다.
  - **[추정]** 읽은 내용을 바탕으로 한 판단.
  - **확인 못 함** 근거를 찾지 못했다 — 현장 인터뷰로 확인할 것.
- 공개 자료(기사 · 설문 · 채용 공고)로 확인한 것은 [조사-대리점-생태계.md](조사-대리점-생태계.md) 에 출처와 함께 있다.

## 1. 전화 한 통에서 마감까지

```
정비소(공업사 · 카센터)
  │ ① 전화로 주문 (일부는 문자 · 사진)
  ▼
접수 담당(현장 호칭 '부장님')
  │ ② 차종 · 연식 · 차대번호 · 부품 이름을 듣고 품번을 찾는다
  │ ③ 본사가 주는 대리점용 판매 전산에 품번 · 수량 · 거래처를 넣는다   ← 전화 주문이 전산에 처음 들어가는 자리
  ▼
④ 출고 전표 인쇄
  ▼
⑤ 창고에서 꺼내기(피킹) → 바코드로 전표와 대조(검수)
  ▼
⑥ 기사가 전표 여러 장을 묶어 한 회차로 출발 → 정비소마다 들러 내려놓음
  │   급하면 이미 나간 기사에게 덧붙이거나 퀵(오토바이 · 소형 화물)을 부른다
  ▼
⑦ 배송 닫기. 못 준 건은 다음 날로
  ▼
⑧ 반품 · 교환 · 회수 → 기사가 받아 오고, 본사 전산에 반품을 따로 넣는다
  ▼
⑨ 돈: 보험 수리 건은 보험사가, 일반 건은 정비소가 낸다
  ▼
⑩ 저녁 마감
```

- **주문을 받는 일(①~③)과 주문을 처리하는 일(④~⑩)이 서로 다른 전산에서 돈다.** [현장 문서]
- 그래서 **통화에서 오간 말은 어느 전산에도 구조화되어 남지 않는다.** 남는 것은 녹음 파일과 전표뿐이다. [추정]
- 전표 인쇄 시각이 사실상 「주문 시각」으로 쓰이지만 실제 통화 시각과는 다르다. 전표를 뽑은 사람이 전화를 받은 사람과 다를 수 있다. [현장 문서]

## 2. 단계별로 본 것

### 주문 접수 (전화)
- 손님은 사실상 정비소다. 주문 대부분이 전화로 온다고 보지만 국내 비율은 **확인 못 함**.
- 접수 담당이 원하는 것은 「전화가 안정적으로 걸리는 것」과 「누가 거는지 울릴 때 바로 보이는 것」이었다. [현장 문서]
- 전화가 몰리면 놓친다. 놓친 전화 수는 지금 어디서도 재지 못한다. [현장 문서]
- 하루 통화 수, 1인당 통화 시간은 **확인 못 함**.

### 품번 확인
- 품번 · 차대번호 판별, 정비소별 습관이 접수 담당 머리에 있다. 숙련에 시간이 걸린다. [현장 문서 · 추정]
- 같은 부품이 뒷자리만 다른 품번(색상 · 사양 · 좌우)으로 갈린다. [현장 문서]
- 반품이 많은 정비소에는 「차대번호를 한 번 더 불러 확인」하는 것이 처방으로 쓰인다. [현장 문서]

### 재고
- 대리점에 없으면 본사 물류에서 끌어오거나 이웃 대리점에서 구한다. 결품이 있으면 있는 것만 먼저 내보내고 나머지는 들어온 뒤 보낸다. [현장 문서]
- 그래서 **「언제 들어온다」는 약속이 통화에서 자주 생기는데, 그 약속을 적어 두는 자리가 마땅치 않다.** [추정]

### 출고 · 배송
- 전표는 크게 보험 수리 건 · 일반 건 · 반품 회수 건으로 갈린다. [현장 문서]
- 기사가 한 회차에 전표 여러 장을 묶어 나가고, 급한 것은 나간 기사에게 덧붙이거나 퀵을 부른다. [현장 문서]
- 정비소가 「언제 와요?」라고 묻는 전화가 많다. [현장 문서 · 추정]

### 반품 · 교환
- 반품 원인에는 잘못 주문(잘못 알아들음 · 연식 · 사양 착오), 잘못 꺼냄, 정비소 변심이 섞여 있다. 사유를 따로 남기지 않으면 원인을 가릴 수 없다. [현장 문서]
- 반품 한 건은 「갔다 오고 정리하는 공짜 노동」이다. [현장 문서]

### 외상 · 정산
- 보험 수리 부품값은 보험사가, 일반 건은 정비소가 낸다. [현장 문서]
- 일반 건 외상을 월말에 묶어 정산하는지는 **확인 못 함**.

### 마감
- 저녁에 하루 돈 장부를 마감하고, 하루 업무 메모로 다음 사람에게 넘긴다(「○○ 정비소 단가 문의」 같은 줄). [현장 문서]

## 3. 거래처(정비소)

- 같은 정비소가 대표 휴대폰 · 직원 휴대폰 · 사무실 유선처럼 **여러 번호로 전화한다.** [추정] 거래처 목록에는 보통 번호 한 칸이다.
- 같은 정비소가 이름 · 코드가 갈라져 여러 줄로 보이기도 한다. [현장 문서]
- 정비소는 거래를 끊는다고 말하지 않고 품목별로 조금씩 다른 대리점으로 옮긴다는 이야기가 있다. [현장 문서 · 추정]

## 4. 통화에서만 오가고 전산에 안 남는 것 [추정]

| 정보 | 왜 중요한가 |
|---|---|
| 연식 · 차대번호 · 세부 사양 | 맞는 품번을 고르는 근거. 반품 원인과 닿는다 |
| 좌우 · 앞뒤 · 색상 | 품번 뒷자리를 가른다 |
| 급함 · 언제까지 | 퀵을 부를지, 나간 기사에 덧붙일지 정한다 |
| 결품 때의 약속(「내일 오전 들어오면 보냄」) | 지키지 못하면 정비소가 다른 대리점으로 옮긴다 |
| 대체 허락(다른 사양도 되나) | 반품을 줄인다 |
| 배송지 · 받는 사람 | 본점이 아닌 곳으로 갈 때 |
| 다시 물어볼 것 | 품번 확인 뒤 전화 주기, 정비소가 차를 다시 보고 알려 주기 |
| 누가 말했나 · 누가 받았나 | 「두 개라고 했다 / 안 했다」를 가릴 때 |

## 5. 우리 서비스가 끼어들 자리

| 자리 | 하는 일 | 이번 데모 |
|---|---|---|
| 통화 직후 · 전산 입력 전 | 받아써 주문 카드를 띄운다. 담당은 카드를 보며 전산에 넣는다 | F02 · F04 · F06 |
| 반품 · 다툼 때 | 날짜 · 정비소 · 부품으로 지난 통화를 찾고 그 구간을 다시 들려준다 | F05 · F08 · F09 |
| 「다시 물어볼 것」 · 약속 | 할 일 목록으로 남긴다 | F04 · F10 |
| 주문이 아닌 전화 가르기 | 배송 문의 · 반품 요청 · 재고 · 단가 문의를 따로 표시 | F04(통화 종류, 개발 방과 조율 중) |
| 정비소별 말버릇 · 별칭 | 사전으로 쌓아 새 담당도 알아듣게 | F07 |
| 전화가 울릴 때 그 정비소의 최근 통화 · 주문 | 발신번호 신호가 필요 | 다음 단계 |
| 전표 인쇄 직후 카드와 전표 맞춰 보기 | 「카드엔 2개, 전표엔 1개」를 알림 | 다음 단계(전산 연동 필요) |
| 몰림 재기 | 시간대별 통화 수 · 놓친 통화 | 다음 단계 |

## 6. 조심할 점

- **주문의 정답은 본사 전산이다.** 우리 카드는 보조다. 자동 주문 · 자동 입력은 하지 않는다. [추정]
- **AI 가 품번을 지어내면 안 된다.** 틀린 품번은 오출고 → 반품으로 이어진다. [추정]
- 한 통화에 차 여러 대 · 주문 여러 건이 섞이고, 한 주문이 여러 통화로 나뉜다(「아까 그거 하나 더」). [추정]
- 바쁜 때 접수 담당은 화면을 볼 틈이 없다. **통화가 끝난 뒤 짧게 확인하는 흐름**이 맞을 수 있다. 글자는 크게, 단추는 적게. [추정]
- 사실관계를 가릴 때 **AI 요약이 아니라 원음 구간이 근거**다. 받아쓰기는 숫자(일/이)와 품번 숫자를 잘못 듣기 쉽다. [추정]
- 녹음 프로그램마다 파일 이름 형식이 다르다. 쓰는 중인 파일을 집지 말고(크기가 두 번 같을 때만), 녹음 폴더는 읽기만 하며, 원본은 손대지 않고 사본으로 변환한다. [현장 문서]
- **녹음 파일은 통화가 끝나야 생긴다.** 울릴 때 띄우는 화면은 녹음 폴더만으로는 못 만든다. [현장 문서]
- 대리점 PC 에 저장하던 녹음을 외부 서버 · 외부 AI 로 보내면 처리 위탁, 해외면 국외 이전 문제가 생긴다(법 검토 필요). [추정]

## 7. 현장 인터뷰로 물을 것

1. 하루 주문 전화 수, 놓치는 전화 비율, 바쁜 시간대
2. 통화하면서 전산에 바로 치는지, 종이에 적었다가 치는지
3. 차대번호를 말로 불러 주는지, 문자 · 사진으로 받는지
4. 일반 건 외상을 언제 · 어떻게 정산하는지
5. 「두 개라고 했다 / 안 했다」 다툼이 한 달에 몇 번인지, 그때 녹음을 실제로 찾아 듣는지
6. 녹음 프로그램과 파일 이름 형식(번호 · 수신/발신이 남는지), 한 채널인지 두 채널인지
7. 정비소가 쓰는 부품 별칭 · 차종 줄임말
