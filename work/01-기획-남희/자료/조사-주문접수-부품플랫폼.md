# 조사 A3 · 음성·문자 주문 자동 접수 AI와 자동차 부품 주문 플랫폼

## 이 문서를 읽는 법

- 조사 시점은 2026-11-11 이다. 값·기능·숫자는 모두 이 시점에 공식 사이트·기사에서 본 것이다.
- 표시 규칙
  - **[확인]** 회사 공식 사이트·도움말·약관·앱 스토어 공식 설명에서 확인했다. 다만 정확도·절감 시간 같은 숫자는 공식 페이지에 있어도 **회사 주장**이다. 독립 검증은 아니다.
  - **[추정]** 기사·제3자 리뷰·경쟁사 비교·검색 요약에서 본 것이거나, 공식 페이지를 직접 열지 못했다.
  - **[후기]** 앱 스토어 평점·리뷰 같은 사용자 의견이다.
  - **확인 못 함** 찾았지만 근거를 찾지 못했다. 지어내지 않았다.
- 표 기호: ○ 있음 · △ 부분적이거나 조건부 · × 없음(그런 종류의 서비스가 아님) · ? 공식 자료에 언급이 없어 확인 못 함
- 나라 표기는 회사 소개·기사 기준이며 따로 표시가 없으면 [추정]이다.

## 한눈에 보기

1. 식자재·산업재 유통에서는 "전화·음성사서함·문자·이메일로 온 주문 → AI 가 주문 초안 → 사람이 확인 → ERP" 흐름이 이미 상품이 됐다. Choco, Pepper, REKKI, Canals 가 대표다.
2. 실시간 전화 주문을 AI 가 직접 받는 서비스는 식당(Loman, Kea, ConverseNow)과 일부 유통(Choco VoiceAgent, Canals Live Voice)에 있다.
3. 자동차 부품 플랫폼(PartsTech, Nexpart, RepairLink, Epicor)은 "정비소가 화면에서 품번·재고를 보고 주문"하게 만드는 쪽이다. 전화를 받아쓰는 기능은 거의 없다.
4. 부품 쪽에서 전화·이메일 주문을 AI 로 읽는 시도는 막 나오고 있다(Partly AI Interpreter, Autologue AI counterman, PartsNow.ai). 대부분 [추정] 수준 자료다.
5. 국내에서 부품 대리점의 전화 주문을 받아써서 주문 카드로 만드는 서비스는 이번 조사에서 확인 못 함. 현대모비스 공식 부품몰 앱도 "보유 대리점에 전화 문의"로 끝난다.

### 3-1. Choco OrderAgent · VoiceAgent (독일 · 식자재 유통)

식당 주문 앱으로 시작했다. 2023년 LLM 기반 OrderAgent(당시 이름 Choco AI)를 내며 유통사 주문 처리 쪽으로 옮겼다 [확인] (https://choco.com/us/stories/product-updates/rebranding-choco).

- 음성사서함·WhatsApp·이메일·문자·사진·손글씨 주문을 받아 주문서로 바꾼다 [확인] (https://choco.com/us/orderagent, https://choco.com/us/choco-ai).
- 검토 화면에서 직원이 품목·단위·배송 정보를 확인한다. Autopilot 모드는 주문마다 거래처 주문 이력과 대조해 「진짜 예외」만 사람 검토로 보내고, 검증을 통과한 주문은 ERP 로 바로 보낸다. 「확신 점수가 낮은 주문」이라는 기준은 페이지에 없다(검증 수정 2026-11-11). 초기 사용자는 주문 50%의 수동 검토를 없앴다고 한다(회사 주장) [확인] (https://choco.com/us/orderagent).
- 유통사 상품·고객 데이터로 학습하고, 주문 데이터로 스스로 학습한다고 쓴다 [확인] (https://choco.com/us/orderagent).
- 정확도는 본문 "최대 97%", FAQ "최대 99%"로 서로 다르다. FAQ 의 99% 는 달성치가 아니라 「목표로 한다(aim for)」는 표현이다(검증 수정 2026-11-11) [확인] (https://choco.com/us/choco-ai).
- VoiceAgent 는 2025-12-04 발표했다. OpenAI Realtime API 로 전화를 직접 받는다. 주문을 받고, 상품 질문에 답하고, 재고를 확인해 대체품을 제안한다. 24시간·다국어다. 보도자료의 「주문 정확도 95%」「수작업 처리 시간 50% 감소」는 VoiceAgent 성과가 아니라 Choco AI 기술 전반의 성과로 적혀 있다. VoiceAgent 자체 정확도는 확인 못 함(검증 수정 2026-11-11) [확인] (https://choco.com/us/press/choco-and-openai-join-forces-to-launch-the-first-ai-voice-agent-for-the-food-service-industry).
- 보안: SOC 2(보안·가용성·기밀성), 운영 인프라는 AWS, DPA 공개 [확인] (https://choco.com/us/security). 고객 데이터를 범용 모델 학습에 쓰는지는 확인 못 함.
- 값: 공개 가격 없음, 데모 요청 [확인] (https://choco.com/us/choco-ai). 제3자는 거래처당 월 $20~25로 추정한다 [추정] (https://gappsy.com/tools/choco/). 경쟁사 BlueCart 블로그도 비슷한 숫자를 쓴다 [추정] (https://www.bluecart.com/blog/choco).

## 6. 우리(부품 대리점 전화 주문)에게 주는 시사점

1. 해외 유통 AI 는 모두 "AI 가 주문 **초안**을 만들고 사람이 확인 버튼을 누른다" 구조다(Choco 검토 화면·Autopilot, Canals 한 번 클릭 제출). 우리 주문 카드도 부장님이 확인·수정하는 **초안**으로 두고, 자신 없는 칸은 "다시 물어볼 것"으로 띄운다.
2. 정확도는 받아쓰기보다 **거래처·품목 매칭**에서 갈린다. Choco 는 유통사 상품·고객 데이터, Comena 는 고객 품번 매칭, Partly 는 VIN 검증을 쓴다. 우리는 거래처 목록, 부품 별칭(현장 말) 사전, 차종·연식·차번호 칸을 먼저 만든다.
3. 부품 플랫폼(PartsTech, Nexpart, RepairLink)은 전화를 화면 주문으로 **바꾸게** 하려 했다. 그래도 북미 지역 상용 주문의 약 80%가 전화라는 업체 발언(2017)이 있고 [검증: 확인 불가], 현대모비스 부품몰 앱도 "대리점에 전화 문의"로 끝난다. 고령 담당자에게는 전화를 없애기보다 **전화를 그대로 두고 기록·정리**하는 쪽이 맞다.
4. 전화를 실시간으로 받아 주문 줄로 바꾸는 사례는 Canals Live Voice(카운터·전화), Autologue AI counterman(부품 매장)처럼 막 나오는 중이다. 국내 부품 대리점용은 확인 못 함 → 빈자리다.
5. 국내 통신사 AI 전화(KT, LG U+)는 월 1만~2만 원대로 예약·기본 응대 중심이다. 부품 품번·차종 같은 전문 말과 "지난 통화에서 몇 개라고 했나" 확인 기능은 보이지 않는다(확인 못 함). 우리 차별점은 **지난 통화 찾기와 사실 확인**이다.
6. 조사한 서비스 중 주문 카드 칸마다 **근거가 된 통화 문장·녹음 위치**를 붙여 보여 주는 곳은 찾지 못했다(Slang 의 녹음·요약 정도). "두 개라고 했다/안 했다"를 원문 문장과 재생 위치로 바로 보여 주면 분쟁 대응 가치가 크다.
7. 데이터 정책을 공개한 곳이 적다. 우리는 데모부터 "녹음 원본은 대리점 PC 에, 서버에는 글자만, AI 학습에 안 씀"을 화면과 문서에 밝힌다. Rossum 처럼 보관 기간을 사용자가 정하게 하면 설득에 도움이 된다.
8. 값 기준점: 해외 식당 전화 AI 매장당 월 $199~599, 식자재 주문 AI 거래처당 월 £10~$25 수준(추정 포함), 국내 통신사 AI 전화 월 9,900원~2만 원. 대리점 1곳 기준 월 요금 가설을 세울 때 참고한다.
