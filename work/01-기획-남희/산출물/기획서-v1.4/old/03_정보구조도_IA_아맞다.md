## 1. 작성 기준

| 항목 | 기준 |
|---|---|
| 범위 | 데모에 구현된 화면과 상용화를 위해 추가 제안하는 화면([산출물 2] 6장)을 함께 실음 |
| Depth 1 | 사이드바의 메뉴 묶음('워크스페이스', '함께 일하는 AI')과 그 밖의 영역(진입, 계정, 설정, 고객 지원, 운영, 공통, 오류) |
| Depth 2 | 메뉴 단위 화면 |
| Depth 3 | 화면 안의 영역·탭 또는 하위 화면·모달. 없으면 `-` |
| 화면 ID | [산출물 2]와 같은 ID를 사용함. `SCR` 화면 · `POP` 모달 · `CMN` 공통 요소 · `ERR` 오류 화면 |
| URL(Path) | **상용 구현 시의 제안 경로**임. 데모는 화면을 바꿔도 URL이 바뀌지 않으므로 현행 위치는 비고에 적음. 모달·공통 요소는 `-` |
| 비고 | `데모 구현`(구현 수준은 괄호 안) 또는 `신규`(관련 요구사항 ID)로 시작함. dev 브랜치 제품 데모(`https://t07.3-39-67-126.sslip.io`)에 같은 화면이 있으면 `제품 데모 #/경로`를 덧붙임 |

**데모의 현행 URL**

| URL | 내용 |
|---|---|
| `/` | 프로토타입 선택(SCR-00) |
| `/callnote/` | 아맞다(가칭 「콜노트」 시점 경로)의 모든 화면(SCR-01~SCR-05). 화면 전환 시 URL 불변 |
| `/api/assistant` | 어시스턴트 응답 API(POST) |

**제품 데모(dev)의 현행 경로** — 해시 라우팅(`#/…`)으로 화면마다 주소가 있음

| 경로 | 화면 |
|---|---|
| `#/` | 오늘 브리핑(첫 화면) |
| `#/calls` · `#/calls/:id` | 통화 기록 · 찾기, 통화 상세 |
| `#/board` · `#/shipping` | 주문 카드 보드, 출고 목록 |
| `#/live` · `#/upload` | 실시간 받아쓰기, 녹음 올리기 |
| `#/ask` · `#/glossary` | 지난 통화에 묻기, 낱말 사전 |
| `#/customers/:name` | 거래처별 모아 보기 |
| `#/trial` · `#/help` · `#/admin` · `#/more` | 무료 체험 신청, 도움말, 관리자, 모바일 더보기 |
| `/intro/` | 소개 페이지(체험 신청 `/intro/#signup`) |

## 2. 메뉴 구조 요약

`*` 표시는 상용화를 위해 새로 제안하는 메뉴·화면이며, 바로 앞의 항목 하나에만 해당함.

```text
아맞다
├─ 계정 *
│  ├─ 로그인 · 회원가입 · 비밀번호 재설정 · 초대 수락
│  └─ 워크스페이스 선택
├─ 워크스페이스
│  ├─ 통화 기록 (기본 화면)
│  │  ├─ 통화 목록 · 통화 이력 검색 *
│  │  ├─ 대화 기록 · AI 요약 · AI 주문 카드
│  │  └─ 실시간 기록 · 녹음 파일 업로드 *
│  ├─ 주문 보드
│  │  └─ 출고 목록 *
│  ├─ 오늘의 브리핑
│  └─ 거래처 *
├─ 함께 일하는 AI
│  ├─ 어시스턴트
│  │  ├─ 재연락 문안 초안
│  │  └─ 지난 통화에 묻기 *
│  └─ 공유 지식
│     ├─ 지식 상세 · 낱말 사전 *
│     └─ 지식 제안·수정
├─ 설정 *
│  └─ 프로필 · 워크스페이스 정보 · 구성원·권한 · 알림 · 화면 · 데이터·개인정보 · 수집·AI
├─ 고객 지원
│  └─ 사용 안내 · 도움말 * · 무료 체험 신청 * · 이용약관 * · 개인정보 처리방침 *
└─ 운영 *
   └─ 운영자 콘솔
```

| 함께 일하는 AI | 7 | 5 | 2 |

※ 항목 수는 3장 표의 행 수(화면, 화면 안의 영역, 모달, 공통 요소 포함)임
