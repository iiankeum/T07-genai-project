# [산출물 3] 아맞다 (Ah-matda) 정보구조도 (IA)

**기준일 2026-11-16** · 1절과 1.1절은 서로 다른 호스트를 사용한다. 2절은 상용화 제안 경로다.

**두 데모의 적용 범위.** [화면 프로토타입](https://t07-product-prototypes.butterybeam16.chatgpt.site/callnote/)은 샘플 대화, 주문 카드 UX, 어시스턴트·공유 지식을 설명한다. [현장 업무 데모](https://t07.3-39-67-126.sslip.io/#/help)는 녹음 수집, 받아쓰기, 근거 청취, 확정과 출고를 설명한다. 두 호스트는 서로 다른 배포본이다.

**서비스 최상위 명칭은 아맞다 (Ah-matda)**다. 표의 URL은 각 화면을 확인할 수 있는 배포 주소다.

지정 데모는 하나의 문서 안에서 뷰를 교체한다. 메뉴·탭·패널·모달의 표시 주소는 모두 `/callnote/`다. ‘URL(Path)’ 열의 반복은 동일 주소에서 다른 UI를 연다는 뜻이다. 아래 각 행은 개발 요청서의 동일 화면 ID에 대응한다. 화면 ID는 데이터베이스 식별자나 API 주소와 독립적이다.
