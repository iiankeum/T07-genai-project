## AI 로 기획 작업할 때 (이 폴더 규칙)
- 조사 결과는 `자료/조사-<주제>.md` 로, 출처 URL 과 [확인] · [기사] · [후기] · [추정] 표시를 붙인다.
- 기획서는 `산출물/기획서-src/` 에서 고치고 `python build.py <버전>` 으로 굽는다. PDF 는 덮어쓰지 않고 버전을 올린다.
- 그림은 `자료/그림/만든법/` 의 방식(캐릭터 시트 → 장면)으로 그린다. 그림에는 글자 · 로고를 넣지 않는다.
- 비공개 자료(대리점 업무 프로그램 등)에서 읽은 것은 업계 일반 흐름으로만 옮긴다.
