# 총괄(배\*결) 날짜별 기록

총괄 · 서버 · 음성 인식 · 녹음 수집을 맡은 배\*결(dmms0830-lang)이 날마다 무엇을 했고 무엇을 정했는지, AI 가 무엇을 했는지를 날짜 하나에 문서 하나로 모았다.

- 날마다 **사람이 한 것 · 정한 것**과 **AI 가 한 것**을 나눠 적었다. 이 과목의 주제가 사람과 AI 의 협업이라서다.
- 날마다 그날 배\*결 계정으로 올라간 **커밋 전체**와 그 커밋이 지금 어느 가지에 있는지를 붙였다. 커밋 번호를 누르면 깃허브에서 바로 열린다.
- 모든 줄은 저장소에 이미 있는 회의록 · 작업 기록 · PR · 커밋에서 옮겼다. 사람이 말로 정한 것은 그날의 작업 기록에 남은 것만 적었다.
- 공개 저장소라 실제 녹음 · 받아쓴 글 · 전화번호 · 거래처 이름은 없다. 실제 녹음은 숫자로만 남겼다.
