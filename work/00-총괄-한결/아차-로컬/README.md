# 아차(로컬) — 단어장 끼운 오프라인 받아쓰기 프로그램을 만든 기록

녹음(회의 · 수업 · 전화)을 **인터넷 없이 PC 안에서** 받아쓰고, **내 단어장**으로 고유명사 · 전문 용어 · 현장말을 바르게 적는 Windows 프로그램 「아차(로컬)」 v0.1 을 만든 방의 기록이다. 2026-11-25 밤(21:04 ~ 22:20)에 했다.

배\*결이 회의 · 수업 받아쓰기 앱 Alt(altalt.io)를 보고 「우리도 단어집을 끼워 AI 로 전사하는 오프라인 프로그램을 만들어, 사람들이 쓰고 원리를 갖다 쓸 수 있게 깃허브에 설치 프로그램을 올리자. 아차는 그것을 적용한 사례가 된다」고 해서 시작했다.

**결론**: 프로그램과 설치 파일을 만들어 팀 저장소에 올렸다. 가짜 녹음 두 개에서 단어장을 끼우니 글자 오류율이 9.4% → 5.1%(부품 주문 전화), 2.3% → 0.0%(AI 수업)로 내려갔다. 그 과정에서 **지금 아차가 사전 힌트를 통화 첫 30초에만 쓰고 있다**는 것을 찾았다. 실제 녹음으로는 아직 재지 않았다.
