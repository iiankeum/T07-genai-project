**AI**
- 웹 읽기 에이전트 1개로 Alt 사이트(첫 화면 · 기능 · 요금)를 읽었다. 단어장 · 사용자 사전 기능은 사이트에서 찾지 못했다([원리-조사.md](원리-조사.md) 1절).

- 받아쓰기 엔진(faster-whisper 1.2.1) 원본을 읽고 토크나이저로 재 보니, 그 힌트가 **통화 첫 30초에만** 쓰이고 **낱말 40개 안팎**만 들어간다는 것을 찾았다. 11/24 실제 녹음 시험은 사전이 빈 채로 돌았다는 것도 다시 확인했다.
- 「아차에서 이걸 세게 만들까, 새 제품으로 구상할까」를 물었다.

## 5. 설치본 시험 (21:45 ~ 22:08)

**사람** (22:00 무렵) 「몇 분 정도 작업이 남았지?」 → AI 가 「20 ~ 25분, 남은 것은 시험 두 개 · CPU 속도 손보기 · 올리기」라고 답했다.

**AI**
- 설치 파일(68MB)을 만들어 시험 폴더에 조용히 깔고 돌렸다(21:45).
- **CPU 로 너무 느림**: 첫 문장도 7분 넘게 안 나왔다. 시험 여러 개가 겹친 데다 CPU 일꾼을 논리 코어 수(11개)만큼 잡은 탓이었다. 혼자 재니 30초 녹음에 10.5초. 일꾼 수를 실제 코어 수로 줄이고, CPU 로 10분 넘는 녹음은 두 번 듣지 않게 했다.
- **GPU 가속 받기**: 설치본에서 눌러 NVIDIA 파일 1,264MB 를 받았다(21:57 ~ 21:59). 그런데 이미 CPU 로 연 프로그램 안에서 그래픽 카드로 다시 열다가 **멈췄다**. 새로 켜니 바로 그래픽 카드로 열려서, 받은 뒤에는 「닫았다가 다시 여세요」라고 안내하게 바꿨다.
- 다시 만든 설치본으로: GPU 에서 83초 전화 4.3초, 그래픽 카드 파일을 숨기고 CPU 만으로 72초 강의 88.7초. 둘 다 끝까지 돌았다.
