# 정한 것 — 아차(로컬) v0.1

[안내](README.md) · 「누가」가 **사람**이면 배\*결이 대화에서 정한 것, **AI** 이면 AI 가 판단해서 고르고 알린 것이다. AI 가 고른 것은 바꿔도 된다.

## 사람이 정한 것

| 정한 것 | 내용 | 비고 |
|---|---|---|
| 무엇을 만드나 | 사람들이 쓸 수 있는 **오프라인** 받아쓰기 프로그램 + **단어장**. 아차는 그 원리를 브랜딩해 실제로 적용한 **사례** | AI 는 처음에 「아차 안에서 세게 만들기」를 권했다 |
| 어떻게 내놓나 | 깃허브에 **설치 프로그램**을 올려 사람들이 쓰고, 원리도 갖다 쓰게 | |
| 이름 | **「아차(로컬)」** | AI 선택지(「단어장 받아쓰기」 · 「나중에」)에 없던 답을 직접 적었다 |
| 올릴 곳 | **팀 저장소(T07) 안** | AI 는 개인 계정 새 공개 저장소를 권했다. 팀 저장소는 주인이 팀원이라 팀 확인이 필요하다고 함께 적었다 |
| 설치 파일 도구 | Inno Setup 을 깔아도 됨 | 이미 깔려 있어서 새로 깐 것은 없다 |
| 라이선스 | MIT(누구나 쓰고 고칠 수 있음) | AI 가 「올릴 곳」 질문 설명에 적었고 그대로 진행했다 |

## AI 가 고른 것

| 고른 것 | 왜 | 바꾸려면 |
|---|---|---|
| Windows 먼저 | 배\*결 PC · 대리점 PC 가 Windows. Alt 도 Windows 판이 있다 | 맥은 팀에 `src/mac-app`(아차 전용)이 따로 있다 |
| 엔진 faster-whisper(Whisper) | 아차 일꾼과 같은 엔진이라 비교 · 이식이 쉽다. PC 안에서 돈다 | |
| 기본 모델 `large-v3-turbo` | 가짜 녹음에서 `large-v3` 와 정확도가 비슷하고 3배쯤 빠르다 | 설정에서 `small` · `large-v3` 로 바꿀 수 있다 |
| 단어장 힌트를 `hotwords` 로 30초마다 | `initial_prompt` 는 첫 30초에만 들어간다([원리-조사.md](원리-조사.md) 2절) | |
| 힌트는 223 토큰 안에서 「항상 → 많이 쓰인 낱말 → 단어장 순서」로 | 넘치면 엔진이 잘라 버린다 | 「항상」 칸으로 사람이 순서를 바꾼다 |
| 단어장이 크면 두 번 듣기(CPU 로 10분 넘는 녹음은 안 함) | 거래처가 많아도 그 녹음에 나온 낱말이 자리를 얻게. 시간은 2배 | |
| 받아쓴 뒤 고치기는 규칙과 소리 비교만(AI 안 씀) | 인터넷 없이 · 왜 고쳤는지 설명할 수 있게. 2 ~ 3글자 낱말은 자동으로 안 고치고 제안만 | |
| 사람이 고친 말을 단어장이 배움 | 같은 실수를 다음부터 바로 고친다 | |
| 화면은 Edge 의 주소창 없는 창 | Windows 에 늘 깔려 있어 설치본이 작다(68MB) | |
| PC 안(127.0.0.1)에서만 열리고 실행마다 비밀 표 | 같은 PC 의 다른 웹페이지가 녹음 · 단어장을 못 건드리게 | |
| NVIDIA 가속 파일은 설치본에 넣지 않고 「GPU 가속 받기」로 PyPI 공식 배포본을 받게 | 넣으면 설치본이 1GB 넘고 NVIDIA 파일을 우리가 다시 배포하게 된다 | |
| GPU 파일을 받은 뒤에는 다시 열라고 안내 | 같은 프로그램 안에서 바로 바꾸면 멈췄다([시험-기록.md](시험-기록.md) 4절) | |
| 아차 아이콘 · 색 | 이름을 「아차(로컬)」로 정해서 같은 모양을 썼다 | |
| 코드는 `src/acha-local/`, `dev` 에서 딴 가지 → `dev` 로 PR, 합치지 않음 | AGENTS.md: 코드는 가지 + PR, 7번 제품 코드는 `dev` | |
| 설치 파일은 pre-release | 팀 확인 전이고 실제 녹음으로 재지 않아서 | 확인 뒤 정식 Release 로 바꾼다 |
| 시험 녹음은 합성 목소리 · 지어낸 내용, 파일 이름에 「가짜」 | 공개 저장소 규칙. 정답 글을 알아야 오류율을 잴 수 있다 | |
| 이 이력은 `main` 의 총괄 폴더에 | AGENTS.md: `work/` 문서는 `main` 에 바로 올려도 된다 | |
