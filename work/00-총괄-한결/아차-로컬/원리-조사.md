# 원리 조사 — 단어장이 받아쓰기에 어떻게 들어가나

[안내](README.md)

## 1. Alt(altalt.io) — 배\*결이 보여 준 앱

웹 읽기 에이전트 1개가 첫 화면 · 기능 · 요금 쪽을 읽었다(2026-11-25). 사람이 확인하지 않았다.

- 회의 · 수업을 받아쓰고 요약하는 노트 앱. 말한 사람 나누기 · 실시간 번역 · PDF 요약 · 파일 올려 받아쓰기.
- 받아쓰기는 「자체 개발 엔진」이라고만 적혀 있다. Apple Silicon Mac 과 Windows PC 에서는 PC 안에서 돈다고 한다.
- 요금: 무료(PC 안 받아쓰기 · 요약 무제한이라고 함) · Pro 월 7달러 · 학생 · 기업.
- **단어장 · 사용자 사전 · 키워드 기능은 사이트에서 찾지 못했다.** 이용 가이드(Notion)는 내용이 읽히지 않았다.

AI 의 해석: 일반 회의 노트로 맞붙기는 어렵다. 업종 단어장이 쓰면서 자라는 것이 차별점이 될 수 있다.

## 2. 받아쓰기 엔진(faster-whisper 1.2.1)이 힌트를 다루는 법

엔진 원본 `faster_whisper/transcribe.py` 를 읽어 확인했다(줄 번호는 1.2.1 기준).

| 확인한 것 | 원본 | 뜻 |
|---|---|---|
| 힌트 자리 | 1546 ~ 1550행: `hotwords` 는 `max_length // 2 - 1` 토큰까지, 앞선 글(`initial_prompt` 포함)은 뒤에서 `max_length // 2 - 1` 토큰까지만 | `max_length` 는 448 → **223 토큰**. 넘치면 잘린다 |
| `initial_prompt` 가 쓰이는 때 | 1141 · 1187 · 1383행: `condition_on_previous_text=False` 면 창 하나를 끝낼 때마다 `prompt_reset_since = len(all_tokens)` | `initial_prompt` 는 **첫 30초 창에만** 들어간다 |
| `hotwords` 가 쓰이는 때 | 1532행 `get_prompt`: 창마다 프롬프트를 만들 때 `hotwords` 를 넣는다(`prefix` 가 없을 때) | **30초 창마다** 다시 들어간다 |
| 소리 파일 풀기 | `audio.py` `decode_audio` 가 `av.open(..., metadata_errors="ignore")` | PyAV 19 에서 이 인자가 없어져 깨진다 → 아차(로컬)은 직접 푼다 |

## 3. 지금 아차가 사전을 쓰는 모습 (`dev` 가지 · v1.6)

| 어디 | 하는 일 |
|---|---|
| `src/app/lib/repo.mjs` `dictionaryForAi` | 승인된 「현장말」을 `sttContext`(「자동차 부품 대리점 주문 전화입니다.」) 뒤에 이어 붙여 **600글자로 자른** `initialPrompt` 를 만든다 |
| `src/app/routes/worker.mjs` | 일감을 줄 때 `initialPrompt` 를 일꾼에게 넘긴다 |
| `src/pc-agent/callnote_agent.py` `transcribe_with_vad_guard` | `initial_prompt=…` · `condition_on_previous_text=False` 로 받아쓴다 |
| `src/app/lib/ai.mjs` `dictionaryBlock` | 카드를 만들 때 AI 에게 사전(현장말 · 거래처 · 차종)을 참고 자료로 준다 |

여기서 나오는 것(AI 의 해석 · 아직 아차에서 재지 않음):

1. 일꾼 설정상 사전 힌트는 **통화 첫 30초에만** 쓰인다. 11/24 실제 녹음 200건은 평균 81초였다.
2. 600글자를 보내지만 엔진에는 **223 토큰(낱말 40개 안팎)** 만 들어가고, 잘릴 때 **앞(설명 문장)부터** 사라진다.
3. 11/24 실제 녹음 시험은 새 작업공간이라 사전이 0개였다. 사전을 넣은 상태로는 잰 적이 없다.

→ 아차에 옮길 것: 일꾼을 `hotwords` 로, 서버가 223 토큰 안에서 고르기, 전화번호로 거래처를 알면 그 상호 · 자주 시키는 부품을 먼저. (새 작업 카드로 제안해 둠 · 시작 안 함)

## 4. 힌트 자리 재기

Whisper large-v3 토크나이저로 누구나 쓰는 부품 · 차종 이름 56개를 이어 재 봤다([결과-숫자/힌트-자리-재기.txt](결과-숫자/힌트-자리-재기.txt)).

| 잰 것 | 값 |
|---|---|
| 설명 문장 + 낱말 56개 | 324글자 · **306 토큰** |
| 223 토큰 안에 들어간 낱말 | **38개**(231글자) |
| 설명 문장만 | 17 토큰 |

한국어는 거의 **한 글자가 한 토큰**이다. 그래서 단어장이 크면 무엇을 먼저 넣을지 고르는 것이 중요하다 — 아차(로컬)은 「항상 → 많이 쓰인 낱말 → 단어장 순서」로 고르고, 그래도 넘치면 두 번 듣는다.
