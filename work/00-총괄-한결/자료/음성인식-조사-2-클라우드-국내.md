# 한국어 전화 받아쓰기용 음성 인식(STT) 서비스 비교 — 클라우드 · 국내

> AI 초안 · 돌린 사람: 배*결 · Claude Code(Opus 5.5) 조사 에이전트 1개 · 한결(총괄·서버) 작업방 · 조사일 2026-11-11 · 검토: 아직 없음
>
> - 대상: 자동차 부품 대리점 주문 전화, 8kHz 협대역 녹음, 한국어.
> - 가격 · 기능은 2026-11-11 에 각 공식 페이지에서 확인했다. 가격은 자주 바뀐다. 계약 전에 다시 본다.
> - 「확인 못 함」은 공식 자료에서 찾지 못했다는 뜻이다. 기능이 없다는 뜻이 아니다.
> - 가격은 통화 단위를 바꾸지 않고 원문 그대로 적었다. 원화 가격은 부가세 별도다.

## 1. 다섯 줄 요약

1. 한국어 정확도의 공개 근거는 리턴제로가 직접 잰 벤치마크 하나뿐이다(2025-02 측정). 콜센터 · 저음질 전화 음성 CER 은 RTZR 3.5~4.4%, CLOVA 4.9~6.5%, AWS 7.6~7.8%, Azure 7.8~9.9%, Google · Whisper 8~17%, Deepgram(nova-2) 21~30% 순이다. 이해당사자 측정이고 최신 모델(Chirp 3 · gpt-transcribe · Scribe v3 · Nova-3)은 빠져 있다.
2. 국내 처리와 학습 미사용이 문서로 확인되는 곳은 RTZR(AWS 서울, 학습에 쓰지 않음, 배치 원본 즉시 삭제)과 Azure Korea Central(리전 안 처리, 실시간 · Fast 는 보관 안 함)이다. AWS 서울은 학습 거부(opt-out) 정책을 따로 걸어야 한다. CLOVA 는 한국 리전이지만 학습 사용 조항은 찾지 못했다.
3. 8kHz 처리에서 큰 차이가 있다. CLOVA Speech 는 전화망 코덱(G.711 등)을 지원하지 않아 16kHz PCM 으로 바꿔 넣어야 한다. RTZR 스트리밍 · AWS · Azure · Google telephony 모델은 8kHz 를 바로 받는다.
4. 현장말 사전(「휀다 · 쇼바 · 라지에다」)은 대부분 된다. CLOVA 의 「출력표기|발음」 치환(최대 1,000개)과 AWS 표 형식 커스텀 어휘(DisplayAs)는 표기 통일까지 된다. Azure 는 문장을 넣어 학습시키는 Custom Speech 가 있다.
5. 값은 해외 배치가 시간당 $0.10~0.96, 국내가 1,000~1,680원 수준이다. 월 50시간이면 어느 쪽도 큰돈이 아니다. 동의받은(또는 가짜) 실제 통화 20~30건으로 RTZR · CLOVA · AWS 서울(또는 Azure)을 직접 비교해 고르는 것이 맞다.

## 3. 정확도 근거 — 공개 벤치마크

정확도를 서비스끼리 같은 조건으로 비교한 공개 자료는 리턴제로(RTZR)가 운영하는 저장소 하나만 찾았다(B1).

읽을 때 주의할 점:

- 측정 주체가 경쟁 서비스 하나(리턴제로)다. 자사에 유리할 수 있다.
- 측정 시점은 커밋 기록상 2025-02 다(「25년 2월 측정」). Azure · AWS · Deepgram 결과는 2025-08 에 추가됐다(B2).
- 데이터셋마다 3,000문장을 뽑아 쟀다. 모두 AI-Hub 공개 데이터다.
- 최신 모델이 빠져 있다. Google Chirp 3, OpenAI gpt-transcribe, ElevenLabs Scribe v3, Deepgram Nova-3 는 없다. 「OpenAI Whisper」와 「Google API v2」는 어떤 모델 · 버전인지 표에 없다.
- 자동차 부품 용어가 거의 없는 데이터다. 우리 통화에서는 순위가 달라질 수 있다.

그 밖의 공식 수치:

- ElevenLabs 는 한국어를 「Good」 등급(WER 10% 초과 20% 이하, Scribe v2 기준)으로 표시한다(E2).
- Soniox 는 한국어 CER 4.3% 를 내세우지만 데이터셋 · 날짜를 밝히지 않는다(S2).
- 카카오엔터프라이즈는 2022년 커스텀 STT 가 「내부 실험에서 오류율 30% 이상 개선」이라고 밝혔다. 현재 판매 여부는 확인 못 함(K2).
- 그 밖의 서비스는 한국어 전화 음성 공식 수치를 확인 못 함.

## 4. 서비스별 상세

### 4.1 네이버 클라우드 CLOVA Speech

- **한국어**: 단문 · 장문 · 스트리밍 모두 한국어를 지원한다. 장문은 한 · 영 동시 인식(`enko`)도 된다(N2).
- **길이 · 크기**: 장문 최대 2시간(sync), 6시간(Batch · async), 최대 2GB(N2).
- **가격**(N1, 2026-11-11 요금 탭 확인, VAT 별도, 15초 단위 올림):

  | 유형 | 플랜 | 서비스 | 단위 | 요금 |
  |---|---|---|---|---|
  | 단문 | Basic | 음성 인식 | 15초 | 4원 |
  | 장문 | Free | 음성 · 화자 · 이벤트 | 15초 | 무료(매월 20분, 계정당 도메인 1개) |
  | 장문 | Basic | 음성 인식 | 15초 | 5원 |
  | 장문 | Basic | 화자 인식 | 15초 | 2원 |
  | 장문 | Basic | 이벤트 탐지 | 15초 | 2원 |
  | 스트리밍 | Basic | 음성 인식 | 15초 | 5원 |

  - 시간당으로 바꾸면 장문 1,200원, 화자 인식까지 켜면 1,680원이다(계산값).
  - 공식 예시: 10초 이용 시 5원, 32초 이용 시 15원(화자 · 이벤트 미사용).
- **커스텀 단어**(N3): `boostings` 로 키워드를 넣는다.
  - 최대 1,000개, 500개 이하 권장. 한글 · 영어만 된다.
  - 가중치 1~5(소수 가능).
  - `출력 표기|발음` 형식이면 발음된 말을 출력 표기로 바꿔 준다. 예: `펜더|휀다` 처럼 쓰면 「휀다」를 「펜더」로 적게 할 수 있다(형식은 문서 기준, 실제 동작은 시험 필요).
  - **1음절 단어는 부스팅되지 않는다.**
  - `forbiddens` 로 결과에서 숨길 말도 지정한다.
  - 스트리밍 도메인당 부스팅 · 금지어 설정 한도가 1개에서 30개로 늘었다(2026-07-23, N4).
- **화자 분리**: 장문에서 지원한다. 구분 한도가 10명에서 30명으로 늘었다(2026-09-17, N4).
- **전화 음질 — 주의**: 제품 페이지는 「전화망 음성(PSTN)에서도 높은 성능」이라고 쓴다. 그러나 같은 페이지 사양표에 다음 주석이 있다(N1).
  - 「전화망(협대역) 코덱은 지원하지 않습니다」
  - 대상: G.711(A-law/μ-law), G.723.1, G.729, GSM 6.10, AMR-NB/AMR-WB, ADPCM 계열.
  - 이런 음원은 WAV 로 감싸도 결과가 비어 있을 수 있다. PCM 16bit / 16kHz / mono WAV 나 MP3(128kbps 이상)로 바꿔 넣으라고 한다.
  - 스트리밍 입력은 16kHz 16bit mono PCM 만 받는다.
  - 즉 8kHz 통화 녹음은 **16kHz PCM 으로 다시 샘플링해서** 넣어야 한다. 이 변환이 정확도에 주는 영향은 직접 재야 한다.
- **실시간**: gRPC 스트리밍. 2025-11-20 에 Streaming 2.0 을 냈다(N4).
- **데이터 위치 · 학습**:
  - 리전은 한국이다(N2).
  - 공식 FAQ: 「네이버 클라우드 플랫폼에서는 고객사의 데이터로 접근하지 않습니다」(N5).
  - 고객 음성을 모델 학습에 쓰는지 정한 조항은 **확인 못 함**. FAQ 는 「CLOVA Speech 서비스 이용 약관」을 보라고만 한다.
  - 인식할 파일과 결과는 고객의 Object Storage 버킷에 둔다(도메인 생성 시 지정).

### 4.2 CLOVA Speech Recognition(CSR)

- 상품 페이지 공지: 「이제 CSR 의 기능을 CLOVA Speech 에서 제공합니다」(N6).
- 한 번에 60초까지만 인식한다. 4원/15초(10초 4원, 32초 12원, 65초는 60초까지만 인식하고 16원).
- 월 이용 한도는 앱당 30만~3,000만 초 범위에서 조정한다.
- 통화 전체 받아쓰기에는 맞지 않는다. 신규 도입 대상에서 뺀다.

### 4.3 리턴제로 RTZR STT (구 VITO)

- **한국어**: 모델 `sommers`(기본, 한국어 · 일본어), `whisper`(다국어, 한국어 강화)(R2, R3).
- **가격**(R1, VAT 별도, 월 사용량 누진):

  | 구간 | 월 사용량 | 시간당 |
  |---|---|---|
  | T1 | 0~1,000시간 | 1,000원 |
  | T2 | 1,000~10,000시간 | 500원 |
  | T3 | 10,000~25,000시간 | 400원(사전 문의) |

  - 가입 시 600분(10시간)을 준다. 다시 채워지지 않는다(R5).
- **커스텀 단어**:
  - 파일 STT: `keywords` 에 단어 배열을 넣는다. 개수 · 형식 제한은 문서에 없다(R2).

- **전화 음질**: 스트리밍이 8,000~48,000Hz 를 받고 MULAW · ALAW · AMR 인코딩을 지원한다(R3). 파일 STT 는 mp4 · m4a · mp3 · amr · flac · wav 를 받는다. 최대 2GB · 4시간(R2).
- **실시간**: gRPC · WebSocket(R3).
- **데이터 위치 · 학습**(개인정보 처리방침, 공고 · 시행 2026-11-09, R4):
  - 「회사는 고객이 OpenAPI 를 통해 전송한 음성 데이터, 전사 결과 … 를 회사의 AI 모델 학습 또는 성능 개선 목적으로 사용하지 않습니다」.
  - 실시간: 음성 · 결과를 따로 보관하지 않는다.
  - 배치: 원본 음성은 인식이 끝나면 바로 삭제한다. 결과는 **AWS 서울 리전**에 최대 3일 두고 자동 삭제한다.
  - API 호출 로그(요청 ID · 상태 · 오류)는 1년 보관한다.
  - 요약 · 전사 정제 같은 생성형 AI 부가 기능을 켜면 데이터가 미국 등 국외(Anthropic, Google Vertex AI)로 갈 수 있다. 기본 STT 만 쓰면 국외 이전이 없다.
  - 고객이 개인정보를 보내면 리턴제로는 수탁자 지위다. 필요하면 위수탁계약을 맺으라고 약관이 적는다(R6).

## 6. 우리 용도에서 따질 점

### 6.1 8kHz 녹음 넣는 방법

| 서비스 | 8kHz 처리 |
|---|---|
| CLOVA Speech | 그대로 못 넣는다. G.711 등 전화 코덱은 결과가 빌 수 있다. 16kHz · 16bit · mono PCM WAV 로 바꿔야 한다 |
| RTZR | 스트리밍은 8kHz · μ-law · A-law 를 바로 받는다. 파일 STT 의 8kHz 안내는 확인 못 함(형식 목록에 AMR · WAV 있음) |
| AWS | 8,000Hz 명시 지원 |
| Azure | 8kHz 16bit mono PCM 스트림 지원 |
| Google | telephony 모델. 8kHz 를 리샘플링하지 말고 보내라고 권장 |
| OpenAI · ElevenLabs · Deepgram · Soniox | 공식 안내 확인 못 함 |

### 6.2 화자 분리와 채널

- 녹음이 좌 · 우 채널로 나뉘어 있으면(대리점 / 손님) 화자 분리보다 채널 분리가 정확하다.
- 단 채널마다 따로 과금하는 곳이 많다. Google · RTZR · Deepgram 은 채널 길이를 더해 과금한다고 명시한다.
- 한 채널(mono)이면 화자 분리가 필요하다. CLOVA 는 화자 인식에 15초당 2원을 더 받는다.

### 6.3 현장말 사전

- 「휀다 · 쇼바 · 라지에다」처럼 표준어와 다른 말은 두 가지로 다룬다.
  - **인식 돕기**: 말한 그대로를 잘 알아듣게 한다(부스팅 · keyterm · phrase list).
  - **표기 통일**: 들은 말을 정해진 품목명으로 바꾼다. CLOVA 의 `출력표기|발음`, AWS 커스텀 어휘의 `DisplayAs` 가 여기에 해당한다. 나머지 서비스는 받아쓴 뒤 우리 쪽에서 사전으로 바꾸면 된다.
- CLOVA 는 1음절 단어를 부스팅하지 않는다. 짧은 품목 약어는 시험해 봐야 한다.
- AWS 는 어휘 파일에 개인정보를 넣지 말라고 한다. 거래처 이름을 사전에 넣을 때 주의한다.

### 6.4 개인정보

- 통화 녹음에는 이름 · 전화번호 · 차번호가 들어간다. 받아쓰기 업체는 개인정보 처리 수탁자가 된다.
- 국내 처리가 문서로 확인되는 곳: RTZR(AWS 서울), AWS(서울 리전, opt-out 필요), Azure(Korea Central), CLOVA(한국 리전).
- 해외 처리: Google(한국어는 서울 리전 없음), OpenAI(처리 US · EU), ElevenLabs(기본 미국), Deepgram(한국 리전 없음). 국외 이전 고지 · 동의 검토가 필요하다.
- 학습 사용:
  - 쓰지 않음이 기본: RTZR(명시), OpenAI API(기본값), Google(데이터 로깅 꺼짐이 기본), Azure(실시간 · Fast 비보관).
  - 거부 설정이 필요: AWS(opt-out 정책), ElevenLabs(Data use 메뉴), Deepgram(`mip_opt_out`).
  - 확인 못 함: CLOVA Speech.

### 6.5 다음 할 일

1. 동의받은 실제 통화(또는 가짜로 녹음한 통화) 20~30건과 사람이 쓴 정답 원고를 준비한다. 공개 저장소에는 올리지 않는다.
2. 후보 3곳 이상(RTZR, CLOVA Speech, AWS 서울 또는 Azure Korea Central)에 같은 파일을 넣는다. 무료 제공량 안에서 된다(RTZR 600분, CLOVA 월 20분, AWS 월 60분, Azure 실시간 월 5시간).
3. 전체 CER 과 함께 **품목명 · 수량 · 차종을 맞혔는지**를 따로 센다. 주문 받아쓰기에서는 이쪽이 더 중요하다.
4. 현장말 사전 50~100개를 만들어 사전 있음 / 없음을 비교한다.
5. 고른 업체와 개인정보 위수탁 조건(보관 기간, 학습 미사용)을 문서로 받는다.
