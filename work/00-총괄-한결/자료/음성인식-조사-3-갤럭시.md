> 쓰려는 상황: 대리점 직원이 갤럭시 폰으로 받는 주문 전화를 글로 옮기고, 글이나 녹음 파일을 PC/서버로 옮겨 주문 카드로 정리한다.
> 읽는 법: 문장 끝 `[번호]` 는 맨 아래 출처 목록 번호다. 출처를 못 찾은 것은 「확인 못 함」이라 적는다. 커뮤니티 글은 사용자 보고일 뿐 공식 사실이 아니다. 「AI 판단」은 출처가 아니라 이 문서를 쓴 AI 의 의견이다.

## 1. 기종 · One UI · 한국어 · 처리 위치 · 유료화

### 1-1. 기능과 흐름

- 삼성 전화 앱으로 통화를 녹음하면 「텍스트 변환 어시스트(Transcript assist)」가 글로 옮긴다. 요약 · 번역도 된다 [1].
- One UI 6.1(2024) 때는 통화 녹음 받아쓰기를 음성 녹음 앱에서만 했다. 전화 앱에서 바로 볼 수 없다는 불만에 삼성 담당자가 「유관 부서에 전달하여 개선을 검토」라고 답했다(2024-04) [16].
- One UI 7 베타(2024-12, S24, 한국 포함 6개국)부터 통화 내용을 글로 옮기는 기능이 들어갔다. 켜 두면 녹음이 자동으로 글이 된다 [13].
- 한국 화면 기준 설정 경로: 전화 앱 → 더보기 → 설정 → 통화 녹음 → 텍스트 변환 어시스트 → 「통화 녹음을 텍스트로 자동 변환」 켜기 [14]. 삼성 모더레이터도 같은 옵션 이름으로 안내했다 [15].
- 보는 곳: 최근 기록 → 녹음된 통화 → 「통화 녹음 및 텍스트 보기」 [14]. 화자를 문자 대화처럼 나눠 보여준다 [14].
- 미국 안내의 설정 항목: Summarize transcripts, Process data only on the device(선택), Auto detect language, Auto transcribe recorded calls, Transcription language 와 언어 팩 다운로드 [1].
- 자동 변환은 새 통화부터 적용된다는 사용자 답이 있다. 예전 녹음은 하나씩 변환해야 한다(검색 요약으로만 확인) [14].

### 1-2. 지원 기종 · One UI

- 미국 공식: 통화 녹음과 텍스트 변환 어시스트 통합은 Android 15 · One UI 7 이상이다 [1].
- 미국 공식: Galaxy A56 5G, A36 5G, A26 5G, A17 5G 는 통화 받아쓰기 · 요약을 쓸 수 없다 [1].
- 한국 공식 Galaxy AI 페이지: 「Galaxy AI는 S24 시리즈 이후 출시된 스마트폰부터 지원됩니다.」 [3]
- One UI 6.1 로 S23 시리즈 · S23 FE · Z 폴드5 · Z 플립5 · 탭 S9 에 Galaxy AI 가 들어왔다(국내 2024-03-28부터 순차, 검색 요약으로만 확인) [12].
- One UI 6.1 로 S22 시리즈 · Z 폴드4 · Z 플립4 · 탭 S8 에도 Transcript Assist 가 들어왔다(2024-05부터) [11].
- 그러나 S22 울트라 사용자가 One UI 7 이후에도 전화 앱에 텍스트 변환 어시스트 메뉴가 없다고 물었고 답은 없다(2025-06) [17]. S22 계열의 전화 앱 받아쓰기 지원은 확인 못 함.
- 한국 공식 각주: 「텍스트 변환 어시스트 기능은 사전 설치된 삼성 전화 앱 및 삼성 노트, 삼성 통역 앱을 사용하여 녹음된 파일에서만 사용 가능합니다.」 오디오는 3시간 이내만 처리한다 [3].
- 외부 전화 앱에서는 설정할 수 없다 [14].
- One UI 9 정식판은 2026-09 한국부터 S26 · S25 · 폴드7 · 플립7 에 배포 중이라는 보도가 있다(검색 요약으로만 확인) [45]. One UI 9 에서 통화 받아쓰기 흐름이 바뀌었는지는 확인 못 함.

### 1-3. 한국어

- 한국 공식 각주: 「통화 지원(예: 실시간 번역), 메모 지원, 통역, 텍스트 변환 지원 언어: 한국어, 영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어 …」 모두 22개 언어 [3].
- 미국 공식 받아쓰기 언어 목록에도 Korean 이 있다 [1].
- 언어 자동 감지 때문에 한국어 통화가 영어로 옮겨진 사례가 있다. 「다시 변환」에서 한국어를 고르라는 답이 있다(검색 요약으로만 확인) [20].
- AI 판단: 대리점 폰은 자동 감지를 끄고 받아쓰기 언어를 한국어로 고정하는 편이 낫다.

### 1-4. 처리 위치(온디바이스인가)

- 한국 공식: 「텍스트 변환 및 요약 기능은 네트워크 연결 및 삼성 계정 로그인이 필요합니다.」 [3]
- 한국 공식: 「Galaxy AI 데이터를 기기 내에서 처리할지 클라우드에서 처리할지 선택할 수 있습니다.」 [3]
- 미국 공식: 받아쓰기 · 요약에는 삼성 계정 로그인과 인터넷 연결이 필요하다. 「Process data only on the device」 스위치는 선택해서 켠다 [1].
- 삼성 담당자 답(2024-02, S24): 「S24 음성녹음 앱에서는 최대 3시간까지 음성 녹음 및 텍스트 변환(On device)을 제공하고 있습니다.」 [19]
- SamMobile(2026-07-10): 음성 녹음 앱의 받아쓰기는 지금 기기 안 AI 로만 만든다. 요약만 클라우드를 쓴다(기기 처리 선택 가능) [24].
- SamMobile(2025-09, One UI 7 · S24+): 설정 → Galaxy AI → Process data only on device 를 켜도 Transcript Assist 는 기능 전부를 쓸 수 있다 [26]. 한국어 메뉴 이름은 확인 못 함.
- 2026-07 보도: 녹음을 삼성 서버로 올려 받아쓰는 「클라우드 받아쓰기」 옵션을 시험 중이다. 누설 기반이고 정식 출시는 확인 못 함 [24][25].
- 정리: 받아쓰기는 기기 안, 요약은 기본이 서버다. 고객 통화를 삼성 서버로 보내지 않으려면 「기기에서만 처리」를 켠다. 비행기 모드에서 받아쓰기가 되는지는 실기기로 확인해야 한다.

### 1-5. 유료화

- 2024-01 S24 각주: 「Galaxy AI features will be provided for free until the end of 2025 on supported Samsung Galaxy devices.」 [27]
- 2025-07 Unpacked: 기본 제공(provided by default) Galaxy AI 기능은 유료화 계획이 없다고 밝혔다 [28].
- 지금 한국 공식 페이지: 「삼성 갤럭시 기기의 Galaxy AI 기본 기능들은 무료로 제공되나, 향후 출시되는 향상된 기능이나 새로운 서비스는 유료로 제공될 수 있습니다.」 무상 기간 문구는 없다 [3].
- 미국 공식: 기본 기능은 삼성 서비스 약관의 「Advanced intelligence」 항목에 나열된 것이다 [1]. 그 목록에 통화 받아쓰기가 있는지는 확인 못 함.
- SamMobile 단독(2026-11-09): 유료 Galaxy AI 요금제를 준비 중이고 「All existing Galaxy AI features will remain free」라고 보도했다. 번역 · 요약 · 이미지 생성에 하루 한도(무료 요약 하루 5회 등)를 두는 구조도 보도됐다 [29]. 통화 요약이 이 한도에 들어가는지는 확인 못 함.
- AI 판단: 주문 전화가 하루 수십 건이면 요약 한도가 걸릴 수 있다. 주문 카드 정리를 갤럭시 AI 요약에 기대지 않는 편이 안전하다.

## 2. 변환된 글을 밖으로 꺼내기

### 2-1. 공식 방법(모두 수동)

| 어디서 | 방법 | 결과 | 출처 |
|---|---|---|---|
| 전화 앱 | 받아쓴 글을 길게 눌러 선택 → 복사 → 다른 앱에 붙여넣기. 요약도 같은 방법 | 클립보드 글 | [1] |
| 음성 녹음 앱 | 받아쓰기 탭에서 선택 → 공유 → 음성 파일 / 텍스트 파일 / 음성과 텍스트 파일 | 파일 공유 | [1][2] |
| 음성 녹음 앱 | 더보기 → 삼성 노트에 추가 | 삼성 노트 메모 | [2] |

- 공유 대상: Quick Share, 이메일, 블루투스, 클라우드 앱, 메시지, 노트. 모델 · 버전 · 설치 앱에 따라 다르다 [1].
- 「텍스트 파일」의 확장자 · 인코딩 · 화자 표기 형식은 확인 못 함.

### 2-2. 자동으로 파일이 남는가

- 사용자 보고(2025-03): 받아쓴 글이 별도 파일로 저장되지 않는다. 백업하면 음성 파일만 남고 받아쓴 글은 없어진다 [18].
- 공식 문서도 받아쓴 글의 저장 위치를 밝히지 않는다 [1][2].
- 받아쓴 글이 m4a 파일 안에 함께 들어가는지는 확인 못 함.
- 결론: 갤럭시 AI 가 만든 글을 「자동으로」 PC 로 옮기는 공식 길은 찾지 못했다.

### 2-3. 개발자 API

- 갤럭시 AI 통화 받아쓰기 결과를 다른 앱에 넘겨주는 공개 API · SDK 는 찾지 못했다. 삼성 개발자 사이트를 직접 확인하지는 않았다(확인 못 함).
- 다른 앱이 통화 음성을 직접 녹음하는 길은 막혀 있다. 안드로이드의 `VOICE_CALL` 음원은 `CAPTURE_AUDIO_OUTPUT` 권한이 필요하고, 이 권한은 시스템 전용이라 일반 앱은 받을 수 없다 [30].
- Google Play 는 2022-05-11부터 접근성 API 로 통화를 녹음하는 앱을 금지했다. 미리 깔린 기본 전화 앱은 예외다 [32].
- 다른 앱이 할 수 있는 일: 삼성 전화 앱이 남긴 녹음 파일을 읽는 것이다. Android 13 이상은 `READ_MEDIA_AUDIO` 권한으로 다른 앱이 만든 오디오 파일을 읽는다 [31].

### 2-4. 「자동」으로 옮기는 현실적인 길

1. 녹음 파일(m4a)을 자동으로 서버에 옮기고, 서버에서 따로 받아쓴다. 사람 손이 안 든다(5장 참고).
2. 갤럭시 AI 글은 직원이 통화 직후 폰에서 내용을 확인하는 보조로 쓴다.
3. 반자동: 직원이 통화 뒤 음성 녹음 앱에서 「텍스트 파일」을 공유해 정해진 메일 · 메신저로 보낸다. 통화마다 손이 한 번 든다.

## 3. 통화 녹음 파일

- 국내 모델은 통화 녹음을 기본으로 준다. 설정 경로: 「삼성 전화 앱 > 더보기 > 설정 > 통화 녹음 > 통화 자동 녹음」 [7].
- 자동 녹음 대상: 모든 번호 / 저장되지 않은 번호 / 선택한 번호만 [7].
- 기본 전화 앱이 아닌 외부 전화 앱이 깔려 있으면 녹음이 안 될 수 있다 [7].
- 자동 녹음이 켜져 있으면 통화가 끝날 때 파일이 자동 저장된다 [5][6].
- 저장 경로(삼성전자서비스, 2026-09-30) [5]:
  - Android 14 · 13: `내 파일 > 내장 저장공간 > Recordings > Call`
  - Android 12 ~ 9: `내 파일 > 내장 메모리 > Recordings > Call`
  - Android 15 이상(One UI 7 ~ 9)은 공식 문서에서 확인 못 함. 같은 경로일 가능성이 높지만 실기기로 확인해야 한다.
- PC 에 USB 로 연결하면 `내 PC > 휴대장치 > 내부 저장소 > Recordings > Call` 에서 보인다(블로그, 2026-06) [43].
- 형식은 m4a 다. 삼성 음성녹음 담당자가 「당사 앱에서 녹음한 m4a 파일」만 받아쓰기를 지원한다고 답했다(검색 요약으로만 확인) [21]. 음성 녹음 앱의 기본 저장 형식도 M4A 다 [24].
- 파일 이름: 옛 기종(S10) 기준 「상대 이름 또는 번호_날짜_시분초.m4a」 꼴이라는 블로그가 있다(검색 요약으로만 확인) [44]. 최신 기종 규칙은 확인 못 함. 서버에서 파일 이름으로 상대 번호를 뽑으려면 실기기 확인이 필요하다.
- 목록 보기 · 공유: 「전화 > 옵션 더보기 > 설정 > 통화 녹음 > 녹음한 통화」 또는 「음성 녹음 > ≡ > 통화녹음」에서 길게 눌러 공유한다 [6].
- 상대방 알림: 미국 모델은 녹음 시작 · 끝에 상대에게 알림음이 간다 [1]. 국내 정식 모델은 알림이 없다는 사용자 답이 많지만 공식 문서로는 확인 못 함 [23].
- 삼성 클라우드로 백업 후 복원하면 통화 기록과 녹음 파일이 연결되지 않는다(삼성 담당자 답, 2023-03) [22].

## 4. 정확도 · 품질

- 공개 수치(단어 오류율 등): 없음. 한국어 통화 기준 공개 평가는 찾지 못했다.
- 삼성 공식: 「결과의 정확성은 보장되지 않습니다」, AI 특성상 결과가 매번 다를 수 있다(2026-10-21) [8]. 갤럭시 AI 안내도 결과의 정확성 · 완성도 · 신뢰성을 보장하지 않는다고 적는다 [9]. 인도 페이지도 「Accuracy of results may vary」라고 적는다 [4].
- 사용자 보고:
  - 2024-02, S24: 긴 통화 받아쓰기 정확도가 낮다는 불만. 다른 사용자는 마이크 가까이 또렷하게 말해야 잘 된다, 반년이 지나도 나아지지 않았다고 적었다 [19].
  - 2025-02, One UI 7 팁 글: 주변 소음 · 발음 문제가 없으면 화자 구분이 정확하다 [14].
  - 한국어 통화가 영어로 옮겨진 사례 [20].
  - 2025-10 업데이트 뒤 「통화 녹음 및 텍스트 보기」 버튼이 안 뜨는 오류. 옵션을 껐다 켜자 해결됐고, 모더레이터는 오류 로그 전송을 안내했다(2026-05 에도 같은 안내) [15].
- 보도: 기기 안 받아쓰기는 어려운 음질이나 긴 녹음에서 힘들 수 있어 클라우드 받아쓰기를 만든다고 한다(2026-07) [25].
- AI 판단: 주문 전화에는 부품 번호 · 차종 · 수량처럼 틀리면 안 되는 말이 많다. 공개 수치가 없으니 가짜 주문 대본으로 재연한 통화로 직접 재 보는 것이 맞다.

## 6. 한국 법적 유의점

- 직원이 자기가 받는 통화를 녹음하는 것은 통신비밀보호법 위반이 아니다. 법은 대화에 참여하지 않은 제3자의 녹음을 막는다 [38][39][40].
- 녹음과 받아쓴 글에는 고객 이름 · 번호 · 주문 내용 같은 개인정보가 담긴다. 다른 회사에 넘기면 개인정보 보호법 제17조(제3자 제공)를, 외부 서버 · 받아쓰기 업체에 처리를 맡기면 제26조(업무위탁)를 따라야 한다 [41][42].
- 이 절은 법률 자문이 아니다. 실제 서비스 전에 전문가 확인이 필요하다.

## 7. 이 프로젝트에 주는 시사점 (AI 판단)

- 갤럭시 AI 받아쓰기는 직원 폰 화면의 보조로만 쓰고, 주문 카드 흐름은 m4a 파일 기준으로 짠다.
- 흐름: 국내 갤럭시 자동 녹음 → `Recordings/Call` 의 m4a → FolderSync 또는 자체 앱 → 서버 저장소 → 서버 받아쓰기 → 주문 카드.
- 고객 통화가 삼성 서버로 가지 않게 「기기에서만 처리」를 켜 둔다. 요약 기능 일부를 잃을 수 있다.
- 자동 녹음을 「모든 번호」로 두면 개인 통화도 올라간다. 업무 전용 폰이거나 「선택한 번호만」을 검토한다.

## 8. 확인 못 한 것 · 실기기로 볼 것

- One UI 7 ~ 9(Android 15 ~ 17)의 통화 녹음 저장 경로와 파일 이름 규칙.
- 「텍스트 파일」 공유 결과의 형식(확장자, 화자 · 시각 표기).
- 받아쓴 글이 m4a 안에 들어가는지.
- 비행기 모드에서 통화 받아쓰기가 되는지(실제 온디바이스 여부).
- S22 · S23 · A 시리즈 개별 기종의 전화 앱 받아쓰기 지원.
- 2026-11 보도된 유료 요금제에서 통화 받아쓰기 · 요약이 한도 대상인지.
- 음성 녹음 앱 「클라우드 받아쓰기」의 정식 출시 여부.
- 국내 모델 녹음 알림 여부를 밝힌 공식 문서.
- 갤럭시 AI 받아쓰기 결과를 읽는 개발자 API 유무(삼성 개발자 사이트 미확인).
- 영어권 비교 체험기(Tom's Guide)는 본문을 읽지 못해 넣지 않았다.
