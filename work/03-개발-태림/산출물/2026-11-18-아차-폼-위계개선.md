# 아차 주문 폼 위계 개선

## 실제 변경
- 입력값과 근거 동작을 하나의 입력면에 묶고 AI 출처·번호 일치·저장 상태는 아래로 분리.
- 라벨/입력/도움정보 순서 통일. 불확실 필드 전체를 칠하지 않고 확인 메시지로 구분.
- 중첩 카드 대신 품목별 구분선. 기본 정보 → 주문 품목 → 배송 및 요청사항 순서.
- 기존 동작·선택자·계정별 임시저장·revision·권한 경계는 그대로.

## 공식 근거
- [Form control](https://montage.wanted.co.kr/docs/components/selection-and-input/form-control/design): label/input/message/accessory 역할 분리.
- [Text field](https://montage.wanted.co.kr/docs/components/selection-and-input/text-field/design): 입력 컨테이너와 trailing accessory의 일관된 위계.
- [Section message](https://montage.wanted.co.kr/docs/components/feedback/section-message/design): 필요한 범위에 상태·주의 메시지.
- Montage React 컴포넌트를 설치한 것이 아니라 기존 vanilla 앱에 원칙을 적용한 구현이다.

- 가짜 데이터 화면 18뷰, 큰글씨 9, 기존 E2E 10, Node 185 통과.

- PC/모바일 실제 캡처 확인. 전면 접근성 인증이나 1.6 전체 완료를 의미하지 않는다.
