# 체험 신청 전송 중 수정 내용 소실

기존 폼은 보내기 버튼만 잠갔다. 요청이 진행 중일 때 연락처·남길 말·동의를 바꾸면 서버에는 최초 값이 전송되고, 성공 후 새 입력은 사라졌다. 실제 trial 모듈과 지연된 가짜 응답으로 재현했다.

수정: 요청에 넣을 값 확보 후 input/select/textarea와 동의 입력을 잠근다. 요청 실패 시 값과 동의를 유지하고 기존 disabled 상태로 복구한다. 성공 시 기존 완료 화면을 유지한다. 서버 API나 동의 규칙을 바꾸지 않는다.

검증: 잠금, 요청 중 중복 submit의 POST 1회, 실패 보존·잠금 해제, 수정 재시도 payload·성공1회, 입력 소실 방지 총 5조건 통과. 기존 Node191개·실제 앱 가짜 브라우저 흐름10개 통과. CI에 전용 회귀를 연결했다.
