# 주문 카드 수기 검수 집계

[#61](https://github.com/iiankeum/T07-genai-project/issues/61)에서 녹음을 듣고 판단한 결과를 개수로 집계한다. 앱, 모델, 녹음, 네트워크는 사용하지 않는다. 사람의 청취 판단을 자동으로 대신하지 않는다.

```sh
cd 'work/03-개발-태림/산출물/카드-검수'
python3 audit.py 가짜-검수.csv
python3 -m unittest -v
```

1. 결과를 보기 전에 검사할 통화를 고른다. 모델을 비교할 때는 같은 표본을 사용하되 모델·설정별 CSV를 나눈다.
2. **저장소 밖의 로컬 CSV**에 임의로 붙인 `C001` 형식의 시험 번호와 칸별 판정만 적는다. 번호 연결표, 실제 이름, 거래처, 부품 문자열, 녹음/전사/파일 경로는 CSV에 적지 않는다.
3. 칸은 `customer`(거래처), `vehicle`(차종), `delivery`(출고 요청), `part:01`(첫 품목), `quantity:01`(첫 수량) 형태다. 여러 품목은 `:02`, `:03` 등으로 구분한다. 같은 통화에서 품목 대응 기준을 미리 정한다. 정답이 있는데 비어 있는 칸이나 근거 없이 채운 칸은 정답 오차로 표시한다(`wrong`).
4. `correct` / `wrong`에는 **그 칸에 해당하는** 「확인 필요」 경고 유무를 `yes` / `no`로 적는다. 다른 칸의 경고는 `no`다. 판정이 어렵거나 대상이 아니면 `unsure` / `not_applicable`을 쓰고 경고는 빈칸으로 둔다. 카드 자체가 없으면 `C003,card,missing_card,`처럼 한 줄을 기록한다.
5. `python3 audit.py <로컬 CSV>`의 출력은 집계뿐이다. 행 오류에도 입력 내용이나 파일 경로를 출력하지 않는다. 원본 CSV는 커밋하지 않는다.

- 칸 기준: `unwarned_wrong / judged`는 판정한 칸 중 경고 없이 틀린 비중이다. `unsure`, `not_applicable`, 카드 없음은 분모에 넣지 않고 별도로 보고한다.
- 통화 기준: `calls_with_unwarned_error / calls_with_judged_fields`는 **하나 이상 판정한 통화 중, 판정한 칸에** 경고 없는 오류가 하나 이상 있던 비중이다. 일부 칸만 본 통화를 포함하므로 검수 범위를 함께 적는다. 분모 0이면 비율을 계산하지 않는다.
- 가짜 예시는 통화 4개 중 카드 없음 1개, 판정한 통화 2개 중 경고 없이 틀린 통화 1개, 판정한 칸 5개 중 경고 없이 틀린 칸 2개다. 실제 모델 성능이 아니다.
