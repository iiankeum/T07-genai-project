# 근거 확인 후 편집 위치로 복귀

실제 가짜 앱에서 두 번째 품목 품번 수정→근거→대화에서 보기→주문 카드 복귀 시 값은 남지만 초점이 카드 전체로 이동하는 문제를 재현했다. 수정 전 전용 회귀가 실패했다.

화면 내 마지막 입력과 근거 품목을 기억하고 복귀 시 같은 입력에 초점/스크롤을 복원한다. DOM교체 시 필드키/품목 stableID로 재탐색하며 저장/API/권한/재생은 바꾸지 않았다.
