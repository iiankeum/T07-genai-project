# AGY Montage v2 → 실제 제품 UI 재구성 1차

신*림(taejs) · ChatGPT dot AI 초안 · 2026-11-18 21:09 KST

## 반영한 것

독립 AGY 시안의 상단 통합 탐색, 작업공간 선택, 녹음·받아쓰기 바로가기, 중앙 콘텐츠 정렬을 실제 제품에 적용했다. AGY의 가짜 상태 관리 코드를 제품에 복사하지 않았다. 기존 API·권한·저장·작업공간 격리 로직은 그대로 사용한다. 모바일은 기존 실제 제품의 5개 업무 탐색과 상세 확정 동작을 유지했다.

기존 시안은 별도 경로에 보존했다. AGY의 모바일 캡처는 1회 수정 후에도 오른쪽이 잘리는 문제가 남으므로 그대로 채택하지 않았다. 실제 제품은 별도로 360/390px와 큰 글씨로 검증했다.

## 시험 결과

- Node: 175개 통과, 0 실패.
- 기존 브라우저 업무 여정: 10개 통과. 실제 업로드·실제 계정·유료 API 사용 없음.
- 화면 8개 × PC/모바일 = 16개, 모바일 큰 글씨 8개 가로 넘침 없음.
- 새 상단 6개 목적지·작업공간·보조 기능 7개 경로 존재 자동 확인.
- 업로드 동의/형식, 모바일 주문·출고 1탭, 상세 고정 행동 가림 및 카드/원문 전환 확인.
- 캡처: `../자료/agy-v2-product-after/`, 브라우저 결과 `../자료/agy-v2-product-e2e/`.

## 완료와 미완료 구분

이는 전역 UI 재구성 1차다. 모든 화면의 내부 폼을 새 디자인으로 전면 교체한 것은 아니다. 시안에 있는 모델 다운로드 재개 UI 등의 모의 기능을 실제 동작으로 과장하지 않는다. 기존 제품의 스펙 기능을 삭제하지 않고 단계적으로 옮긴다.

남은 일: 출고 CSV·인쇄 직접 검증, 입력 오류/작업공간 전환 상태 접근성, 더보기 정보 위계, native 앱 빌드 반영, 실제 사용자 사용성. 배포·병합·원격 push는 하지 않았으며 기존 승인 오류 제한을 존중한다.
