# PR #5 갱신 준비본 — 아직 원격에 반영하지 않음

로컬 GitHub 연결 오류로 푸시 전 동기화가 실패했다. 이 문서는 기존 브랜치의 후속 커밋을 푸시한 뒤 본문을 갱신하기 위한 초안이다. 원격에 없는 변경을 이미 제출했다고 표시하지 않는다.

## 제목

feat: 아맞다 v1.6 업무 화면 재구성과 Mac 로컬 AI 기반

## 변경

기획서 v1.6의 주문 검토·확정·출고, 계정·작업공간, 승인형 지식과 근거 질의 기능에 이어, 오늘 업무 대기열·통화 검색·원문과 주문 카드의 화면 구조를 다시 구성했다. 기존 HTML/JavaScript와 API를 유지했다. Wanted Montage 토큰을 사용하며, Antigravity는 설치됐지만 실행 오류 -10827로 사용하지 못했다.

Mac AppKit/WKWebView 앱에 Node 24를 번들하고, 로컬 자료와 선택한 HTTPS 서버의 실행 경로를 분리했다. AI_PROVIDER=ollama로 카드·브리핑·질문을 연결했다. Ollama와 Whisper 모델·CPU 일꾼은 별도 설치가 필요하다. 기존 팀 서버는 Node 24와 SQLite 직접 실행을 기본으로 유지하고 Docker는 선택 사항이다.

Alt로 추정되는 필기앱의 로컬 기본·선택 클라우드 구분을 참고해, 수동 Docker/Node/Ollama 설치가 없는 최초 모델 준비 흐름과 릴리즈 체크리스트를 설계했다. 이 마법사는 아직 미구현이며 Alt 내부 설치기를 검증한 결과가 아니다. Lightning-SimulWhisper 코드는 포함하지 않았다.

## 이번 후속 변경의 검증

- 소켓을 사용하지 않는 Node 회귀 40/40, 변경 JS/MJS 19개 구문 검사 통과.
- Mac Apple Silicon 빌드·ad hoc 서명·소스 100개 대조·production 의존성 8개 버전 일치·내장 Node/SQLite·부모 종료 연동 확인.
- E2E는 서버 listen EPERM으로 0개 실행. 새 화면 캡처 없음. 실제 앱 GUI와 Whisper/Ollama 추론 미검증.
- 유료 AI와 실제 고객 자료를 사용하지 않았으며 병합·운영 배포·팀 GPU 변경 없음.

기존 b86b498의 Node 139/139·PC 17/17·브라우저 8개 및 캡처 8장은 이전 구현의 증거다. 이번 화면의 E2E 결과로 재사용하지 않는다.
