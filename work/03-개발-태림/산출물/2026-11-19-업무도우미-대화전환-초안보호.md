# 대화 전환 중 질문 초안 보호

## 재현
업무 도우미에서 저장된 대화를 선택하고 GET 응답을 지연했다. 입력창은 계속 편집 가능했다. 그동안 적은 질문은 대화 응답이 도착하면 빈 값으로 덮였다. 실제 assistant 모듈과 가짜 GET만으로 재현했으며 POST는 없었다.

## 최소 수정
- 저장 대화 조회·삭제 중에만 질문 작성을 잠근다. 이유를 보이는 짧은 진행 안내와 ARIA 설명으로 제공한다.
- 실패 시 기존 초안과 원래 disabled·설명·busy 상태를 복원한다.
- 성공 시 기존 정책대로 새로 선택한 대화의 질문칸을 비운다. 전환 전에 쓴 초안의 정책 자체는 바꾸지 않는다.
- AI 답변 대기 중 다음 질문을 작성하는 기능은 유지한다. 서버 API·권한 계약은 변경하지 않는다.

## 검증
- 신규 가짜 API 20조건 통과. 1440/390 viewport 각각 조회 성공·실패/재시도, 삭제 성공·실패/취소, 답변 대기 중 다음 초안, 원래 disabled/설명 복구, 순차 A-B-A, 언마운트·이전 mount 응답을 검사했다.
- 기존 업무 도우미 초안 초점 6조건과 Node188 통과. 오류·외부 요청 0건.
- 독립 감사·구현과 읽기 리뷰, 주 검토를 수행했다.

## 불필요한 변경을 하지 않은 항목
AI 재정리 중 note/items 수정도 별도로 점검했다. 실제 카드 모듈과 가짜 revision-aware API의 미저장/저장 완료 두 순서에서 입력 보존을 확인했다. 결함으로 판단하지 않아 재정리 입력 잠금을 추가하지 않았다. 미저장 보존은 저장 완료와 다르며 이후 충돌복구 전체를 검증한 것은 아니다. [검사 결과](../자료/assistant-thread-20261119/reextract-negative-fake.json)
