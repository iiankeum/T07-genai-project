# 공통 폼 오류와 비동기 모달 초점

## 구현 범위
- 공통 bindForm의 필드 오류를 안정된 고유 feedback ID로 aria-describedby에 연결. 기존 도움말 ID 보존, 재제출 때 자신이 추가한 오류 링크만 제거.
- 필드에 대응하지 않는 오류는 status 영역으로 초점 이동. 두 폼의 오류 연결과 submit payload는 서로 간섭하지 않음.
- 재연락 문안의 비동기 응답이 모달 내용을 교체할 때 기존 닫기 버튼의 초점을 새 동일 동작으로 복귀. 대체 동작이 없으면 모달 제목으로 초점을 유지.
- 실제 라우터가 읽는 knowledge-assistant.css에서 재연락 모달 제목/닫기 고정. 별도 미사용 stylesheet를 만들지 않음.

## 불변
권한/API/외부발송/자동확정 기능 추가 없음. 모달 닫기 때 요청 AbortController 취소와 늦은응답 무시 동작 유지.

## 검증 범위
실제 모듈+가짜 응답 기반 내부검증이며 스크린리더 실사용/전체 WCAG 인증 아님. native dialog의 브라우저 크롬으로의 탭 이동과 페이지 배경으로의 초점 누수를 구분한다.

## 결과
