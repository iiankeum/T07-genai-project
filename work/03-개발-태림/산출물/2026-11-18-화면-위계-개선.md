# 아맞다 화면 1차 개선

## 왜 어색했나
- Montage 색상 토큰만으로 화면 전체의 우선순위가 정해지지 않는다. 모바일은 제목·동작·날짜·상태·통계가 높이를 차지해 실제 할 일이 첫 화면 아래로 밀렸다.
- 통화 상세의 최근 목록·원문·편집 입력란과 근거 강조가 모두 비슷한 세기로 경쟁했다.
- 기존 E2E는 외부 요청을 차단하므로 CDN 글꼴이 로드되지 않았다. 기존 캡처는 Pretendard 적용을 검증한 증거가 아니다.

## 바꾼 것
- 통계 5개를 모바일 한 줄로 정리하고, 제목은 28/38px, 본문·라벨 굵기를 구분했다. 첫 처리 항목이 하단 내비게이션 위에 보이는지 자동 검증한다.
- 최근 통화는 보조 영역으로, 원문은 읽는 영역으로, 주문 카드는 편집 영역으로 구분했다. 선택 근거·불확실성·확정 경고·접근성 기능은 유지했다.
- Pretendard JP Variable v1.3.9와 OFL을 로컬 번들에 포함했다. 인터넷 없이도 동일한 글꼴을 사용한다. 원본은 약 5.1MB이며 다운로드 크기 최적화는 별도 과제다.

## 공식 근거와 판단의 구분
- [Montage Typography](https://montage.wanted.co.kr/docs/foundations/base-material/typography): 글꼴·크기·굵기·행간·자간으로 정보 위계를 만든다. Title 1은 32/44px, Title 2는 28/38px, Body 1은 16/24px이다.
- [Montage Foundations](https://montage.wanted.co.kr/docs/foundations): 색상뿐 아니라 타이포그래피·그리드·깊이도 설계 체계에 포함한다.
- [Pretendard 원본](https://github.com/orioncactus/pretendard/tree/v1.3.9): 공식 태그의 글꼴·라이선스를 함께 보관했다.
- 업무 우선 배치와 통화 화면 역할 구분은 이 프로젝트에 대한 설계 판단이며 Montage의 강제 규칙이라고 주장하지 않는다.

## 검증과 남은 것
- Node 170개, 브라우저 10개 통과. 오프라인 글꼴 로드, 360px 첫 처리 항목 가시성, 큰 글씨 가로 넘침 회귀 추가.
- 주문 수정·근거·확정·출고·공유지식 승인·공간 격리 흐름 유지. 서버·인증·로컬 모델 동작 변경 없음.
- Antigravity로 만든 결과물이 아니다. 기존 HTML/CSS 기반 1차 개선이며 전면 재설계 완료라고 주장하지 않는다.
- Wanted React 컴포넌트 설치와 동일한 결과가 아니다. 토큰과 디자인 규칙을 기존 모듈 앱에 적용한 구현이다.
- 실제 사용자 승인, 신규 Mac 시험, 네이티브 패키지 갱신은 이 브라우저 검증과 별개다.
