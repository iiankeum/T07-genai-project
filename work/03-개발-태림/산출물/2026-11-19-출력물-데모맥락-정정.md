# 출력물의 데모 표시 정정

> AI 초안 · 돌린 사람: 신*림 · 도구: ChatGPT dot · 2026-11-19

## 문제와 변경
비공개 작업공간에도 거래처 화면, 통화 글 복사, 출고 인쇄와 CSV 파일명에 가짜 데모 표시가 붙는 문제를 가짜 데이터로 확인했다.
- 거래처·전화번호는 중립 라벨을 쓴다. 데모 작업공간 안내는 유지한다.
- 복사한 통화 글은 개별 `isFake === true`일 때 가짜 자료임을 알린다. false/미제공을 실제 자료라고 단정하지 않는다.
- 출고 인쇄·CSV 파일명은 작업공간 모드에 따라 데모 안내를 붙인다. 비공개 자료 전체를 가짜로 단정하지 않는다.
- 거래처 페이지 제목의 이전 가칭을 아차로 정리했다.

## 검증
- 실제 화면 모듈과 가짜 API의 demo/private/미확인 × isFake true/false/미확인 9조합 통과.
- 실제 CSV 라우트 HTTP 응답 및 통화 복사 함수 신규 Node 2개 포함 전체 Node 190개 통과.
- 브라우저 오류와 외부 요청 0건. 독립 읽기 리뷰에서 차단급 문제 없음.

## 범위와 한계
문자열과 함수 결과를 확인한 내부 회귀다. 실제 클립보드·프린터·인증·실사용자 시험은 아니다. CSV HTTP 테스트는 접근 컨텍스트를 주입했다. 출고 목록의 개별 가짜 주문 표시를 추가한 것은 아니다. 권한·데이터 저장·업무 상태 로직은 변경하지 않았다. 실제 사용자 자료·외부 AI·메일·배포를 사용하지 않았다.
