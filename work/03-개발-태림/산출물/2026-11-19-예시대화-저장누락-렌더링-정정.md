# 예시 대화 저장 누락과 렌더링 정정
> AI 초안 · 돌린 사람: 신*림 · 도구: ChatGPT dot · 2026-11-19

## 재현과 변경
첫 예시 문장 뒤 둘째 문장이 타이핑되는 동안 저장하면 서버에 보낸 글은 1줄, 화면은 2줄이었다. 예시 입력 중 저장 버튼과 save 함수 양쪽을 막고 문장 완료 뒤 저장하도록 안내했다. 샘플 재생과 초기화 동작은 유지했다.

확정 줄의 SafeHtml 배열을 render에 직접 넘겨 HTML 마크업이 문자로 보이는 별도 결함도 확인했다. 배열을 html 템플릿으로 감싸 실제 대화 행으로 렌더링하며 사용자 문자열 이스케이프를 유지한다.
