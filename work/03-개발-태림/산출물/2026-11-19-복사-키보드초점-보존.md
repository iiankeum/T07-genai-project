# 복사 후 키보드 초점 보존

## 문제와 수정
받아쓴 글·답장·마감 문구 복사의 공용 함수는 clipboard 권한 거절 시 임시 textarea로 복사한다. 이를 제거하면 원래 버튼·입력의 초점과 편집 선택 영역이 사라졌다. 키보드 사용자가 다음 입력으로 이어가기 어렵다.

대체 복사 시작 시 현재 초점과 텍스트 선택 영역을 보존한다. 임시 textarea를 정리한 뒤 원래 요소가 남아 있고 초점이 여전히 임시 요소에 있을 때만 스크롤 이동 없이 복구한다. 권한 대기나 복사 이벤트 중 사용자가 다른 곳으로 이동하면 이를 존중한다. 복사 결과와 오류 안내는 유지한다.

## 검증
- 수정 전 실제 공용 모듈·가짜 clipboard/execCommand: 8조건에서 초점 소실 재현.
- 수정 후 14조건 통과: 정상 clipboard, fallback 성공·실패·예외, 원래 요소 삭제, 권한 대기 중 초점 이동, 복사 이벤트 중 이동. 버튼 Enter/다음 Tab과 textarea backward 선택 영역 확인.
- Node 191개 및 기존 브라우저 10개 흐름 통과. 독립 읽기 리뷰에서 blocker 없음.
- 새 test:copy-focus-e2e를 CI에 연결. 증거는 ../자료/copy-focus-20261119의 가짜 JSON만 저장한다.
