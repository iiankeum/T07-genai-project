# 접근성·다품목 후속 검증

## 확인한 문제와 수정
- 주문 입력/라벨 일부가 px 고정이라 '글씨 크게'에 맞춰 확대되지 않았다. 입력은 기본 16px/24px, 라벨은14px/20px 비율로 rem을 사용한다. 전체 CSS 토큰 이관을 의미하지 않는다.
- 지식 제안 저장 중 Escape로 창을 닫고 요청 실패하면 오류가 닫힌 창에만 남고 재진입시 입력이 초기화되는 현상을 실제 모듈+지연 mock으로 재현했다. 저장 중 native cancel만 차단하고 진행 상태를 알린다. 실패 후 입력·오류를 보여주고 닫기를 다시 허용한다. 성공 후 기존 동작 버튼으로 초점을 돌린다.

## 범위
자동화/내부 시각 검증이며 사용자 만족도·실사용 과업평가가 아니다. 음성 재생은 실제 오디오가 아닌 callback 여부로 검증한다. 실제 서버 저장/권한 보증은 기존 통합 회귀 범위와 구분한다.

## 남은 접근성 감사
계정·설정 공통 폼의 오류문과 개별 입력 aria-describedby 연결, 어시스턴트의 비동기 모달 갱신 초점, 전체 스크린리더 탐색은 추가 점검 대상이다. 1.6 전체완료·WCAG 인증을 주장하지 않는다.

## 추가 재현 및 수정
품목 입력 후 blur/change가 동일값으로 다시 저장 준비를 하면서 확정 버튼을 교체해 첫 클릭이 무시되는 현상을 확인했다. 정규화 값이 같으면 중복 처리하지 않는 guard를 넣었다. 다른 입력은 기존 동일값 guard를 유지한다. API/draft/revision 로직은 변경하지 않았다.

## 검증 결과
1/5/10품목 × PC/모바일 × 기본/큰글씨 12조건 실제 mountCard+mock API 통과. 추가/삭제 ID 보존·근거 callback·확인항목 초점·마지막입력 가림·수정 직후 단일 확정클릭·pending flush·readonly를 확인했다. 실제 큰글씨 computed fontSize 증가도 확인. 실제오디오 재생/운영서버는 검증 안 함. 기존 E2E10 및 복구8 통과. 지식 mock 회귀8범위(지연실패 포함)도 통과.
