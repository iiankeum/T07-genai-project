# 독립 신규 시안의 실제 제품 반영

## 반영 범위
- 기능 스펙·Montage 공식 문서만 입력으로 만든 독립 시안에서 신규 PC LNB·평면 통화 목록 구조를 적용한다.
- PC는 시간/거래처/통화·주문 내용/상태를 열로 맞춘 목록. 모바일은 목록 셀과 기존 하단 탐색을 유지한다.
- 과도한 검색 패널 상자를 제거하고 상태 탭→검색→기간/상세조건 순서로 정리한다. DOM 키보드 순서도 동일하다.
- 독립 시안의 우측 상세 패널은 아직 이식하지 않는다. 현재 검증된 상세·주문 화면과 보안·자동저장 로직을 그대로 사용한다.
