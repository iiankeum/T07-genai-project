# v1.6 직접 재개 검증
> AI 초안 · 돌린 사람: 신*림 · 도구: ChatGPT dot · 2026-11-18 14:38 KST

## 한 줄 결론
새 업무 화면과 기존 주문 흐름은 실제 브라우저 시험까지 통과했고 PR #5에 반영했다. **Mac에서 실제 AI가 동작하는 완제품 설치 경험은 아직 남아 있다.**

## 이번에 확인한 것
- `src/app`에서 `npm test`: 단위·통합 151개 통과, 실패 0.
- `npm run test:e2e`: 브라우저 여정 10개 통과, 페이지 오류 0.
- 오늘 업무 우선순위, 검색·필터 유지, 원문과 주문 필드 연결, 자동 저장→확정→출고, 재연락, 360px 화면을 검증했다.
- 가입·1회용 확인·작업공간 격리, 다른 공간으로 바뀐 오래된 탭의 저장·내보내기 차단도 검증했다.
- 데스크톱 통화 화면과 모바일 오늘 화면 캡처를 직접 확인했다. 이는 전체 접근성·모든 기기 검증을 뜻하지 않는다.
- 실제 고객 자료·유료 AI는 사용하지 않았다. 브라우저의 외부 CDN 요청도 차단했다.
- 코드 커밋 `42501cc`의 [GitHub Actions 회귀·E2E](https://github.com/iiankeum/T07-genai-project/actions/runs/44245470736)와 비밀키 검사도 모두 통과했다.

## 무엇이 달라졌나
이전 작업방에서 막혔던 실행·네트워크 작업을 현재 허용된 환경에서 재개했다. 기본 브라우저 실행은 macOS 격리 제한으로 실패했으나 정식 실행 승인 절차를 거쳐 성공했다. 보안 설정을 변경하거나 사용량 제한을 우회하지 않았다. 기존 로컬 변경을 유지하여 `42501cc`까지 PR 브랜치로 올렸다.

## 아직 안 한 것
- Ollama/Whisper 실제 모델 설치·음성 전사·언어 추론. 현재 해당 모델 런타임 설치를 확인하지 못했다.
- Mac 네이티브 앱의 실제 파일 선택·설치 후 최초 실행, 자동 모델 준비 UI, 배포 서명·공증.
- Antigravity 생성, 실제 이메일 배달, Docker 기동·복원, 운영 서버 배포.
- 팀 GPU 설정 변경, main/dev 푸시, PR 병합.

## 다음 우선순위
**터미널 없이 처음 켰을 때 준비 상태가 보이는 Mac 앱**을 우선한다. 로컬 모드와 팀 서버 연결을 구분하고, 모델이 없으면 준비 방법을 안내해야 한다. 실제 모델 시험과 사용자 설치 검증 전에는 배포 완료라고 표시하지 않는다.
