# 실제 로컬 음성→주문 카드 검증
> AI 초안 · 돌린 사람: 신*림 · ChatGPT dot · 2026-11-18 15:12 KST

## 한 줄 결론
가짜 음성을 실제 로컬 모델로 받아쓰고 주문 카드로 저장·표시했다. 원문에 없는 거래처·차종을 모델이 생성하는 문제를 발견해, 해당 값은 비우고 사람이 확인하도록 막았다.

## 검증한 경로
1. macOS Yuna로 “앞 브레이크 패드 한 세트와 앞 디스크 두 개 부탁합니다.”를 합성했다. 실제 고객 녹음은 쓰지 않았다.
2. 임시 localhost 앱에 WAV 업로드, 작업큐 임대, 인증된 음성 다운로드·SHA256 일치를 확인했다.
3. 기존 `WhisperTranscriber`와 실제 small 모델이 한국어를 전사했다. CPU int8, 약3.7초 음성이다.
4. 실제 결과 API→기존 파이프라인→qwen3:4b→SQLite저장→조회까지 수행했다.
5. Chromium에서 저장된 통화 화면을 열고 캡처했다. 패드1·디스크2가 저장되며 고객·차종은 빈칸과 확인 경고로 표시됐다.

전체 서버의 상시 워커 프로세스를 기동한 시험은 아니다. 테스트가 기존 일꾼 핵심 함수를 호출하고 실제 큐·결과 API를 연결했다. 실제 사용자 계정이 아닌 분리된 임시 데모 공간을 사용했다.

## 발견·수정한 결함
첫 실제 전체 카드 시험에서 원문에 없는 거래처와 차종이 생성됐다. 단순 JSON 추출 성공만으로는 이 결함이 보이지 않았다.

- 거래처·담당자·차종·연식·차번호는 원문 값, 승인 별칭, 확인 가능한 유사 음성정정만 허용한다.
- 실제 원문에 없는 인용은 근거에서 제거한다. 무관한 실제 문장만 붙인 값도 허용하지 않는다.
- 제거한 값은 확인 경고로 남긴다. 번호 매칭과 기존 정정 기능은 유지한다.
- 자유 AI 요약 대신 검증된 구조화 카드로 목록 요약을 만든다. 방향 접두어 중복도 제거했다.
- 품목·수량 전체 의미 정확도, 시간/배송/긴급 표현의 해석까지 보장하는 장치는 아니다. 실제 현장 평가가 필요하다.
