# 아맞다 화면 재구성과 Mac 로컬 앱

기존 PR #5의 기능을 보존한 후속 작업이다. 화면 재구성, Mac 패키징, 실제 모델 추론, 브라우저 검증, 원격 PR 반영은 각각 다른 완료 조건이다. 이전 커밋 `b86b498`의 139개/17개/8개 통과와 캡처 8장은 이번 화면의 검증 증거가 아니다.

## 1. 구현한 범위

| 영역 | 이번 변경 | 확인 범위 |
|---|---|---|
| 화면 프레임·통화 검색 | 업무/지식 메뉴, 작업공간 전환, 일관된 SVG 아이콘, 검색·주요 필터·펼치는 상세 필터로 HTML 재구성 | JS 구문 검사. 새 브라우저 시각 검증은 차단됨 |
| 오늘 브리핑 | 할 일 대기열 우선, 숫자 요약, 오른쪽 AI·마감 도구, 최근 통화. 자동 유료 생성 없음 | 가짜 데이터 mount/click 점검 및 구문 검사. 모바일 실제 배치는 미검증 |
| 통화 상세·주문 카드 | 거래처 제목과 메타 분리, 원문 행, 근거 연결선, 카드 필드 그룹, 별도 스크롤과 상태 작업 버튼. 모바일 대화/주문 전환 | 기존 API·data-* 계약 유지, 구문 검사. 실제 E2E 미완료 |
| 실제 로컬 LLM 연결 | `AI_PROVIDER=ollama`, 기본 `qwen3:4b`, `/api/show` 확인 뒤 `/api/chat`의 JSON 스키마 응답. loopback 고정, 크기·시간 제한, 클라우드 모델 차단, 자동 외부 대체 없음 | 가짜 HTTP 전송으로 카드·브리핑·질문 경로 검증. 실제 추론 아님 |
| Mac 앱 | Swift AppKit/WKWebView, 번들 Node 24, 별도 자료 폴더와 5601 포트, 로컬 기본/HTTPS 서버 선택, 종료 연동, 로컬 AI 설정 파일 | Apple Silicon 로컬 빌드·ad hoc 서명 검사. 앱 GUI와 실제 모델 연결 미검증 |

화면은 기존 vanilla HTML/JavaScript 모듈을 새 템플릿으로 교체했다. React 전환이나 Antigravity 생성본을 사용했다고 표시하지 않는다. 서버·DB·권한·확정/출고 규칙은 보존한다. Mac 모델 가중치·Ollama·Python 전사 환경은 앱에 포함하지 않고 설치자가 최초에 별도로 준비한다. Apple Metal 음성 전사는 미구현이다.

## 2. Antigravity 실제 확인

- `/Applications/Antigravity.app`과 버전 2.26.0, 번들의 실행 파일 존재를 확인했다.
- PATH에는 `antigravity` 명령이 없고, 앱 내부에도 확인한 범위에서 사용 가능한 CLI가 없었다.
- `open /Applications/Antigravity.app`은 LaunchServices의 `kLSNoExecutableErr(-10827)`을 반환했다. 파일 존재와 오류 메시지가 일치하지 않아 앱 자체 손상인지 실행 환경 문제인지는 확정하지 않았다.
- UI 자동화 확인도 `-10827`로 실패했다. 로그인 상태·모델 선택·생성 기능을 확인하지 못했다. **Antigravity를 이용한 생성은 수행하지 않았다.** 현재 대안은 기존 런타임의 HTML 구조를 직접 재구성하는 것이다.

## 3. 검증 결과와 실행 차단

- 변경 JS/MJS 19개 구문 검사와 `git diff --check`를 통과했다.
- Node 24.19.0에서 AI adapter·화면 유틸리티·브리핑 출처/캐시·개인 작업공간 라벨 **27개 통과**. [로그](../자료/redesign-local-20261118/node-tests.txt).
- `AI_PROVIDER=ollama` 테스트는 가짜 HTTP transport를 사용한다. 실제 모델이 응답했다는 증거로 삼지 않는다. 제공자와 모델이 바뀌면 브리핑 캐시를 재사용하지 않으며 반환된 출처를 보존한다.
- 새 브라우저 스크립트는 기존 8개 업무에 오늘 대기열·모바일·통화 검색/필터를 추가했다. 현재 실행은 `listen EPERM 127.0.0.1:5627`에서 차단되어 **브라우저 흐름 0개 실행**. [결과](../자료/redesign-local-20261118/e2e-blocked.json) · [오류 로그](../자료/redesign-local-20261118/e2e-blocked.log).
- Chrome 실행도 SIGABRT/EPERM으로 종료됐다. 새 디자인의 캡처를 만들지 못했다. 기존 캡처를 복제하거나 새 결과로 표시하지 않는다.
- Ollama와 `qwen3:4b`, faster-whisper가 현재 Mac에 준비되어 있지 않다. 모델 다운로드, 실제 음성 전사·카드 정리·근거 질의·성능·오프라인 검증은 미실행이다.
- GitHub 연결 앱의 코드 쓰기와 PR 본문 갱신은 모두 403 `Resource not accessible by integration`. 로컬 Git 동기화는 `Could not resolve host: github.com`. 원격 PR #5의 마지막 확인 HEAD는 `b86b498`이다. 후속 변경의 PR 반영은 확인하지 못했다.
- 권한 우회, 유료 API 호출, 실제 고객 자료 사용, 팀 GPU 설정 변경, 병합·운영 배포를 하지 않았다.

로컬 패키지는 `out/Ahmatda-macos-arm64.zip`이다(47,297,441 bytes, SHA-256 `ebb67ae7d63ca6ae19c102c84dc5525ccd2cec564b568992451a68610fbf9894`). ZIP 무결성과 별도 경로에 풀어 수행한 deep strict 서명 검사를 통과했다. 바이너리는 Git에 포함하지 않으며 공개 릴리스로 업로드하지 않았다.

Mac 앱 빌드가 성공해도 사용자 설치·GUI 조작·음성/언어 모델 추론을 모두 검증한 것은 아니다. ad hoc 서명은 Developer ID 서명이나 Apple 공증이 아니며 App Store 배포판도 아니다.

### 재연결 뒤 재확인 — 2026-11-18 KST

- 작업 파일과 UI 커밋 `38da244`를 보존했다. 중복 실행 중인 하위 작업은 없었고, Astra 검토와 GPT-6.1 Sol high 패키지 검증을 분리했다.
- 서버 소켓을 사용하지 않는 AI·Ollama·화면 유틸리티·로컬 브리핑·시드 회귀 **40/40 통과**. 이전 27개를 포함하며 두 수를 합산하지 않는다. [재실행 로그](../자료/redesign-local-20261118/resume-node-tests.txt). 변경 JS/MJS 19개 구문, bash 구문, plist 및 diff 검사도 통과했다.
- E2E 재실행은 `listen EPERM 127.0.0.1:5627`로 서버 시작 단계에서 종료됐다. 실행한 브라우저 흐름은 여전히 0개이고 새 화면 캡처는 없다. [재실행 결과](../자료/redesign-local-20261118/resume-e2e-blocked.json) · [로그](../자료/redesign-local-20261118/resume-e2e-blocked.log). 전체 HTTP 회귀도 같은 서버 실행 권한이 필요하여 이번 회차에 통과했다고 기재하지 않는다.
- Antigravity `open`은 동일한 `-10827` 오류다. 재설치·권한 우회·생성 사용은 하지 않았다.
- Mac 번들의 런타임 리소스 100개는 현재 소스와 일치한다(HTML 2개는 빌드 시 외부 폰트 링크 제거). production 패키지 8개 버전 일치, dev 패키지와 `.env`·SQLite·WAV 미포함을 확인했다. 내장 Node 24.19.0의 임시 SQLite 초기화, 라우트 로딩·health handler 직접 호출, stdin 부모 종료 시 SIGTERM 종료도 통과했다. 현재 Swift 소스 재컴파일의 코드 섹션도 번들 런처와 일치했다. 이 검사는 서버 소켓이나 네이티브 앱 창을 열지 않는다. [재현 명령과 패키지 기록](../자료/redesign-local-20261118/mac-package-verification.txt).
- `gh pr view`는 API 연결 오류, `git pull --ff-only origin feat/ahmatda-v16-montage`는 GitHub DNS 오류다. 연결 앱의 읽기로 PR #5 HEAD가 여전히 `b86b498`임을 확인했다. 푸시 전 동기화를 완료할 수 없어 원격 변경을 수행하지 않았다.
- 최종 검토에서 macOS 파일 업로드의 WKUIDelegate 메서드 누락을 발견하여 같은 origin 프레임에서 NSOpenPanel을 열고 다중 선택·취소를 반환하도록 보완했다. [Apple 공식 설명](https://developer.apple.com/documentation/webkit/wkuidelegate/webview(_:runopenpanelwith:initiatedbyframe:completionhandler:))과 대조했다. 컴파일·패키지 재검증과 실제 GUI 파일 선택은 별도이며 후자는 미검증이다.
- 검토 제안: Mac 전용 서버의 요청 Host 고정 검사를 추가 방어로 검토할 수 있다. 현재 계정·업무 API는 인증과 작업공간 검증이 있고 쿠키도 host-only/SameSite=Strict여서, 이번 검토에서 대체 Host만으로 기존 업무 자료가 노출되는 경로는 확인하지 못했다. 실제 네트워크 재현은 미실행이다.

## 4. 시각 수용 기준과 남은 크리티컬 패스

1. 1440px에서 날짜·미처리 수와 우선 업무 3건이 먼저 보이는지 실제 캡처로 확인한다.
2. 통화 상세의 원문/카드 폭과 저장·확인 상태를 확인한다. 1280px에서는 최근 통화 레일을 접고, 360px에서는 수평 넘침·버튼 겹침 없이 주문/원문 이동을 검증한다.
3. 근거 선택 시 문장·필드·연결선이 같은 대상을 표시하는지 확인한다. 키보드 포커스, 44px 조작 영역, reduced-motion, 저장 실패·충돌·잠금 상태를 검사한다.
4. 실행 권한이 허용된 환경에서 `npm test`와 `npm run test:e2e`를 재실행하고 **새** 화면 캡처를 추가한다. 현재 막힌 테스트를 우회 실행하지 않는다.
5. Mac 앱을 설치·실행하여 가입/인증·파일 업로드/다운로드·앱 종료 후 Node 종료를 검증한다. 로컬 모델 준비 후 인터넷 없이 가짜 음성→Whisper→Ollama 카드→질문까지 실증한다. fixture 결과와 분리한다.
6. 검증한 변경과 증거를 기존 브랜치에 푸시하고 PR #5를 갱신한다. 기본 110개 요구사항의 잔여 항목은 기존 추적표와 함께 유지한다.
