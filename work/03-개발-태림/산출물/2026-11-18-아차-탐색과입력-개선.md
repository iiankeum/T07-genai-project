# 아차 탐색과 입력 개선

## 문제 → 적용
- 긴 원문을 눈으로 훑어야 함 → 문장 내 검색·일치 개수·이전/다음. Enter/Shift+Enter/Escape 지원. 검색은 서버 쓰기/AI 요청/자동재생 없음.
- 지식 관계에 `관계 | 대상` 문법 요구 → 관계 설명/연결 이름 별도 입력, 기존 이름 추천, 행 추가·삭제. 기존 배열·승인·이력 그대로.
- 거래처 번호 관리가 지식에 숨음 → PC 메뉴/모바일 모든 도구에 거래처 진입. 기존 지식 분류 화면을 재사용.
- 질문 화면 둘의 목적 불분명 → 업무 도우미(현재 통화 할 일·재연락)와 통화 내용 찾기(여러 통화 검색)로 표시명/설명 구분. 경로·기능 삭제 없음.
- 설정 홈에 같은 메뉴 중복 → 목적지 목록만 표시. 하위 화면은 전체 설정으로 돌아가기 제공. 내부 식별자 변경 없음.

## 기능 대응
통화/주문/출고/재연락, 원문근거·재생, 지식 승인/반려/이력/CSV/출처, 계정·권한·작업공간 및 로컬 연결 제한을 유지한다. LNB에 새 페이지 저장소를 만든 것이 아니라 기존 목적지 링크를 추가했다.

## 실제 검증
- PC/모바일 26뷰, 큰글씨13뷰, 거래처 메뉴 활성 단일 표시, 설정 홈 중복 제거, 기존 동작 검증 통과.
- Node185, 기존 E2E10 통과. 신규 대화검색 테스트는 가짜 실제 앱, 지식 입력 테스트는 실제 모듈+mock API.
- 지식 입력: 0개/부분행/복수/기존편집/10개 제한/삭제/취소/모바일 범위 검증. 승인 서버 로직 변경 없음.
- 캡처는 모두 가짜 데이터. 지식 폼 캡처는 앱 shell이 아닌 모듈 harness임을 표시한다.

## 남은 범위
- 실제 사용자의 과업 성공률/소요시간은 아직 측정하지 않았다.
- 실제 음성 재생·따라가기와 검색 동시 사용, 전체 스크린리더/키보드 접근성은 별도 점검 필요.
- 녹음·AI 연결 설정의 단계별 상태 안내, 지식의 상세 버전 비교 및 모든 하위 설정 폼 재설계는 미완이다.
- 로컬 적용만. push 차단 유지, 운영 배포/native 패키지 교체 없음. v1.6 전체 완료 아님.
