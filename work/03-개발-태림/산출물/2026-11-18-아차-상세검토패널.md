# 아차 상세 검토 패널 통합

독립 시안의 단순한 검토 패널 위계를 실제 통화 상세에 반영했다. 시안의 단일 품목·가짜 로직을 복사하지 않았다. PC에서는 원문과 여러 품목을 동시에 대조하는 기능을 보존하기 위해 **원문/주문 병렬 패널**을 쓴다. 목록 위에 뜨는 모달을 그대로 복제한 것은 아니다. 통화별 URL과 기존 라우팅을 유지한다.

## 변경
- 세 개 영역이 경쟁하던 화면에서 최근 통화를 기본 접힘 보조영역으로 바꿨다. 열기/검색은 유지한다.
- 원문은 평면 문서로, 주문은 편집 패널로 구분했다. 제목/정보/입력 간격·버튼 위계를 정돈했다.
- 모바일은 주문/대화 탭과 하단 확정 동작을 유지한다. 새 이름 아차를 유지한다.

## 스펙 보존
- REQ-HIS-01~07: 상세 이력·검색·근거 시점·원문·거래처·URL 유지. 녹음은 이번 fixture에 없어 실제 음성 청취는 미검증.
- REQ-ORD-01~09: 카드 controller/API 미수정. 여러 품목·품번 수동입력·입력검증·사람확인·확정잠금·재연락·동시수정·자동저장 유지.
- REQ-AI-03~05: 불확실 값과 근거 표시 및 연결선 E2E 확인. 모델 정확도 검증 아님.
- REQ-ERR/계정: actor/workspace·user-scoped draft 코드 미수정. 기존 세션·공간 격리 흐름 E2E 통과.

## 검증
- design-screens18뷰·큰글씨9개·모바일 하단 액션·마지막 입력 가림 없음 통과.
- 최근 통화 기본접힘→열기→검색→접기 접근 추가 확인.
- browser-e2e10 흐름 통과(기존 시험 이름의 'three columns'는 과거 제목이며 현재는 두 검토 패널+접힌 보조영역).
- 실제 원문 근거를 누른 후 연결선·강조, 품번/메모 저장, 사람확인·확정·재연락·출고/취소·새로고침 상태유지 통과.
- 모든 데이터는 가짜이며 외부AI·실계정 사용 없음. 현장 사용성·전체 보조기기 적합성 미검증.
