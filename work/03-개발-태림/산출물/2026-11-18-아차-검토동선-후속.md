# 아차 검토 동선 후속

## 이번 적용
- 주문 카드: 거래처/차량 요약 → 품목/수량 → 기본정보 편집 → 배송/요청사항. 기능은 숨기거나 삭제하지 않음.
- 수량/품목 편집 클릭은 편집만 수행. 명시적 근거 버튼에서만 대화 이동/재생을 요청함.
- 확정 전 확인 목록은 해당 입력/사람확인/질문해결 버튼으로 이동 가능.
- 지식 상세: 선택한 제목에 초점, 목록 복귀, 승인본/미적용 제안 구분. 검토 대기는 상단 노출, 이력만 접기.
- 연결 설정: 녹음 가져오기/글로 받아쓰기/주문 정리 3단계. 설정 상태를 실제 처리 성공으로 표시하지 않음.
- 기존 관리자 권한·토큰 교체/폐기 확인·30일·작업공간 불변·외부전송 동의 및 모든 API 유지.

## Montage 대조 (공식 문서 직접 확인)
- [Grid](https://montage.wanted.co.kr/docs/foundations/base-material/grid): 8px 기반, 4배수 간격 권장. 제품은 현재 기존 혼합 간격도 남아 있어 전체 토큰 준수를 주장하지 않음.
- [Typography](https://montage.wanted.co.kr/docs/foundations/base-material/typography): 본문 16/24, 라벨 14/20 등 역할 구분. 기존 앱 일부 12/13 보조 텍스트는 추가 검토 대상.
- [Semantic color](https://montage.wanted.co.kr/docs/foundations/base-material/colors/semantic): 브랜드는 중요 행동, 주의/오류는 상태로 분리. 모든 상자를 파랑으로 칠하지 않음.
- [Form control](https://montage.wanted.co.kr/docs/components/selection-and-input/form-control/design): 라벨/입력/메시지 역할과 초점·오류 연결 유지.
- [Popup](https://montage.wanted.co.kr/docs/components/presentation/popup/design): navigation/content/action 영역 구분, 긴 내용은 좌측 정렬·스크롤. 실제 제품은 native dialog + 자체 CSS이며 공식 React 패키지 설치/사용 아님. 긴 지식 폼은 제목/닫기 고정.
