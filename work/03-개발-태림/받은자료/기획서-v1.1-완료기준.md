## F01 녹음 올리기 · P0 · 화면 `#/upload`

- 목적: 이미 녹음된 주문 통화를 끌어다 놓기만 하면 서비스에 들어간다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 통화 목록 위 「녹음 올리기」를 누르거나 파일을 끌어다 놓는다
  2. 「가짜(연습) 녹음만 올립니다」 확인 체크
  3. 목록 맨 위에 「받아쓰기 기다리는 중」 → 「받아쓰는 중」으로 생긴다
  4. 다 되면 주문 카드가 「확인 필요」로 생긴다
- 완료 기준:
  - [ ] m4a · mp3 · wav 를 올리면 통화 목록 맨 위에 「받아쓰기 기다리는 중 / 받아쓰는 중」으로 나타난다
  - [ ] 받아쓰기가 끝나면 주문 카드가 「확인 필요」로 생긴다
  - [ ] 너무 크거나(10MB · 5분 초과) 오디오가 아니면 이유가 한국어로 뜬다
  - [ ] 가짜 녹음 예시 파일을 내려받아 바로 시험할 수 있다

## F02 받아쓰기 (통화 글) · P0 · 화면 `#/calls/:id`

- 목적: 통화를 처음부터 다시 듣지 않고, 문장마다 시각이 붙은 글로 읽는다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 통화를 누르면 상세 화면이 열린다
  2. 위에는 녹음 재생 막대, 아래에는 문장마다 시각(0:42)이 붙은 글
  3. 문장을 누르면 그 시각부터 재생된다
  4. 화면 위에 받아쓰기 일꾼 상태(켜짐 / 대기 중)가 보인다
- 완료 기준:
  - [ ] 통화 상세에 문장마다 시각이 붙은 글이 나온다
  - [ ] 문장을 누르면 그 대목부터 녹음이 재생된다
  - [ ] 새 녹음은 받아쓰기 일꾼(대표님 PC GPU)이 켜져 있을 때 받아써진다. 꺼져 있으면 「받아쓰기 일꾼 대기 중」으로 줄을 선다
  - [ ] 미리 넣은 가짜 통화 54건(합성 음성 · 문장별 시각)으로 나머지 기능은 언제나 체험된다

## F03 실시간 받아쓰기 체험 · P0 · 화면 `#/live`

- 목적: 말하는 즉시 화면에 글이 써지고, 말을 멈추면 주문 카드가 채워지는 경험을 바로 보여 준다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 「실시간 체험」 화면에서 마이크 단추를 누른다(마이크 허락 · 「소리는 브라우저 회사가 받아씁니다 — 지어낸 주문만 말하세요」 안내)
  2. 말하는 동안 글이 한 줄씩 써진다
  3. 말을 멈추면 AI 가 카드를 채운다(몇 초)
  4. 지원하지 않는 브라우저는 「샘플 대화 재생」으로 같은 흐름을 본다
- 완료 기준:
  - [ ] 마이크 단추를 누르고 말하면 몇 초 안에 글이 써진다
  - [ ] 말을 멈추면 카드의 차종 · 부품 · 수량 · 급함 칸이 채워진다
  - [ ] 크롬 · 엣지 · 안드로이드 크롬에서 마이크로 동작하고, 아이폰 사파리 · 파이어폭스에서는 「샘플 대화 재생」으로 같은 흐름이 나온다
  - [ ] 체험 화면에 소리가 어디로 가는지 안내가 보인다

## F04 주문 카드 자동 정리 · P0 · 화면 `#/calls/:id`

- 목적: 받아쓴 글에서 주문에 필요한 것만 뽑아 한 장의 카드로 만든다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 받아쓰기가 끝나면 AI 가 카드 초안을 만든다(낱말 사전 · 거래처 목록 참고)
  2. 카드 칸: 통화 종류(주문 · 배송 문의 · 반품 · 교환 · 재고 · 단가 문의 · 기타) · 거래처 · 차종(세대) · 연식 · 차번호 · 부품(이름 · 수량 · 좌우 · 불러 준 품번) · 급함 · 배송/수령 · 원하는 때 · 다시 물어볼 것 · 메모
  3. 부품이 여럿이면 줄이 여럿. 차가 둘이면 메모에 나눠 적고, 「아까 그거 하나 더」처럼 앞 통화를 가리키면 다시 물어볼 것에 넣는다
  4. AI 가 채운 칸에는 「AI 초안」 표시
- 완료 기준:
  - [ ] 가짜 통화 하나를 열면 카드의 각 칸이 채워져 있다
  - [ ] 고쳐 말한 수량은 마지막 값으로 나온다
  - [ ] 한 통화에 부품이 여럿이면 줄이 여럿 생긴다
  - [ ] 통화에서 말하지 않은 품번은 비어 있다(AI 가 지어내지 않는다)
  - [ ] 주문이 아닌 통화(배송 문의 등)는 통화 종류가 표시되고 부품 줄이 비어도 정상이다

## F05 근거 표시 · 「들어 보기」 · P0 · 화면 `#/calls/:id`

- 목적: AI 가 틀릴 수 있는 곳을 숨기지 않고, 「두 개라고 했다 / 안 했다」를 녹음으로 바로 확인한다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 카드의 칸(부품 · 수량 · 차번호 등)을 누른다
  2. 통화 글에서 그 말을 한 문장이 색으로 표시되고 화면이 그리로 간다
  3. 녹음이 그 시각부터 재생된다
  4. 의심 값에는 노란 「들어 보기」 표시와 이유(예: 차번호 가운데 글자 빠짐)
- 완료 기준:
  - [ ] 카드의 칸을 누르면 근거 문장이 색으로 표시되고 녹음이 그 시각부터 재생된다(녹음이 없는 일부 대본 통화는 문장 표시까지)
  - [ ] 차번호 한글 빠짐 · 품번 자릿수 이상 · 비슷한 거래처 둘 같은 값에 「들어 보기」와 이유가 붙는다
  - [ ] 통화 글에서 부품 · 수량 · 차 같은 주문 내용이 색으로 강조된다

## F06 카드 고치기 · 확정 · P0 · 화면 `#/calls/:id · #/board`

- 목적: 사람이 확인한 주문만 「확정」되어 출고로 넘어간다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 칸을 눌러 고친다(고친 칸은 「사람이 고침」 표시)
  2. 「다시 물어볼 것」이 남아 있으면 확정 단추가 이유와 함께 막힌다(「해결함」으로 지운다)
  3. 「확인하고 확정」 → 주문 카드 보드 · 출고 목록의 확정 칸에 나타난다
  4. 출고하면 「출고 완료」로 바뀐다
- 완료 기준:
  - [ ] 칸을 눌러 고칠 수 있고 새로 고쳐도 남는다(서버 저장)
  - [ ] 상태가 「확인 필요 → 확정 → 출고 완료」로 바뀐다
  - [ ] 「다시 물어볼 것」이 남아 있으면 확정이 막히고 이유가 보인다
  - [ ] AI 초안 값과 사람이 고친 값이 구분돼 보인다

## F07 낱말 사전 (현장 말 · 거래처 · 차종) · P0 · 화면 `#/glossary`

- 목적: 휀다 · 쇼바 · 라지에다 같은 현장 말과 거래처 이름을 AI 가 맞게 알아듣게 한다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 「낱말 사전」 화면에 현장 말 · 거래처 · 차종 세 칸
  2. 「현장 말 → 표준 말」 한 줄을 넣거나 지운다
  3. 사전은 받아쓰기 힌트와 카드 정리 둘 다에 쓰인다
  4. 통화 화면의 「AI 로 다시 정리」로 새 사전을 반영해 카드를 다시 만든다(사람이 고친 칸은 그대로)
- 완료 기준:
  - [ ] 사전에서 한 줄을 넣고 지울 수 있다
  - [ ] 가짜 거래처 목록 · 차종 목록이 미리 들어 있다
  - [ ] 넣은 뒤 「AI 로 다시 정리」를 누르면 고친 낱말이 카드에 반영되고, 사람이 고친 칸은 그대로 남는다

## F08 통화 찾기 · P0 · 화면 `#/calls?q=`

- 목적: 시간순으로만 쌓인 녹음에서 원하는 통화를 낱말 · 날짜 · 거래처로 바로 찾는다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 통화 목록 위 검색칸에 낱말을 친다
  2. 날짜 · 거래처 · 상태(확인 필요 / 확정 / 출고 완료)로 거른다
  3. 결과마다 낱말이 든 문장이 굵게 보인다
  4. 누르면 그 통화의 그 대목으로 가서 재생할 수 있다
- 완료 기준:
  - [ ] 검색어가 들어간 통화만 남는다(통화 글 · 카드 내용 모두)
  - [ ] 결과에 해당 문장이 굵게 보인다
  - [ ] 결과를 누르면 그 통화의 그 대목으로 간다
  - [ ] 날짜 · 거래처 · 상태 거르기가 된다

## F09 지난 통화에 묻기 · P0 · 화면 `#/ask`

- 목적: 사람에게 묻듯 물어서 지난 통화 사실을 근거와 함께 확인한다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 「묻기」 칸에 질문을 쓴다(예시 질문 단추도 있다)
  2. AI 가 저장된 통화 글 · 카드만 보고 답한다
  3. 답 아래에 근거 통화(거래처 · 날짜 · 시각)와 그 문장이 붙는다
  4. 근거를 누르면 그 대목이 재생된다
- 완료 기준:
  - [ ] 질문하면 답과 근거 통화 · 문장이 함께 나온다
  - [ ] 근거를 누르면 그 통화의 그 대목으로 가서 재생된다
  - [ ] 근거가 없으면 「찾지 못했어요」라고 답하고 지어내지 않는다

## F10 오늘 브리핑 · 할 일 · P0 · 화면 `#/ (첫 화면)`

- 목적: 하루 주문 흐름과 남은 일(확인 필요 · 급한 미출고 · 다시 전화할 곳)을 한 화면에서 본다.
- 데모 범위: 실제 동작
- 화면 흐름:
  1. 첫 화면(오늘 브리핑)에 숫자 타일 5개(오늘 통화 · 주문 카드 · 확인 필요 · 급한데 출고 전 · 다시 전화할 곳)
  2. 할 일 목록: 확인 필요 카드 · 급한 미출고 · 다시 전화할 곳(되물을 말 포함)
  3. AI 한 단락 요약과 「AI 가 고른 먼저 할 일」
  4. 「마감 요약 복사」 → 메신저에 붙여 넣는다
- 완료 기준:
  - [ ] 오늘 통화 수 · 주문 카드 수(통화 종류가 주문인 것) · 확인 필요 · 급한 미출고가 숫자로 나오고, 주문이 아닌 통화는 종류별 개수가 한 줄로 나온다
  - [ ] 다시 전화할 곳이 거래처 · 되물을 말과 함께 목록으로 나온다
  - [ ] 「마감 요약 복사」를 누르면 붙여 넣을 수 있는 글이 복사된다

## P1

### F11 걸려 온 번호로 거래처 맞추기 · 화면 `#/calls/:id`

- 목적: 받아쓰기로 틀리기 쉬운 상호를 전화번호로 확실히 한다.
- 데모 범위: 가짜 번호 · 거래처
- [ ] 녹음에 걸려 온 번호(가짜)가 있으면 카드의 거래처가 목록의 이름으로 채워지고 「번호로 확인」 표시가 붙는다. 화면에서는 번호 가운데를 가린다.

### F12 녹음 폴더 자동 보내기 · 화면 `PC 프로그램 → #/upload 안내`

- 목적: 대리점 PC 녹음 폴더에 새 파일이 생기면 알아서 서버로 간다.
- 데모 범위: PC 프로그램(Node) · 가짜 녹음만
- [ ] 폴더에 가짜 녹음을 넣으면 1분 안에 사이트 통화 목록에 나타난다. 같은 파일은 두 번 들어가지 않는다.

### F13 거래처별 통화 모아 보기 · 화면 `#/customers/:name`

- 목적: 한 정비소와의 통화 · 주문을 시간순으로 본다.
- 데모 범위: 실제 동작
- [ ] 거래처 이름을 누르면 그 거래처의 통화 · 카드가 날짜순으로 나온다.

### F14 출고 목록 내보내기 · 화면 `#/shipping`

- 목적: 확정 주문을 이 기사가 들고 나갈 목록으로 만든다.
- 데모 범위: 실제 동작(인쇄 · CSV)
- [ ] 확정 카드만 거래처별로 묶여 나오고, 인쇄 · CSV 내려받기가 된다.

### F15 큰 글씨 · 쉬운 보기 · 화면 `모든 화면 위 막대`

- 목적: 돋보기 없이 읽게 한다.
- 데모 범위: 실제 동작
- [ ] 「글씨 크게」를 누르면 전체 글씨가 커지고, 다시 열어도 유지된다.

## 모든 화면 공통

- [ ] 휴대폰 · 태블릿 · PC 어디서나 열린다. 로그인 없이 누구나 데모를 본다
- [ ] AI 가 채운 칸은 「AI 초안」으로 보이고, 사람이 고치거나 확정하면 표시가 바뀐다
- [ ] 품번은 통화에서 불러 준 것만 적는다. AI 가 찾거나 지어내지 않는다
- [ ] 사람이 고친 칸은 「다시 정리」해도 AI 가 덮어쓰지 않는다
- [ ] 본문 글씨는 크게(17px 이상), 버튼은 손가락으로 누르기 쉽게, 말은 현장 말로
- [ ] 데모의 통화는 모두 가짜다. 「가짜 통화」 표시, 올리기 화면에 「실제 녹음은 올리지 마세요」 확인
