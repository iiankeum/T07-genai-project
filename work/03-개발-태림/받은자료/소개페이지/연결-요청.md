# 소개 페이지 연결 요청 — 마케팅(강현 방) → 개발(태림 방)

> AI 초안 · 돌린 사람: 배*결 · Claude Code(Opus 5.5) · 강현(마케팅) 작업방 · 2026-11-11 · 원본은 `work/02-마케팅-강현/산출물/소개페이지/`
> 이 폴더는 마케팅 방이 넣은 **사본**이다. 고칠 일이 있으면 마케팅 방 원본을 고치고 다시 넣는다.

## 1. 어디에 올리나
- 설계.md 의 `/intro/` 그대로: 이 폴더의 4개 파일을 `src/app/public/intro/` 에 넣으면 `https://t07.3-39-67-126.sslip.io/intro/` 가 된다.
  - `index.html` · `intro.js`(동작 · 설정) · `privacy.html`(개인정보 처리방침 시안) · `og.png`(카톡 미리보기 1200×630)
- 사이트 CSP(`script-src 'self'`)에 맞췄다. 인라인 스크립트 없음, 인라인 스타일만 있음(`style-src 'unsafe-inline'` 허용 범위), 글꼴은 Google Fonts.
- 앱의 `#/trial` 은 `/intro/#signup` 으로 보내거나 같은 항목으로 만들어 달라(둘 중 편한 쪽).
- 앱 위 막대나 도움말 어딘가에 「무료 체험 신청」 → `/intro/#signup` 링크가 있으면 좋다.

## 2. 신청 API — `POST /api/trial-signup` (개발 방 답 2026-11-11 23시대에 맞춤)
`intro.js` 의 `CONFIG.signupEndpoint` 가 `/api/trial-signup` 이다(같은 주소 상대 경로, `Content-Type: application/json`). 주소가 바뀌면 그 한 줄만 바꾸면 된다.
설계.md 의 `/api/trial` 기본 칸(`name · org · contact · role · message · consent`)도 같은 본문에 함께 실어 보내므로, 어느 쪽 이름으로 받아도 된다.
**`industry` 는 선택이다**(최소 수집 조사 결과 필수에서 뺐다 — 비어 있으면 `''`). 필수는 `name` · (`phone` 또는 `email`) · `consentPrivacy:true` 셋뿐이다.
「데모 체험」 버튼은 같은 서버 상대 경로 `/` 로 간다(`/?from=intro&src=…`). 파일로 열어 볼 때만 전체 주소를 쓴다.

보내는 JSON(설계 기본 칸 + 마케팅 추가 칸):

| 칸 | 값 | 필수 | 메모 |
|---|---|---|---|
| `name` | 문자열 ≤40 | 필수 | 호칭도 됨 |
| `org` | `''` | — | 상호는 받지 않는다(최소 수집) |
| `contact` | 휴대폰 숫자만(`01012345678`) 또는 이메일 | 필수 | 둘 중 하나 |
| `role` | `부품 대리점 · 도매` / `정비소` / `다른 도매업` / `그 밖` / `''` | 선택 | |
| `message` | 문자열 ≤500 | 선택 | |
| `consent` | `true` | 필수 | 필수 동의 |
| `phone` · `email` | `contact` 를 나눠 담은 것 | — | 하나는 `''` |
| `industry` | `parts-dealer` · `repair-shop` · `other-wholesale` · `other` · `''` | 선택 | `role` 의 코드 |
| `callsPerDay` | `lt10` · `10-30` · `30-100` · `100+` · `unknown` · `''` | 선택 | |
| `region` | 시 · 도 이름 또는 `''` | 선택 | |
| `recordingSetup` | `office-phone` · `mobile-auto` · `none` · `unknown` · `''` | 선택 | |
| `heardFrom` | `instagram` · `threads` · `kakao-openchat` · `naver-cafe` · `band` · `referral` · `offline` · `search` · `other` · `''` | 선택 | |
| `interviewOk` | boolean | 선택 | 15분 전화 인터뷰 가능 |
| `consentPrivacy` | `true` | 필수 | `consent` 와 같은 뜻 |
| `consentMarketing` | boolean | 선택 | **선택 동의(홍보 연락).** `true` 일 때만 소식 문자 · 메일을 보낼 수 있다 |
| `source` | 주소의 `?src=` 값(없으면 `direct`) ≤40 | — | **채널별 성과를 세는 핵심 칸** |
| `pageVersion` | `intro-draft-2026-11-12` | — | |
| `website` | 보통 `''` | — | 스팸 막기 숨은 칸. **채워져 오면 저장하지 말고 `200 {ok:true}` 만** 돌려준다 |

응답: 성공은 `200 {"ok": true}`. 실패는 설계대로 `{error, message}` + 4xx — `message` 를 화면에 그대로 보여 준다(한국어로). `404` 면 「아직 연결 안 됨」 안내가 뜬다.

## 3. 부탁(우선순위 순)
1. `trials` 표에 칸 더하기: `consent_marketing`(+동의 시각) · `source` · `heard_from` · `interview_ok` · `industry` · `calls_per_day` · `region` · `recording_setup` · `page_version`. 못 하면 `source` 와 `consent_marketing` 만이라도. **동의 시각(`consent_at`)은 꼭** — 언제 동의했는지 증명용.
2. 서버 검사: `name` 비었거나 `phone`(010 등 10~11자리 숫자) · `email` 둘 다 모양이 아니면 400 `{error:'bad_contact', message:'휴대폰 번호나 이메일을 다시 확인해 주세요.'}`. `consentPrivacy !== true` 면 400. 같은 IP 1시간 3건 넘으면 429 — `message` 를 화면에 그대로 보여 준다(예: 「잠시 뒤 다시 시도해 주세요」).
3. 숫자 세기(관리자만): 체험 신청 수 — 전체 · `source` 별 · `industry` 별 · 날짜별. 관리자 화면 `GET /api/admin/trials` 에 묶음 숫자가 함께 나오면 마케팅 기록(`docs/promotion/`)에 바로 옮길 수 있다. 연락처는 관리자 화면 밖으로 내보내지 않는다.
4. 방문 수: `/intro/` 과 데모(`/?from=intro&src=…`) 요청 수를 `src` 별로 하루 단위로 세 주면 좋다(개인 식별 없이 숫자만). 어렵다면 Caddy 접속 기록에서 세는 방법만 알려 달라.
5. `og:image` 는 `https://t07.3-39-67-126.sslip.io/intro/og.png` 로 적어 두었다. 주소가 다르면 `index.html` 머리의 meta 한 줄을 바꾼다.

## 4. 지켜 달라는 것(동의 문구에 이렇게 약속했다)
- 신청 정보는 **서버 안에만** 둔다. 저장소 · 로그 · 알림 메일 · 단체 대화방에 이름 · 연락처를 남기지 않는다(새 신청 알림은 「새 신청 1건」만).
- 다른 회사(팀원 회사 포함)에 넘기지 않는다.
- 2026-12-31(가정) 이후 일괄 삭제(백업 포함). 그 전에도 삭제 요청이 오면 지울 수 있게 관리자 삭제가 있으면 좋다.
- 외국 설문 · 메일 서비스(구글 폼 등)를 붙이지 않는다. 붙이면 처리방침부터 고쳐야 한다.
- AWS 지역(서울인지)을 알려 주면 `intro.js` 의 `CONFIG.storage` 와 `privacy.html` 을 채운다.

## 5. 시험한 것
- 이 폴더를 개발 사이트와 같은 CSP 헤더 + 가짜 `POST /api/trial-signup` 로 띄워(로컬) 신청 → 「접수됐습니다」 → 「다른 분께 보내기」까지 콘솔 오류 없이 동작했다. 받은 JSON 은 위 표와 같다. 휴대폰 번호에 띄어쓰기를 넣어도 숫자만 보낸다.
- 휴대폰 폭 375px 에서 가로 넘침 없음. 빈 칸 제출 시 오류 3개(이름 · 연락처 · 동의)가 글로 뜬다.
- 실제 사이트에서는 아직 못 해 봤다.
