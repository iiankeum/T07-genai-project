Node와 부모 파이프 종료 확인
  python3 - <<'PY'
from pathlib import Path
from subprocess import Popen, PIPE

bundle = Path('out/Ahmatda.app/Contents').resolve()
node = bundle / 'MacOS/node'
boot = bundle / 'Resources/parent-lifetime.mjs'
probe = 'process.on("SIGTERM", () => { console.log("eof-triggered-termination"); process.exit(0); }); console.log("ready"); setInterval(() => {}, 1000);'
with Popen([node, '--import', boot, '-e', probe], stdin=PIPE, stdout=PIPE, stderr=PIPE, text=True) as child:
    assert child.stdout.readline().strip() == 'ready' and child.poll() is None
    child.stdin.close()
    child.stdin = None
    output, error = child.communicate(timeout=5)
    assert child.returncode == 0 and output.strip() == 'eof-triggered-termination', (child.returncode, output, error)

소스 검토
정상 실행 경로에서 부모만 파이프 쓰기 쪽을 유지한다. 앱이 종료되면 쓰기 쪽을 닫고 Node에 SIGTERM을 보낸다. Node는 HTTP 서버를 닫고, 서버가 닫히지 않더라도 3초 이후 종료하도록 처리한다. 아맞다 창은 동일 origin 이동만 허용한다. 로컬 프로세스는 루프백 바인딩과 유료 AI 비활성화를 명시하고 자식 환경에 실행에 필요한 값을 선별 전달한다.
앱의 WebView origin 정책은 Node HTTP 서버 자체의 Host 정책과 별개다. 로컬 서버에 고정 Host 검사는 없다. 공개 상태 조회·인증 전 요청 수용 가능성에 해당하며, 로그인 쿠키는 host-only이고 제품 API에는 유효한 계정과 워크스페이스가 필요하다. 외부 사이트에서 연결되는 경우나 인증된 업무 자료 접근을 실제 재현하지 않았다.

검증 범위
ad hoc 서명은 이 로컬 패키지 기준이다. Developer ID 배포 서명과 공증은 완료 범위에 포함되지 않는다. 네트워크 및 루프백 권한 제한으로 WebKit 화면, GUI 인증·업로드, 실제 Ollama 및 Whisper 모델 추론, 완전 오프라인 업무 흐름을 검증하지 않았다. 운영 자료와 유료 API는 사용하지 않았다.
