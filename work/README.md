## 폴더 안의 모양

```
work/<번호>-<역할>-<이름>/
  README.md     # 이 역할이 맡은 일, 지금 상태, 산출물 목록
  LOG.md        # 작업 기록 — 새 기록이 맨 위
  산출물/        # 남에게 넘기는 최종본(기획서 PDF, 계획서 등)
  자료/          # 조사 메모, 그림, 중간 결과
  받은자료/      # 다른 역할이 넘겨 준 것(넘기는 쪽이 새 파일로만 넣는다)
```

## AI 가 작업했을 때 기록하는 법

자세한 규칙은 [AGENTS.md](../AGENTS.md)의 「AI 작업 기록 규칙」이 기준이다.

```markdown
## 2026-11-12 01:30 KST · 한 줄 제목
- 돌린 사람 · 도구: 배*결(dmms0830-lang) · Claude Code(Opus 5.5) · 남희(기획) 작업방
- 한 일:
- 왜:
- 어떻게: 조사 방법 · 에이전트 수 · 참고한 자료
- 결과물: [파일](경로)
- AI 가 판단한 것 · 사람이 확인할 것:
- 다음 할 일:
```
