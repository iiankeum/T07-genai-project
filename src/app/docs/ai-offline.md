# 과금 없이 AI 경로 시험하기

> AI 초안 · Codex · 태림(개발) 작업방 · 2026-11-18

Node.js 24부터 실행할 수 있다.

```bash
cd src/app
npm run start:offline
npm run test:offline
```

`start:offline`은 `AI_PROVIDER=fixture`를 강제한다. 환경에 Claude 키나 운영 설정이 있어도 외부 모델 API를 부르지 않는다. `test:offline`은 임시 데이터 폴더에 가짜 WAV를 올리고, 일꾼이 받아쓴 형태의 가짜 결과를 보내고, 주문 카드·브리핑·묻기 API를 확인한다. 실제 GPU, 모델 키, ffmpeg가 필요 없다.

브라우저에서 실시간 받아쓰기 페이지를 열고 「샘플 대화 재생」을 누르면 새한카센터 가짜 대화의 주문 수량이 두 개에서 세 개로 바뀐다. 오늘 화면에서는 「AI 요약 만들기」를 눌러 예시 브리핑을 만든다. 「지난 통화에 묻기」의 예시 질문은 저장된 문장이나 카드에 연결한다. 가짜 응답은 화면과 API에 표시한다. 샘플에 없는 글은 빈 카드로 저장해 직접 채울 수 있다.

## 제공자 설정

| 서버 설정 | 카드 정리 · 브리핑 · 묻기 |
|---|---|
| `AI_PROVIDER=off` | 꺼짐. 서버의 기본 설정이다. |
| `AI_PROVIDER=fixture` | 등록된 샘플 대화와 저장된 기록을 바탕으로 결정적인 테스트 응답을 돌려준다. |
| `AI_PROVIDER=anthropic` | `ALLOW_PAID_AI=1`, `ANTHROPIC_API_KEY`, 작업공간의 전체 AI 허용이 있을 때만 Claude를 부른다. `CLAUDE_MODEL`로 모델을 고른다. |

외부 모델 호출을 꺼 둔 작업공간은 서버에 키가 있어도 호출하지 않는다. 마스킹 설정에서도 마스킹 경로가 준비될 때까지 외부 전송을 막는다. 앱에 등록한 테스트 응답은 외부 모델 설정과 독립적으로 동작한다.

업로드한 녹음은 일감으로 등록된다. 실제 환경에서 받아쓰기는 연결된 일꾼이 한다. 일꾼이 보낸 글로 서버가 카드 초안을 정리한다. 브라우저의 실시간 마이크 체험은 브라우저 음성 인식으로 받아쓴 글을 서버에 보낸다. 브라우저 음성 인식 서비스의 연결 조건은 브라우저에 따라 다르다. 샘플 대화 체험은 브라우저 음성 인식과 원본 음성을 쓰지 않는다.

## 제공자 교체

`lib/ai.mjs`의 제공자 호출은 작업 종류, 입력 자료, 프롬프트, 동일한 JSON 스키마를 받아 `{ data, model }`을 돌려준다. 수량·품번 검증과 근거 대목 연결은 카드 파이프라인에서, 할 일과 인용의 참조 확인은 브리핑과 묻기에서 맡는다. 로컬 모델을 연결할 때도 이 계약을 유지한다. 중단 신호는 외부 모델 호출 옵션으로 전달한다.
