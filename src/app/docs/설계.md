# 콜노트(가칭) 데모 사이트 설계

> AI 초안 · 돌린 사람: 배*결 · Claude Code(Opus 5.5) · 태림(개발) 작업방 · 2026-11-11 · 검토 전
> 기준 문서: 기능목록 v0(`work/03-개발-태림/받은자료/기능목록-v0.md`, F01~F15). 기획서 PDF v1 이 오면 그것이 기준이다.

## 1. 한 장 구조

```
 휴대폰·태블릿·PC 브라우저 ──HTTPS──▶ Caddy(80/443) ──▶ node src/app/server.mjs (127.0.0.1:5600, RAM 300MB 안)
   │  화면: public/ (빌드 없는 ES 모듈 · 해시 라우팅)            │
   │  실시간 받아쓰기: Web Speech API(ko-KR, 브라우저 회사 서버)   ├─ node:sqlite  DATA_DIR/callnote.sqlite
   │                                                             ├─ 오디오      DATA_DIR/audio/<callId>.wav (16kHz mono)
 녹음 PC 프로그램 ──POST /api/ingest (INGEST_TOKEN)──────────────▶├─ ffmpeg: 올린 원본 → 16k mono WAV (원본은 지움)
 받아쓰기 일꾼(GPU PC, Whisper) ◀──claim/result (WORKER_TOKEN)──▶├─ 일감 줄(jobs) · 일꾼 상태(workers)
                                                                 └─ Claude API(서버에서만): 카드 추출 · 브리핑 · 묻기
```

- **빌드 없음 · 의존성 하나**(`@anthropic-ai/sdk`). 서버 RAM 1GB 를 실서비스와 나눠 쓰므로 가볍게.
- **비밀값은 서버 환경변수에만.** 브라우저 코드 · 응답 · 로그 · 저장소에 넣지 않는다. AI 호출은 모두 서버에서.
- **누구나 쓰는 사이트**: 돈이 드는 동작(AI · 올리기)은 IP 별 빈도 제한 + 하루 전체 상한. 지우기 · 초기화 · 체험 신청 보기는 관리자 암호로만.
- **가짜 데이터만**: 모든 화면 위에 「가짜 통화 데모」 띠. 올리기 화면은 「실제 녹음은 올리지 마세요」 + 확인 체크.

## 5. API 모양 (화면 ↔ 서버 계약)

공통: JSON. 실패는 `{error: "짧은_코드", message: "한국어 설명"}` + 4xx/5xx. 쓰기 요청은 `Content-Type: application/json` 만 받는다(교차 사이트 위조 막기).

### 5.1 통화(call) 모양 — `callView()`
```json
{
  "id": "call_...", "recordedAt": "2026-11-11T05:42:00.000Z", "source": "seed|upload|ingest|live",
  "status": "queued|transcribing|extracting|ready|failed", "statusLabel": "받아쓰는 중",
  "title": "새한카센터 · 앞범퍼 · 14:42 · 0:24", "customer": "새한카센터",
  "callerNumber": "010-****-4829", "durationSec": 24.3, "hasAudio": true, "isFake": true,
  "summary": "아반떼 AD 앞범퍼 1개, 오전 배송", "error": null,
  "card": { ...카드 모양 또는 null },
  "transcript": "...(상세에서만)", "segments": [{"start":0,"end":1.4,"text":"...","speaker":"A"}]
}
```
### 5.2 카드(card) 모양 — `cardView()`
```json
{
  "status": "draft|confirmed|shipped|cancelled", "statusLabel": "확인 필요|확정|출고 완료|취소",
  "callType": "주문|배송 문의|반품·교환|재고·단가 문의|기타",
  "customer": "새한카센터", "customerByPhone": false, "contact": "김 실장",
  "carModel": "아반떼 AD", "modelYear": "2017", "plate": null,
  "items": [{"part": "앞범퍼", "side": null, "qty": 1, "partNo": null, "quote": "앞범퍼 하나 있어요", "at": 1.6}],
  "urgent": true, "due": "오전 중", "delivery": "배송",
  "askBack": ["LED 인지 일반인지"], "unsure": [{"field": "plate", "reason": "차번호 가운데 한글이 빠졌을 수 있음", "at": 3.1}],
  "fixes": [{"heard": "헨더", "fixed": "휀다"}],
  "evidence": {"customer": {"quote": "새한카센터인데요", "at": 1.6}, "carModel": {...}, "plate": {...}, "urgent": {...}, "due": {...}},
  "note": null, "callback": false, "callbackReason": null,
  "edited": ["qty"], "aiDraft": { ...AI 가 처음 만든 같은 모양 }, "aiError": null, "aiModel": "claude-opus-5-5",
```

## 6. AI(Claude) 쓰는 곳 — `lib/ai.mjs`

- SDK `@anthropic-ai/sdk` 1.8.0, 모델 `claude-opus-5-5`(환경변수 `CLAUDE_MODEL` 로 바꿈). `output_config: {effort: 'low', format: {type: 'json_schema', schema}}` 로 구조화 출력. 거절은 `stop_reason === 'refusal'` 을 먼저 보고 「AI 가 답하지 않았습니다」로 처리. 서버 쪽 대체 모델(`fallbacks: "default"`, 베타 `server-side-fallback-2026-07-01`)을 켠다.
- effort 를 `low` 로 둔 까닭: 카드 추출은 대표님 프로토타입이 `--effort low` 로 10건 평가를 통과했고, 누구나 쓰는 데모라 비용 · 기다림을 줄인다. 브리핑 · 묻기도 짧은 글이라 `low`. 모델은 바꾸지 않았다.
- 키가 없으면 AI 기능만 「AI 키 없음」을 보이고 나머지는 돈다.

| 함수 | 입력 | 출력 |
|---|---|---|
| `extractCard({transcript, segments, glossary, customers, carModels})` | 받아쓴 글 | 카드 초안(근거 문장 포함) |
| `writeBriefing({day, stats, cards})` | 오늘 숫자 · 카드 요약 | `{paragraph, todos:[{title, why, callId}]}` |
| `answerQuestion({question, history, contexts})` | 질문 + 찾은 통화 문장들(번호 붙임) | `{answer, found, citations:[{callId, segIndex}]}` |

### 카드 규칙(대표님 프로토타입 `ordercard.py` 를 잇는다)
- 통화에서 말한 것만. 말하지 않은 칸은 비운다. **품번은 불러 준 것만**(서버가 한 번 더 검사해 글에 없는 품번은 지우고 「들어 보기」로 돌린다).
- 수량을 고쳐 말했으면 마지막 값. 위치(운전석 · 좌우)는 `side` 로.
- `askBack`: 통화에서 묻고 답이 안 정해진 것만. `unsure`: 받아쓰기가 틀렸을 수 있는 값(차번호 한글 빠짐 · 품번 자릿수 · 비슷한 거래처 둘).
- 거래처는 사전의 거래처 목록 표기로 맞춘다. 걸려 온 번호가 목록의 가짜 번호와 같으면 그 이름으로 채우고 `customerByPhone: true`(F11).

## 7. 화면

- 모바일 우선. 폭 < 900px: 아래 탭 막대(오늘 · 통화 · 실시간 · 묻기 · 더보기). 900px 이상: 왼쪽 메뉴. 태림 님 시안(보라 `#7863da` · Noto Sans KR · 둥근 카드)을 잇되 글씨를 키운다(본문 17px, 큰 글씨 켜면 20px).
- 모든 화면 위: 「가짜 통화 데모」 띠 · 일꾼 상태(켜짐/대기 중) · 「글씨 크게」.
- 통화 상세: 위에 오디오 막대, 왼쪽(모바일은 위) 통화 글, 오른쪽(모바일은 아래) 주문 카드. 카드 칸을 누르면 글의 그 문장이 칠해지고 그 시각부터 재생된다.
- 사용자 입력은 모두 `ui.js` 의 이스케이프 템플릿으로 그린다(innerHTML 에 날 글을 넣지 않는다).
- 홈 화면에 추가: `manifest.webmanifest` + 아이콘 + 아무것도 저장하지 않는 `sw.js`.

## 8. 데모 데이터

- 시드: 대표님 프로토타입의 가짜 통화 10건(대본 · 정답 카드, 거래처 · 차번호 · 품번 모두 지어냄)을 받아쓴 글 · 문장 시각 · 카드로 바꿔 넣는다. 오디오는 없다(「녹음 없음 · 대본으로 만든 가짜 통화」 표시).

- 날짜 굴리기: 서버가 뜰 때와 한 시간마다, 오늘 통화가 하나도 없으면 시드 통화 날짜를 오늘로 옮긴다(「오늘 브리핑」이 늘 살아 있게).

## 9. 보안 점검표

- CSP `script-src 'self'`(인라인 스크립트 없음) · `frame-ancestors 'none'` · nosniff · HSTS · Referrer-Policy · Permissions-Policy(마이크는 이 사이트만).
- 쓰기 요청: JSON 만 · Origin 검사 · 관리자 쿠키 `HttpOnly; SameSite=Strict; Secure`.
- 업로드: 크기 → 형식(파일 머리 바이트 + ffprobe) → 길이 순으로 막고, 원본은 변환 뒤 지운다. 일꾼에게는 변환한 WAV 만.
- IP 는 해시로만 저장. 체험 신청은 관리자만 본다. 로그에 본문 · 토큰을 남기지 않는다.
- 저장소: `.data/` · `.env` · 녹음은 `.gitignore`. gitleaks(CI)로 확인.

## 10. 통합 때 더한 것
- **통화 종류(callType)**(남희 방 요청): 주문 / 배송 문의 / 반품·교환 / 재고·단가 문의 / 기타. AI 가 고르고 사람이 고칠 수 있다. 주문이 아니면 부품 줄이 없어도 확정된다. 브리핑의 「주문 카드」 수는 종류=주문만, 나머지는 종류별 개수.
- **다시 정리 덮어쓰기 규칙**(남희 방 요청): 사람이 고친 칸(edited)은 「AI 로 다시 정리」해도 그대로 두고, 빈칸 · AI 초안 칸만 새 값으로 바꾼다. AI 초안(aiDraft)은 새 값.
- **시드**: 해결사 방 가짜 통화 54건(`seed/calls-fx.json`, 문장별 실제 시각 · 근거 인용 · 다툼 시나리오 3쌍). 합성 음성은 저장소 밖에 있고 `POST /api/admin/seed-audio` 로 서버에 붙인다. 처음 시드(대표님 프로토타입 10건 + 지은 10건)는 `seed/archive/` 로 옮기고 시험용으로만 쓴다. 가장 늦은 시드 통화가 지금보다 뒤면 전체를 당긴다(새벽 시연 대비).
