# 콜노트 PC 프로그램 — 받아쓰기 일꾼 · 녹음 폴더 감시

킥오프에서 한결(총괄)이 맡은 「녹음 폴더 → 서버 전송 프로그램」과 「Whisper 등 PC 안 모델」의 첫 버전이다.
대표님 프로토타입(call-order-card)의 받아쓰기 부분(faster-whisper large-v3 · GPU · 낱말 사전 힌트)을 출발점으로 했다.

```
[녹음 폴더] ──watch──▶ POST /api/ingest ──▶ [데모 서버] ─ ffmpeg 로 16kHz WAV 변환 · 일감 줄 세움
                                                  ▲  │
                         [받아쓰기 일꾼(이 PC, GPU)] ─┘  └─ 받아쓴 글 → Claude 로 주문 카드
                          claim → WAV 받기 → Whisper → result
```

서버 API 는 개발(태림) 방의 [`src/app/docs/worker-api.md`](../app/docs/worker-api.md) v1 을 따른다.

## 두 가지 일

| 모드 | 하는 일 |
|---|---|
| `worker` | 서버에서 받아쓰기 일감을 가져와 이 PC 의 Whisper 로 받아쓰고 결과를 돌려준다. 20초마다 「살아 있음」을 알린다(끊기면 사이트에 「받아쓰기 일꾼 대기 중」). |
| `watch <폴더>` | 폴더에 새 녹음이 생기면 서버로 올린다. 아직 쓰는 중인 파일은 기다리고(크기 · 시각이 그대로일 때만), 같은 내용(SHA-256)은 두 번 올리지 않고, 서버가 바쁘거나 인터넷이 끊기면 30초 · 1분 · 2분 … 최대 30분 간격으로 다시 보낸다. |
| `run <폴더>` | 위 둘을 한 번에. |
| `send <파일>` | 파일 하나를 바로 올린다(시험용). |
| `check` | 서버 주소 · 토큰 유무 · 서버 응답 · GPU 를 확인한다. 토큰 값은 찍지 않는다. |

## 설치 (윈도우)

준비물: Python 3.10 이상. NVIDIA 그래픽카드가 있으면 빠르다(없으면 CPU 로 느리게 돈다). **ffmpeg 는 필요 없다** — 일꾼은 서버가 바꿔 둔 WAV 만 받는다.

```
cd src\pc-agent
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pip install -r requirements-gpu.txt     # NVIDIA 그래픽카드가 있을 때만
```

처음 일꾼을 켜면 음성 인식 모델(약 3GB)을 내려받는다. 대표님 PC 에는 프로토타입 때 받은 것이 있어 바로 뜬다.

## 토큰 · 서버 주소

저장소 밖 비밀 폴더(`%USERPROFILE%\.t07-secrets\`)의 파일을 읽는다. 저장소에 넣지 않는다.

| 파일 | 줄 |
|---|---|
| `worker.env` | `SERVER_URL=https://t07.3-39-67-126.sslip.io` · `WORKER_TOKEN=…` |
| `ingest.env` | `SERVER_URL=…` · `INGEST_TOKEN=…` |

환경변수 `SERVER_URL` · `WORKER_TOKEN` · `INGEST_TOKEN` 이 있으면 그것이 먼저다. 토큰은 서버 관리자(한결 방)가 서버에서 만든 값이다.

## 실행

```
.venv\Scripts\python callnote_agent.py check
.venv\Scripts\python callnote_agent.py worker
.venv\Scripts\python callnote_agent.py watch D:\녹음\가짜통화
.venv\Scripts\python callnote_agent.py run D:\녹음\가짜통화 --name gpu-pc-1
.venv\Scripts\python callnote_agent.py send 가짜통화01.wav
```

- 멈출 때는 `Ctrl+C`. 받아쓰던 일감이 있으면 서버에 「다시 줄 세움」을 알리고 끝난다.
- 기록: `%LOCALAPPDATA%\callnote-agent\agent.log`, 폴더 감시 상태 `watch-<폴더 해시>.json`(어느 파일을 언제 올렸는지).
- 자주 쓰는 선택: `--skip-existing`(처음 켤 때 이미 있던 파일은 올리지 않음) · `--recursive`(하위 폴더까지) · `--device cpu` · `--model large-v3-turbo`.
- 재부팅 때 자동으로 켜는 설정은 아직 만들지 않았다(대표님이 정한다).

## 안전 약속

- **공개 데모 서버에는 가짜(연습) 녹음만 보낸다.** 프로그램은 `fake=true` 로 보내고, 서버는 가짜가 아닌 녹음을 거절한다. 실제 통화 녹음 폴더를 감시 폴더로 지정하지 않는다(실제 녹음은 동의 · 가림 절차를 정한 뒤 따로).
- 실제 통화 녹음 파일 이름에는 이름 · 전화번호가 들어가곤 해서, 기본으로 **중립 이름(`rec-<해시 앞 12자>.확장자`)** 으로 보낸다(`--keep-filename` 으로 끌 수 있다).
- 일꾼은 인터넷에서 누가 올렸는지 모르는 파일을 이 PC 의 디코더(ffmpeg)로 열지 않는다. 서버가 서버 안에서 16kHz mono 16bit WAV 로 바꾼 것만 받고, 파이썬 `wave` 로 형식 · SHA-256 을 확인한 뒤 읽는다. 약속과 다르면 받아쓰지 않고 실패로 돌려준다.
- 토큰은 `SERVER_URL` 과 같은 주소로만 보낸다. 일감이 다른 주소에서 오디오를 받으라고 하면 거절하고, 리다이렉트도 따라가지 않는다.
- 받아쓴 글 · 토큰 · 파일 경로는 로그에 찍지 않는다(길이 · 걸린 시간만).
- Whisper 가 녹음 끝 무음에서 지어내는 꼬리(「자막 제공 …」 「시청해 주셔서 감사합니다」)는 버리고 보낸다(프로토타입의 방식 + 자주 나오는 문장 몇 개).

## 실제 녹음 처리 — 가린 뒤 Claude (`real_mode.py`)

대표님 결정(2026-11-12): 실제 통화 녹음은 **PC 안에서 개인정보를 가린 뒤, 가린 글만 Claude 로 보낸다.** 이 경로는 데모 사이트 · 서버 · S3 를 전혀 거치지 않는다.

```
[녹음 파일] ─▶ (PC) Whisper 받아쓰기 ─▶ (PC) 가림 + 검사 ─┬─ 검사 걸림 → 보내지 않고 멈춤
 inbox\                 transcript.json     masked.json    │
                                            mapping.json   └─ 통과 → 가린 글만 ──▶ Claude API ─▶ 가명이 든 카드
                                            (대응표, PC 안)                                       │
[카드 모음] ◀── (PC) 가명 → 원래 값 · 거래처 목록 표기로 되돌림 ◀───────────────────────────────────┘
 out\cards.html · cards.csv
```

| 무엇 | 어디로 가나 |
|---|---|
| 녹음 · 받아쓴 원래 글 · 대응표(가명 ↔ 원래 값) · 카드 | **이 PC 의 `%USERPROFILE%\.t07-real\` 에만.** 저장소 · 데모 서버 · S3 에 올리지 않는다(그런 기능이 없다) |
| 가린 글 + 현장 말 사전 · 차종 목록 | Claude API(Anthropic). 거래처 · 이름 목록은 보내지 않는다 |

### 쓰는 법

1. 녹음을 `%USERPROFILE%\.t07-real\inbox\` 에 넣는다(m4a · mp3 · wav · amr · 3gp 등, 하위 폴더 가능).
2. (있으면) 같은 폴더에 목록을 둔다 — 한 줄에 하나.
   - `customers.txt`: 실제 거래처 이름. 더 잘 가리고, 받아쓰기가 틀린 상호(「세안 카센터」)를 목록 표기(「새한카센터」)로 맞춘다.
   - `names.txt`: 직원 · 손님 이름(「철수」처럼 직함 없이 부르는 이름은 목록이 있어야 가린다).
   - `extra.txt`: 그 밖에 가릴 말(우리 회사 이름 등).
3. **처음에는 미리 보기로 시작한다** — 받아쓰고 가리기만 하고 아무것도 보내지 않는다.
   ```
   .venv\Scripts\python real_mode.py preview --limit 5
   ```
   `%USERPROFILE%\.t07-real\preview\미리보기-….html` 을 열어 왼쪽(원래 글)과 오른쪽(보낼 글)을 견준다. 오른쪽에 이름 · 번호 · 상호가 남아 있으면 목록을 보태고 다시 미리 본다.
4. 괜찮으면 카드를 만든다(가림 검사를 통과한 통화만 보낸다).
   ```
   .venv\Scripts\python real_mode.py run
   ```
   결과: `%USERPROFILE%\.t07-real\out\cards.html` · `cards.csv`. 어디까지 했는지는 `real_mode.py status`.

Claude API 키는 저장소 밖 `%USERPROFILE%\.t07-secrets\server.env` 에서 읽는다. 다시 돌려도 이미 한 통화(받아쓰기 · 카드)는 건너뛴다.

### 무엇을 가리나

| 가림 | 예 | 가명 |
|---|---|---|
| 거래처 상호 | 목록의 이름, 「…카센터 · …공업사 · …모터스」 꼴 | 〔거래처A〕 |
| 사람 | 성 + 직함(김 사장 · 이 실장님), 이름 목록 | 〔사람1〕 |
| 차번호 | 48고 7531 · 48고, 7531 · 34R7788 · 67-8901, 나눠 부른 뒷자리 | 〔차번호1〕 |
| 전화번호 | 010-1234-5678 · 1588-0000 · 「공일공 일이삼사 …」 | 〔전화1〕 |
| 주소 · 계좌 · 메일 | 「경기 오산시 …」 「○○로 12」, 숫자 10개 이상 계좌, 메일 | 〔주소1〕 〔계좌1〕 〔메일1〕 |

부품 · 수량 · 차종 · 연식 · 품번 · 금액 · 날짜 · 시각은 주문 정보라 남긴다.

**보내기 직전 검사**: 가린 글에 위 꼴이 하나라도 남았거나, 대응표의 원래 값 · 목록의 이름이 남았으면 그 통화는 보내지 않고 `work\<번호>\check.json` 에 이유(값은 빼고)를 남긴다. 코드에서 바깥으로 나가는 길은 `Sender.send_masked()` 하나뿐이고, 이 함수는 가림과 검사를 거친 `MaskedCall` 만 받으며 보내기 직전에 한 번 더 검사한다.

### 가림의 한계 — 그래서 미리 보기부터

- 패턴으로 찾는 방식이라 **성 없이 부른 이름**(「철수야」), **상호 꼴이 아닌 거래처 이름**(「한성」만 말함), **받아쓰기가 크게 틀린 이름**은 놓칠 수 있다. 목록을 주면 줄어든다.
- 「우리 사장님」 「제 기사가」처럼 이름이 아닌 말을 사람으로 가려 버리는 일이 있다(정보가 조금 줄 뿐 새지는 않는다).
- 거래처 목록에 비슷한 이름이 둘 이상이면(한빛카 · 한일카) 고르지 않고 받아쓴 그대로 두고 카드 「들어 보기」에 적는다.
- 가린 뒤에는 Claude 가 거래처 목록으로 고쳐 읽지 못하므로, 거래처 이름 맞추기는 PC 의 목록 비교가 맡는다.

### 가짜 통화로 잰 결과

`eval_real_mode.py` — 가짜 데이터 전용(calls.json 설명에 「가짜」가 없거나 실제 녹음 폴더면 멈춘다). 결과는 [음성인식-비교 옆 기록](../../work/00-총괄-한결/자료/실제모드-가림-평가.md)에 있다.

## 시험

Whisper 없이 가짜 서버 · 가짜 받아쓰기로 돈다.

```
python -m unittest discover -s src/pc-agent/tests -v
```

확인하는 것(시험 16개): 가림(종류별 · 받아쓰기 꼴 · 목록) · 보내기 전 검사 · 되돌리기 · 「가린 것만 보낼 수 있음」, 일감 받기 → 받아쓰기 → 결과 보내기, 환각 꼬리 버리기, 다른 주소 · 형식이 다른 WAV 거절, 리다이렉트 안 따라감, 폴더 감시의 「쓰는 중 기다리기 · 중복 안 올리기 · 503 이면 미뤘다 다시 · 415 면 그만 · 원래 파일 이름(전화번호) 안 보내기 · 10MB 넘으면 안 보내기」.
