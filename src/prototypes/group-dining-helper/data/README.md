# 식당 데이터

이 폴더의 식당·메뉴는 **모두 지어낸 가상 데이터**다. 이름이 실제 가게와 겹치더라도 관계없다.
회사 주변 식당으로 바꾸려면 두 CSV를 엑셀에서 열어 고치고 **CSV UTF-8**로 저장한다.
다른 폴더를 쓰려면 `.env`에 `RESTAURANT_DIR=폴더경로`.

## restaurants.csv — 식당 한 줄에 하나

| 열 | 뜻 | 예 |
|---|---|---|
| id | 메뉴와 잇는 번호 | R01 |
| 이름 / 업종 / 역 | 업종은 메뉴 희망·기피에 쓰인다 | 숯결 화로구이 / 고기구이 / 강남역 |
| 도보분 | 역에서 걸어서 몇 분 | 6 |
| 단체최대 | 테이블을 붙여 받을 수 있는 최대 인원 | 30 |
| 한테이블최대 | 한 테이블에 앉을 수 있는 최대 인원 | 6 |
| 룸 | 룸 인원, 여러 개면 `;` | 8;12 |
| 룸조건 | 룸 최소 주문 등 | 룸 이용 시 1인 3만 원 이상 주문 |
| 휴무 | 쉬는 요일, 여러 개면 `;` | 일 |
| 점심 / 저녁 / 주차 | Y 또는 N | |
| 분위기 | `조용함`, `시끌벅적`, `고급`, `가성비` 등 | 조용함;고급 |
| 기준메뉴 | 예상 금액을 낸 기준 (화면에 그대로 보임) | 모둠구이 1.5인분 + 된장찌개 + 공기밥 |
| 인당식사 / 인당주류 | 기준 메뉴 인당 금액(원) | 33000 / 7000 |
| 캐치테이블 | 매장 페이지 주소. 넣으면 결정 화면에 예약 버튼이 생긴다 | |
| 가격기준일 | 가격을 확인한 날 | 2026-10-20 |

## menus.csv — 메뉴 한 줄에 하나

| 열 | 뜻 |
|---|---|
| 식당id | restaurants.csv의 id |
| 메뉴 / 가격 / 단위 | |
| 구분 | `메인`, `코스`, `식사`, `사이드`, `주류` — 못 먹는 음식 확인은 메인·코스만 본다 |
| 재료 | `회`, `해산물`, `갑각류`, `돼지고기`, `소고기`, `닭고기`, `양고기`, `매운맛` 중 해당하는 것 (`;`로 여러 개) |

예: “회 못 먹는 분 1명”이면 재료에 `회`가 없는 메인·코스 메뉴가 1개 이상 있어야 후보가 된다.
