# T07 인터랙티브 프로토타입

두 아이템의 UX와 업무 흐름을 비교하기 위한 브라우저 프로토타입이다.

## 실행

별도 패키지 설치나 빌드는 필요하지 않다. 저장소 루트에서 다음 명령으로 정적 서버를 실행한 뒤 `http://localhost:8000`에 접속한다.

```sh
python3 -m http.server 8000 --directory src/prototypes
```

## 화면

| 경로 | 프로토타입 | 주요 흐름 |
| --- | --- | --- |
| `/` | 제품 선택 | 두 아이템 진입 |
| `/callnote/` | 콜노트 | 예시 실시간 전사 → 주문 카드 추출 → 수정·확인 → 주문 확정 |
| `/tablemate/` | 모임테이블 | 조건 입력 → 식당 추천·비교 → 팀 투표 → 예약 요청 시뮬레이션 |

Sites: https://t07-product-prototypes.butterybeam16.chatgpt.site

## 범위

- 실제 STT, LLM, 전화 시스템, 식당 데이터 API, 예약 서비스는 연결하지 않는다.
- 전사와 주문 추출은 예시 대화를 시간차로 표시하는 시뮬레이션이다. 품번은 사람이 결정하는 흐름을 유지한다.
- 식당·가격·룸·추천 결과는 가상 데이터이다. 실제 매장 정보나 예약 가능 여부를 보장하지 않는다.
- 업로드·공유·투표·예약 화면은 데모 범위이며 실제 상대방에게 메시지나 예약을 보내지 않는다.
- 브라우저에 저장되는 데모 상태는 계정 간 동기화하지 않는다.
- 사용자 요청에 따라 테스트, 브라우저 QA, 정확도 및 동작 검증을 실행하지 않았다.

## 저장소 반영

GitHub 연결 앱의 브랜치 생성 요청이 403으로 거부되어 원격 업로드는 완료하지 못했다. 로컬 `feat/interactive-prototypes` 브랜치에 커밋하고, 같은 내용을 Sites의 `/t07-prototypes.patch`에 제공한다. 저장소에서 패치를 적용하려면 다음 명령을 사용한다.

```sh
git switch -c feat/interactive-prototypes
git am /path/to/t07-prototypes.patch
```

이후 쓰기 권한이 있는 계정으로 브랜치를 푸시하고 PR을 생성한다. `main` 직접 수정이나 강제 푸시는 하지 않는다.

## 채팅·공유 지식·지도 확장 프로토타입

원본 소스는 PR #2에 보존한다. 후속 브랜치에서 콜노트의 어시스턴트·공유 지식 화면과 모임테이블의 지도 화면을 추가한다.

### AI 채팅 실행

Node.js 20 이상에서 저장소 루트 기준으로 실행한다.

```sh
node src/prototypes/server/dev.mjs
```

`http://localhost:4177/callnote/`에 접속한다. 모델을 연결하려면 서버 환경에 `OPENAI_API_KEY`를 설정한다. `OPENAI_MODEL`은 선택 사항이며 기본값은 `gpt-4o-mini`다. 서버용 키를 HTML·브라우저 저장소·Git에 넣지 않는다. 로컬 환경 파일을 사용할 경우 `src/prototypes/.env`에 저장하고 다음과 같이 실행한다.

```sh
node --env-file=src/prototypes/.env src/prototypes/server/dev.mjs
```

자유 입력은 서버의 OpenAI Responses API로 처리한다. 키워드 매칭 응답이나 모델 실패 시 가짜 답변을 제공하지 않는다. 모델 연결 없이도 명시적인 예시 대화 버튼으로 화면 흐름을 체험할 수 있다. 정적 서버에서는 실제 AI 채팅 endpoint가 없으므로 예시 체험만 가능하다.

어시스턴트는 사용자가 전달한 통화 목록과 승인된 지식을 참조한다. 주문과 지식은 모델 입력으로 전달되며 API 요청은 `store: false`로 전송한다. 참조 항목은 요청당 통화 최대 100개, 승인 지식 최대 150개, 최근 대화 12개로 제한한다. 실제 품번·호환성·재고·납기를 조회하거나 보장하지 않는다. 재연락 문안과 지식은 담당자가 검토할 초안이다.

### 지식이 쌓이는 방식

팀 용어·별칭·관계·업무 규칙을 추가하고 제안→승인→활용의 흐름을 체험한다. 지식의 변경 이력과 되돌리기를 제공한다. 승인된 지식만 다음 모델 요청에 포함한다. 모델 가중치를 자동 학습시키는 방식은 아니다. 이 프로토타입의 지식은 해당 브라우저에 저장하며 다른 사용자와 동기화하지 않는다.

### 지도

모임테이블의 목록/지도 전환으로 후보를 함께 살펴본다. 가상 식당은 예시 좌표로 구분한다. 직접 찾은 실제 장소의 좌표와 주소를 입력하면 브라우저에 저장하고 외부 지도에서 길찾기를 열 수 있다. 실제 식당의 위치·가격·예약 가능 여부는 자동 검증하지 않는다. 자세한 설명은 `tablemate/MAP.md`를 참고한다.

### Sites 패키징

Sites 소스 체크아웃에서 기존 프로젝트 ID를 유지하고 Worker 배포로 전환한다. `static` 설정을 제거하고 아래 패키징을 실행한다. 별도 의존성 설치 없이 정적 파일과 서버 endpoint를 Worker 한 파일에 포함한다.

```sh
node src/prototypes/server/build-site.mjs
```

출력은 현재 작업 디렉터리의 `dist/server/index.js`다. Sites 런타임에 `OPENAI_API_KEY`를 비밀값으로 설정해야 실제 AI 응답이 가능하다. 원본 Site의 접근 범위는 유지한다.

참고: https://developers.openai.com/api/docs/guides/structured-outputs

사용자 요청에 따라 이 확장에서도 테스트·린트·브라우저 QA·동작 검증은 실행하지 않는다.
