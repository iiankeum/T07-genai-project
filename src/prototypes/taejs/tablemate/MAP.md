# 후보 지도

목록의 지도 버튼 또는 ‘지도와 함께’를 누르면 지도를 표시한다. 지역·음식·인원·예산 조건에 맞는 후보가 지도에 반영되고, 마커 선택과 후보 카드가 서로 연결된다.

기존 예시 식당의 좌표는 역 주변에 배치한 가상 위치이다. 실제 매장 주소나 위치로 사용하지 않는다. 실제 장소는 사용자가 이름·주소·위도·경도를 직접 입력하여 추가할 수 있으며, 해당 브라우저에 저장한다. 메뉴·룸·가격·예약 가능 여부와 좌표를 자동 확인하지 않는다. 외부 지도 검색과 입력 위치로 길찾기를 연결한다.

Leaflet 1.9.4와 OpenStreetMap 타일은 지도 보기 시점에만 불러온다. 외부 네트워크 연결이 필요하며, 파일 URL에서는 타일을 요청하지 않는다. 타일 캐시를 우회하거나 미리 다운로드하지 않고, 지도 위 출처 표기를 유지한다. 로딩 실패 시 외부 지도 링크를 제공한다.

- Leaflet: https://leafletjs.com/reference-1.9.4.html
- 타일 이용 정책: https://operations.osmfoundation.org/policies/tiles/

사용자 요청에 따라 테스트·브라우저 QA·동작 검증은 실행하지 않았다.
