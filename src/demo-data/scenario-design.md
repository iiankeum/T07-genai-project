**모든 거래처 · 사람 · 차번호 · 품번 · 금액은 지어낸 것이다.** 공개 저장소에 올라간다.

### 반드시 지킬 것
1. 아래 MANIFEST 에서 **너에게 배정된 통화만** 쓴다. 통화 id · 시각 · 거래처 · 호칭 · 사실(차종 · 연식 · 차번호 · 부품 · 수량 · 품번 · 금액 · 배송)은 **MANIFEST 그대로**. 바꾸지 않는다. 이어지는 통화(refs)끼리 사실이 맞아야 하기 때문이다.
2. 실제 회사 · 브랜드 이름(자동차 회사명, 부품 회사명, 오일 브랜드, 은행 이름 등)은 쓰지 않는다. 차종 이름(아반떼, 쏘나타, 포터 …)은 써도 된다. 사람은 MANIFEST 의 호칭(「김 사장」「박 부장」)만 쓰고 새 실명을 만들지 않는다.
3. `say` 는 **합성 음성이 그대로 읽을 글**이다. 아라비아 숫자 · 영문자 · 하이픈 · 괄호 · 따옴표를 쓰지 않는다. 숫자 · 영문 · 품번 · 차번호는 사람이 전화로 읽는 한글 소리로 쓴다.
   - 차종 코드: 「아반떼 에이디」「케이파이브 디엘쓰리」「그랜저 지엔세븐」「투싼 엔엑스포」「포터 투」「봉고 쓰리」
   - 연식: 「십칠 년식」「이십일 년식」
   - 차번호: 「삼십사 나, 오육칠팔」처럼 앞 숫자는 수로, 뒤 네 자리는 한 자씩. 세 자리 앞번호는 「백오십칠 머, 이사육팔」
   - 품번: 「오팔일공일 다시 디사에이이오」처럼 한 자씩, 하이픈은 「다시」
   - 수량: 「하나」「두 개」「스무 개」「한 세트」「네 통」, 금액: 「백팔십칠만 사천 원」
   - 문장부호는 쉼표 · 마침표 · 물음표 · 느낌표만. 「…」 대신 쉼표.
4. 현장 통화처럼 쓴다: 짧고 두서없다. 「예예」「아 그거」「잠깐만요」「여보세요?」, 말 끊김, 되묻기, 혼잣말. 대리점 직원은 받은 주문을 **복창**하는 버릇이 있다(그래야 나중에 녹음으로 확인된다). 정비소 쪽은 바빠서 말이 빠르고 줄임말(휀다 · 쇼바 · 라지에다 · 세루모터 · 제네레다 · 데루등 · 본네트 · 활대링크 · 마후라)을 쓴다.
   - 한 통화 **5~14턴**, 대부분 6~10턴. 잡담 통화 · 다툼 통화는 길게(10~14턴). 잘못 건 전화는 3~4턴.
   - 한 턴은 보통 한두 문장. 너무 길면 합성 음성이 부자연스럽다.
5. 사투리는 합성 음성이 읽을 수 있게 **어미 · 낱말 위주로 가볍게**(경상: 「~하이소」「퍼뜩」「와 이리」「~카이」, 전라: 「~하쇼잉」「거시기」「~혀」「~당께」, 충청: 「~해유」「~했슈」「천천히 혀도 돼유」).
6. 공장 소리 통화(tags 에 공장소리)는 정비소 쪽이 시끄러운 곳에서 거는 것이다. 「네? 뭐라고요?」「잠깐만요, 여기 임팩 소리 땜에」 같은 되묻기 · 크게 다시 말하기를 1~2번 넣는다.
7. 인바운드(정비소가 건 전화) 첫 턴은 대리점: 「네, 부품입니다.」「네 부품 대리점입니다.」「예 부품이요.」 등. 아웃바운드(대리점이 건 전화)는 정비소가 먼저 받는다: 「네, 태양카센터요.」

### 출력 형식
UTF-8 JSON 파일 하나: `{"calls": [ ... ]}`. 통화 하나의 모양:

```json
{
  "id": "c03",
  "turns": [
    {"who": "dealer", "say": "네, 부품입니다."},
    {"who": "shop", "say": "예, 우리공업사인데요. 쏘나타 디엔에잇, 차번호가 백오십칠 머, 이사육팔이에요."}
  ],
  "gold": {
    "intent": "주문",
    "is_order": true,
    "customer": "우리공업사",
    "car": "쏘나타 DN8",
    "car_kw": ["쏘나타|소나타", "DN8"],
    "year": null,
    "plate": "157머2468",
    "items": [
      {"action": "주문", "part": "운전석 휀다(펜더)", "part_kw": ["휀다", "펜더", "휀더", "펜다"], "qty": 1, "part_no": null, "car": null},
      {"action": "주문", "part": "운전석 헤드램프", "part_kw": ["헤드라이트", "헤드램프", "전조등"], "qty": 1, "part_no": null, "car": null}
    ],
    "urgent": false,
    "delivery": "내일",
    "needs_ask": true,
    "ask": ["헤드램프 LED/일반(할로겐) 확인 — 거래처가 차 보고 다시 전화"],
    "summary": "쏘나타 DN8(157머2468) 운전석 휀다 1 · 운전석 헤드램프 1(사양 확인 필요), 내일 배송",
    "dispute": null
  }
}
```

gold 필드 설명 (사람이 통화를 듣고 쓴 **정답 카드**):
- `intent`: 통화의 주된 목적 하나 — `주문` `재고문의` `반품` `교환` `주문취소` `주문추가` `주문다툼` `배송독촉` `결제` `외상` `확인회신` `대리점발신` `신규거래` `잘못건전화` 중에서 MANIFEST 에 적힌 것.
- `is_order`: 이 통화로 **새로 출고할 물건**이 생기면 true (교환 · 다툼 후 추가 출고 · 주문추가 포함). 재고문의 · 결제 · 외상 · 취소 · 잘못건전화는 false.
- `customer`: 거래처 표기 그대로. 잘못 건 전화는 null.
- `car`: 정규화한 차종 표기(「아반떼 AD」「K5 DL3」「포터2」). 없으면 null. `car_kw`: 채점용 낱말 — 받아쓴 글에 있어야 할 낱말. 표기가 여럿이면 `|` 로(「쏘나타|소나타」). 세대 코드는 영문(「DN8」).
- `year`: 「2017」처럼 네 자리 문자열 또는 null. `plate`: 「157머2468」처럼 띄어쓰기 없이 또는 null.
- `items`: 이 통화에서 다룬 부품. `action` 은 `주문` `반품` `교환` `취소` `문의` 중 하나. `part` 는 사람이 읽을 이름(위치 · 사양 포함). `part_kw` 는 채점용 동의어(현장 말 · 표준 말 · 흔한 오기 3~6개, 위치 낱말은 넣지 않는다). `qty` 는 정수 또는 null(모를 때). `part_no` 는 「58101-D4A25」 형식 또는 null. `car` 는 여러 차종 통화에서 이 부품의 차종(아니면 null).
- `urgent`: 정비소가 급하다고 했거나(오전 중 · 퀵 · 지금 차 올려놨다 · 손님 기다린다) 대리점이 퀵으로 보내면 true.
- `delivery`: 배송 약속을 짧게(「오전 중」「퀵」「오후 두 시 차」「내일 오전」「이번 주 안」) 또는 null.
- `needs_ask`: 통화가 끝났는데도 **아직 확인해야 할 것**이 남았으면 true, `ask` 에 무엇을 확인할지 적는다(없으면 []).
- `summary`: 대시보드 한 줄 요약(60자 안팎, 숫자는 아라비아 숫자로).
- `dispute`: 다툼 · 확인이 있는 통화만 `{"claim": "거래처 주장", "record": "지난 통화(cNN)에서 실제로 한 말", "who_right": "거래처|대리점", "resolution": "어떻게 정리했나"}`. 아니면 null.
- gold 의 숫자 · 영문은 아라비아 숫자 · 영문으로 써도 된다(사람이 보는 카드).

### 끝나면
파일을 저장한 뒤 `python -c "import json;d=json.load(open(r'<경로>',encoding='utf-8'));print(len(d['calls']))"` 로 JSON 이 깨지지 않았는지 확인하고, 통화 id 목록과 턴 수만 짧게 보고한다.
